# CAPSULE 로고 벡터 정리안 · 2026-11-22

Figma: https://www.figma.com/design/HpoEbOqfoDUwPq4zvYa6LL?node-id=2935-309
페이지: 디자인 시스템
섹션: CAPSULE · 로고 에셋과 사용 가이드 · 2026.11.22

심볼(symbol), 워드마크(wordmark), 가로 조합(horizontal) 각각 color/white/black: 총 9개 SVG.

기존 Figma 최종 로고의 2170×725 래스터 원본을 바탕으로 윤곽을 추출하고 가장자리 잡티를 정리한 검토용 벡터다. 컬러 심볼의 음영은 연속 그라데이션으로 재구성했다. 원본 벡터가 발견된 것은 아니며, 픽셀 단위 복제를 보증하는 에셋은 아니다. 글자도 경로이므로 글꼴 설치 없이 사용할 수 있다. 이미지 태그, 내장 비트맵, 외부 링크, 스크립트가 없다.

화이트/블랙 심볼은 알약 내부를 투명하게 뚫은 한 가지 색의 경로다. 해당 투명 영역에는 배경이 비친다. 가로 조합의 심볼/글자 비율과 간격을 유지한다.

## 사용 규칙

- 심볼 최소 폭 16px, 가로형 최소 폭 100px: 기존 Figma 시트 기준 재사용.
- 워드마크 최소 폭 80px: 새 제안값. 실제 사용 위치에서 검토 후 확정.
- 주변 여백 x = H/4. H는 각 로고 자산의 보이는 높이.
- 밝은 배경: 컬러 또는 블랙. 어둡거나 색이 있는 배경: 화이트.
- 비율/간격을 유지하고, 매우 작은 영역에는 심볼을 우선 검토.

Figma 마스터는 CAPSULE Logo 2026 / Symbol, Wordmark, Horizontal 3개 세트에 Tone=Color/White/Black으로 구성했다. 가로 조합은 심볼/워드마크 인스턴스를 재사용하고, 가이드도 컴포넌트 인스턴스다. 설명 서체만 Noto Sans KR로 대체했으며 로고 글자에는 시스템 글꼴을 사용하지 않았다.

현재 웹 Brand 컴포넌트와 기존 logo.webp는 그대로다. 이 폴더는 검토/내보내기용 에셋이며 배포되는 앱에서는 아직 참조하지 않는다.
