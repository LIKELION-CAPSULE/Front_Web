# 로그인 시안 에셋

`/login?login=illustration|portrait` 시안이 이 폴더의 파일을 자동으로 읽는다. 파일이 없으면 방 배경 + 채린 렌더로 대체된다.

| 파일 이름 | 쓰는 시안 | 권장 사양 |
|---|---|---|
| `illustration.webp` (png·jpg·avif 가능) | 일러스트 | 16:9 이상, 가로 2560px 이상. 메이트는 화면 왼쪽 60% 안, 오른쪽 40%는 로그인 폼이 덮어도 되는 배경 |

파일 이름은 정확히 위와 같아야 한다. 넣은 뒤 개발 서버를 새로고침하면 반영된다.
