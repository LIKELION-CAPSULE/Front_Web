# 출석체크 길 (홈 히어로)

`features/attendance/components/AttendancePath.tsx`에서 사용합니다.

| 파일 | 내용 |
| --- | --- |
| `attendance-path.png` | 원본. 1600×1000 투명 배경. 길, 발판 7개, 7일차 보상 캡슐이 한 장 |
| `attendance-path-road.png` / `.webp` | 원본에서 캡슐(별 2개 포함)만 지운 길. 화면에서 쓰는 배경 |
| `reward-capsule.png` / `.webp` | 원본에서 떼어 낸 캡슐 레이어. 원본 기준 (1169, 14)–(1377, 258), 208×244 |
| `pads.json` | 발판 7개의 윗면 중심 좌표 (이미지 기준 %, 좌상단 원점) |
| `chaerin-idle.png` / `.webp` | 서 있는 포즈. 발끝이 이미지 맨 아래 (WebP는 높이 600) |
| `chaerin-walk.png` / `.webp` | 오른쪽으로 걷는 포즈. 발끝이 이미지 맨 아래 (WebP는 높이 600) |

캡슐 분리: 원본 알파에서 캡슐 몸통을 4방향 연결 영역(알파 > 2)으로 잡고 2px 넓혀 가장자리를 포함하되, 7일차 발판 영역과 그 1px 주변은 제외했습니다. 별 2개와 발판 위쪽의 옅은 빛도 캡슐 레이어로 옮겼습니다. 두 레이어를 겹치면 원본과 같습니다.
