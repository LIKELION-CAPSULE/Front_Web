# 출석체크 길 (홈 히어로)

`features/attendance/components/AttendancePath.tsx`에서 사용합니다.

| 파일 | 내용 |
| --- | --- |
| `attendance-path-road.webp` | 원본(1600×1000 투명 배경, 길·발판 7개·7일차 보상 캡슐 한 장)에서 캡슐(별 2개 포함)만 지운 길. 화면에서 쓰는 배경 |
| `reward-capsule.webp` | dev의 3D 교체 이전 원본에서 분리한 7일차 보상 캡슐 레이어(별 2개 포함). 원본 기준 (1169, 14)–(1377, 258), 208×244. 배치는 left 73.0625%, top 1.4%, width 13%로 복원 |
| `pads.json` | 발판 7개의 윗면 중심 좌표 (이미지 기준 %, 좌상단 원점) |
| `chaerin-idle.webp` | 서 있는 포즈. 발끝이 이미지 맨 아래 (높이 600) |
| `chaerin-walk.webp` | 오른쪽으로 걷는 포즈. 발끝이 이미지 맨 아래 (높이 600) |

예전 캡슐 분리: 원본 알파에서 캡슐 몸통을 4방향 연결 영역(알파 > 2)으로 잡고 2px 넓혀 가장자리를 포함하되, 7일차 발판 영역과 그 1px 주변은 제외했습니다. 별 2개와 발판 위쪽의 옅은 빛도 캡슐 레이어로 옮겼습니다. 두 레이어를 겹치면 원본과 같습니다.

PNG 원본(`attendance-path.png`, 길·캡슐·포즈 PNG)은 런타임에서 쓰지 않아 2026-11-28 정리에서 지웠습니다. 다시 편집해야 하면 git 기록(정리 커밋의 부모)에서 꺼내 쓰세요.

2026-11-28에 홈 캡슐을 `origin/dev`의 원본 레이어와 크기로 되돌렸습니다. 900px 말풍선이 캡슐을 가리지 않도록 한 정렬과 줄바꿈은 유지합니다. 확대에 맞춘 추가 간격과 사용법 강조 범위 확장은 제거했습니다.

3D 열림 WebP는 원본 캡슐의 형태·장식과 첫 프레임이 이어지지 않아 제거했습니다. dev의 기존 연출(왼쪽으로 이동 → 흔들림과 빛 → 별빛과 함께 사라짐)을 사용하며, reduced-motion에서는 즉시 완료 상태를 표시합니다. `scripts/check-reward-opening.mjs`가 정상·동작 축소 모드의 완료 정리와 3D 프레임 요청이 없음을 검사합니다.

홈 에셋은 공용 3D 렌더 대상에서 제외했습니다. `render-polish-assets.mjs`와 기존 이름을 유지한 `pack-reward-sprite.py`는 이제 수화기만 처리하며 홈 캡슐을 덮어쓰지 않습니다. 공용 캡슐 폴더의 문서에 남아 있는 출석 3D 패킹 설명은 과거 방식입니다.
