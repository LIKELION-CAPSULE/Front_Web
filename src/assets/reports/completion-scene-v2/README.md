# 종료 리포트 전체 화면 장면 v2

2026-11-05, 내장 `image_gen`으로 생성한 채린의 완료 장면입니다. [기존 세로 원본](../completion-v1/chaerin-completion-v1.webp)의 얼굴·밝은 미소·의상·손인사·노을빛 교실을 참조해, 채린은 왼쪽에 두고 오른쪽은 결과 패널을 위한 교실 배경으로 구성했습니다. 글자·대사·통계는 이미지에 포함하지 않고 HTML로 표시합니다.

- [PNG 마스터](chaerin-completion-scene-v2.png): 1672×941
- [웹용 WebP](chaerin-completion-scene-v2.webp): 181,716바이트, cwebp 품질 88·method 6
- [최종 프롬프트·참조·생성 방식](generation-manifest.json)
- [파일 크기·SHA-256](asset-metadata.json)

이후 [분리 레이어 v3](../completion-layers-v3/README.md)의 참조로 사용했으며 현재 리포트는 v3를 사용합니다. 이 파일은 초기 전체 화면 장면의 생성 이력으로 보관합니다. 캡슐 카드 미리보기·PNG 내보내기는 기존 `completion-v1` 이미지를 유지합니다. 외부 예시 이미지의 인물·그림체·UI는 생성 입력으로 사용하지 않았습니다.

검증: 2560·1440·1366·1024·1023·768·390·320px에서 이미지 전환·대사/결과 배치·가로 넘침·44px 실행 영역을 확인했습니다. 실제 3분 세션 종료→리포트→캡슐 카드·홈 및 새로고침을 확인했고, 기존 샘플 기록의 집중 흐름도 유지합니다. 유리 표면을 순백 이미지 위에 합성한 보수적 RGB 상한에서 보조 글자(subtle)의 대비는 4.57:1 이상이며, 흐림을 끈 불투명 panel 대체 표현도 확인했습니다. 이는 모든 기기·브라우저의 접근성 인증을 뜻하지 않습니다.
