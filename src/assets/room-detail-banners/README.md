각 파일의 `.png`는 선택된 생성 마스터, `.webp`는 웹용 파일입니다. 대부분 2172×724, 야간 도서관은 2167×726입니다. WebP 9종 합계는 약 **2.24MiB**이며 `cwebp -q 88 -m 6`으로 변환했습니다. 원본 에셋은 덮어쓰지 않았습니다.

하준 배너는 v2에서 의자에 골반을 붙이고 무릎을 낮춘 자연스러운 자세로 수정했습니다. 얼굴·배경·조명·왼쪽 문구 여백은 유지했습니다. [수정 프롬프트와 파일 정보](iljin-detail-banner-v2-generation.json)를 보관하며, v1은 비교용 원본으로 남겨 둡니다.

## 생성과 교체

전체 **프롬프트 세트·인물 참조 파일·생성 결과 경로·실제 크기·WebP 해시**는 [generation-manifest.json](generation-manifest.json)에 있습니다. 공통 생성 조건은 다음과 같습니다.

- 원본의 얼굴·헤어·의상·인원수를 참조한 단일 3:1 파노라마 장면
- 왼쪽은 HTML 문구를 위한 차분한 여백, 오른쪽은 자연스럽게 좌석을 이용하는 인물
- 인물과 공간의 원근·빛·접촉 그림자가 일치하고 몸을 지지하는 의자·소파·방석이 보이는 구도
- 이미지 안 제목·로고·UI·워터마크와 인물 앞을 가리는 책상 제외

[detail-banners.ts](../../features/rooms/detail-banners.ts)에 룸 ID별 경로·크기를 등록하고 [RoomDetailBanner](../../features/rooms/components/RoomDetailBanner.tsx)가 표시합니다. 데스크톱은 문구를 이미지 위에 배치하고, 1023px 이하에서는 인물 쪽 이미지와 문구를 위아래로 배치합니다. 배치는 [room-detail-banner.css](../../features/rooms/components/room-detail-banner.css)에서 조정합니다.

메인화면의 룸 카드는 `scenes/`의 분리된 배경·전신을 계속 사용합니다. 상세 배너를 바꿀 때는 이 폴더에 새 버전을 만들고 등록 경로를 교체하면 됩니다.

## 함께 반영한 화면 정리

공통 토글과 메인 룸 필터의 외곽선, 헤더 PREVIEW, 상세의 추가 영문 문구·설명과 떠 있는 포스터, 홈 링크의 왼쪽 화살표, 친구 카드의 `다음 만남을 기다려요`를 제거했습니다. 도윤·모루·하준·유리는 `features/characters/artwork.ts`의 `cardPortrait`로 얼굴 확대 범위를 따로 관리합니다. 아바타 및 공부 장면의 원래 배치는 유지합니다.

9개 룸과 320/390/768/1024/1440px 화면에서 브라우저 검사 **100개**, 기존 단위 테스트 **33개**, ESLint 및 프로덕션 빌드가 통과했습니다. [검증 기록](validation.json)에 범위를 저장했습니다. 실제 모바일 기기와 다른 브라우저 엔진은 이번 검사에 포함하지 않았습니다.
