# Tween UI Number Counter

[공식 Number Counter](https://tween-ui.vercel.app/component/number-counter)의 GSAP `ScrollTrigger`·`useGSAP` 일회성 트리거와 NumberFlow 숫자 롤링을 사용합니다. 단순 텍스트 보간으로 흉내 내지 않고 공식 레지스트리 소스를 로컬로 적용했습니다. [원본 해시·변경 내역](upstream.json), [MIT 원문](LICENSE.txt), [배포 고지](../../../../public/licenses/TweenUI-MIT.txt)를 보존합니다.

리포트의 공부/집중/자리 비움 시간, 목표 진행률, 집중률, 복귀 횟수, 친구와 함께한 시간·다음 레벨까지의 분, 확정된 현재 호감도, 샘플 집중 흐름의 시간에 적용합니다. 날짜·완료 시각·Lv 단계·범위 상한 등 고정 의미의 표기는 유지합니다. 호감도가 미정인 `—`는 애니메이션하거나 0으로 바꾸지 않습니다.

- 기본 1.8초이며 화면에 들어오면 한 번만 재생합니다. 모바일에서 아래 영역은 스크롤 진입 후 재생하고, 다시 스크롤해도 반복하지 않습니다. `instant`는 즉시 시작이 필요한 곳의 원본 옵션입니다.
- `ko-KR` 포맷과 기존 분/시간·소수 초 단위를 유지합니다. `AnimatedDuration`은 기존 `duration`/`measuredDuration`과 같은 반올림을 사용합니다.
- 최종값의 정수·소수 자릿수를 먼저 확보합니다. `595`는 `000`에서, `44.6`은 `00.0`에서 시작하며 소수점·구분자는 고정됩니다. NumberFlow의 `trend={1}`과 `continuous`로 각 숫자 칸이 위로 회전합니다. 각 `::part(digit)`만 클리핑하고 외부 표시 영역도 보호합니다.
- 보이지 않는 일반 텍스트가 인라인 기준선·너비·줄 높이를 정합니다. 실제 숫자는 그 위에 겹쳐 표시하고 라이브러리의 추가 마스크 패딩은 0으로 둡니다. 카운터의 `+10초`, `595분`과 일반 글자의 기준선이 같으며 줄 높이가 늘어나지 않습니다. 보조 기술에는 최종값을 한 번 제공하고, 보이는 롤링은 숨깁니다.
- 모션 감소 설정 변경도 바로 반영합니다. 트리거·지연 타이머는 언마운트 때 정리합니다.
