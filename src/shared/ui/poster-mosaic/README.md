# PosterMosaic

포스터 9종을 5개 행으로 배치하고, 홀수 행은 오른쪽·짝수 행은 왼쪽으로 끊김 없이 이동합니다. 이미지는 `object-fit: contain`으로 원본 전체를 보여 줍니다. 행 높이를 공유하되 각 칸의 너비는 디코딩한 원본 이미지 비율에 맞춥니다. 칸 내부의 위아래/좌우 여백 없이 원본을 표시하고, 포스터 사이에는 지정한 격자 간격만 남깁니다.

```tsx
<PosterMosaic images={authPosters} rowSpeed={24} rotation={-10} />
```

`images`는 `id`와 `src` 목록입니다. `rowSpeed`는 초당 이동 픽셀 수이며, `rotation`은 전체 격자의 회전 각도입니다. 부모에 높이가 정해져 있어야 합니다. 로그인 포스터 목록은 [`features/auth/posters.ts`](../../../features/auth/posters.ts)에서 관리합니다.

중복 트랙을 한 주기씩 옮기는 GSAP 애니메이션 5개를 사용합니다. 이미지 소스를 디코딩한 뒤 각 원본 비율을 적용하고 재생합니다. 이동 거리는 서로 다른 칸 너비와 간격을 한 세트씩 합산해 반복 경계를 맞춥니다. 리사이즈 시 진행률을 유지하고 이동 거리를 다시 계산합니다. 일시정지·모션 감소 설정·탭 숨김을 지원하고 언마운트 시 observer·이벤트·애니메이션을 정리합니다.
