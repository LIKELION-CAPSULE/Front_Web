# CAPSULE Web

AI 친구와 함께 공부하는 CAPSULE의 프런트엔드 데모입니다. 백엔드 없이 더미 계정·기록·크레딧으로 전체 화면 흐름을 체험할 수 있습니다. `Front_Web` 안에서 독립적으로 실행하며, 옆의 `Landing_Page`와 의존성·설정을 공유하지 않습니다.

## 실행

Node.js 22 LTS(22.13 이상) 또는 24 이상이 필요합니다. `.nvmrc`는 Node 22를 기준으로 합니다.

```bash
cd Front_Web
npm ci
npm run dev
```

Vite가 출력하는 로컬 주소에서 확인합니다.

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run preview
```

## 화면 흐름

```text
더미 로그인 → 내 아바타 → 홈 → 스터디룸 상세
  → 카메라 확인 → 목표 시간·대화 옵션 선택 → 공부 → 휴식·대화
  → 종료 리포트 → 캡슐 카드·다음 약속 → 홈
```

| 경로 | 화면과 동작 |
|---|---|
| `/login` | 카카오·더미 계정 시작 화면. 로그인/회원가입 링크로 우측 전체 폼 전환. 회원가입은 약관 2개 필수 동의 및 전문 보기 (`?mode=login`, `?mode=signup`) |
| `/onboarding` | 이름과 헤어·의상·외모·배경의 샘플 옵션 선택 |
| `/mypage` | 닉네임·아바타 편집, 모든 친구가 공유하는 나의 일정 조회·추가·수정·삭제 |
| `/` | 첫 방문/이어하기 홈, 룸 탐색·저장, 진행 중인 세션 복귀 |
| `/rooms/:roomId` | 룸 설명과 친구 관계, 공부 시작 |
| `/rooms/:roomId/prepare` | 실제 카메라·마이크 권한 및 로컬 얼굴 감지 확인, 캠 배경 선택(기본·블러·이미지 3종, 미리보기에 즉시 반영) → `?step=goal`에서 목표 시간·대화 옵션 선택 |
| `/study/:sessionId` | 1:1/1:3 공부, 포커스 보기, 타이머·일시정지·채팅·휴식·등급 변경, 하단 메뉴 **배경 바꾸기**로 캠 배경 변경(준비 화면 선택 유지) |
| `/reports/:recordId` | 집중·딴짓·복귀·관계 변화의 샘플 결과 |
| `/capsules/:recordId` | 카드 색·PNG 저장·공유·날짜/시간 휠로 다음 공부 약속 |
| `/records` | 전체/스터디룸별 시간·이용일·최근 세션, 이전/다음 주·월 탐색 |
| `/characters/:characterId` | 친구별 관계·해금 콘텐츠·선물·공부 시작 |
| `/characters/:characterId/shop` | 선물/보이스 필터·미리보기·더미 구매·보관함 |
| `/credits` | 잔액·패스·통합 충전/사용/보너스 내역·샘플 영수증, 우측 상단 충전 버튼 |
| `/credits/charge` | 패스/크레딧 토글 가격표 → 결제 오버레이 → 완료 영수증 출력·떼기·재출력 |

`/characters`는 기본 친구 채린의 관계 화면으로 열립니다. 없는 룸·친구·기록은 찾을 수 없음으로 처리합니다.

## 빠르게 체험하기

1. 카카오로 계속하기 → 아바타 설정을 완료하거나, **가입 없이 둘러보기**를 누릅니다.
2. 쌀쌀맞은 갸루짝꿍이 나에게만 친절하다! → 공부 시작 → 카메라 확인 → 대화 옵션을 선택합니다.
3. 공부 화면의 **데모 조작 → 휴식 화면 보기**를 누르면 목표 시간을 기다리지 않고 휴식을 볼 수 있습니다. 공부 타이머는 `경과 시간 / 목표 시간`으로 표시하며 0초부터 늘어납니다. 휴식 미리보기는 07:42부터 줄어듭니다.
4. 쉬는 시간에 프리미엄으로 올리면 이미 낸 200을 제외한 300만 차감됩니다. 베이직의 하루 3회 대화 한도는 친구·공부/휴식 화면 전체에서 공유하며, 서울 기준 새벽 5시에 갱신합니다.
5. 종료 후 캡슐 카드 이미지를 저장하거나 다음 공부 약속을 추가합니다. 크레딧 충전·선물·패스도 더미 상태로 연결됩니다.

프로필 메뉴의 **마이페이지**에서 닉네임·아바타와 나의 시험·목표·약속을 한곳에서 관리합니다. 일정은 모든 친구가 함께 기억하는 공통 목록이며 예정/전체/지난 기간으로 조회합니다. 일정마다 친구를 지정하지 않으며, 기존 친구별 일정도 내용과 날짜를 보존해 공통 일정으로 이전합니다. 친구 화면에는 개별 일정 영역을 표시하지 않습니다. 프로필 메뉴에서 **첫 방문 화면 보기**, 로그아웃, **체험 기록 초기화**도 할 수 있습니다. 사용자 데이터는 `localStorage`의 `capsule-wireframe-demo:v1`에 저장됩니다. 저장을 사용할 수 없으면 메모리로 동작하며, 새로고침하면 초기화될 수 있음을 화면에 안내합니다.

공부 화면의 **확대 모드(V)**에서는 친구 카드를 눌러 크게 보기·원래 보기로 전환합니다. **말 걸기 모드(C)**나 헤더 대화 버튼은 오른쪽 공통 채팅 패널을 엽니다. 친구 토글로 상대를 바꾸면 각 대화 이력·입력 중인 내용을 유지하며 영상의 확대 상태는 바뀌지 않습니다. 넓은 화면은 사이드바, 1023px 이하는 배경 스크롤을 막는 드로어로 표시합니다. 공부·휴식에서 같은 패널을 사용하며 새 답장만 타이핑하고 이전 이력은 즉시 표시합니다. 입력창은 입력 시 확장되며 Enter로 전송, Shift+Enter로 줄바꿈합니다. 한글 조합 중 Enter는 전송하지 않습니다. 영상 위 유리 독에서 마이크·카메라·아바타/실제 캠·일시정지·계속·종료를 조작하며 데모 메뉴는 룸 제목 오른쪽에 있습니다. 헤더 시간은 `00:17:23 / 00:50:00` 형식이고 바뀐 숫자만 움직입니다. 집중률은 50% 미만 빨강, 50~80% 미만 흰색, 80% 이상 초록이며 미측정은 `—`입니다. 움직임 줄이기 설정에서는 패널·타이핑·숫자 효과를 생략합니다.

## 디자인

홈의 친구 환영 장면, 포스터형 스터디룸 카드, 일러스트 기반 공부·휴식 화면, 친구 관계·선물·기록·크레딧 화면을 같은 색상·컨트롤로 연결했습니다. 룸/친구 검색·저장 필터·SVG 아바타 미리보기를 지원하고, 캡슐 카드의 실제 PNG에도 친구 그림이 들어갑니다.

- 색상·폰트·간격: `src/styles/index.css`의 Tailwind `@theme`
- 공통 UI: `src/shared/ui`의 `Brand`, `Icon`, `AvatarIllustration`, `Button`, `Panel` 등
- 친구 그림·표정·인물별 표시 영역: `src/features/characters/artwork.ts` / 공통 렌더링: `CharacterArtwork`
- 룸 문구·친구 구성: `src/features/rooms/data/rooms.ts` / 원본 포스터: `src/features/rooms/posters.ts` / 이미지 결합: `services/room-service.ts`
- 룸 장면의 배경·친구·책상·제목: `src/features/rooms/artwork.ts` / `src/styles/scenes.css`
- 탐색·기록·공통 피드백 스타일: `src/styles/interactions.css`
- 상세 가이드: [디자인 시스템](docs/DESIGN_SYSTEM.md)

참고 사이트의 기존 조사로 활동 달력·집중률 링·공통 로딩·조용히 집중 모드를 추가했습니다. 현재 52곳을 재조사한 뒤 메인 히어로의 큰 슬로건과 소개는 방문 상태별로 바꾸고, 우측 하단 대사를 초상화·이름·꼬리 없는 글래스모피즘 형태로 정리했습니다. 확인 범위·접근 오류·적용 판단은 [52곳 재조사 기록](docs/WELCOME_HERO_RESEARCH.md)에 있습니다. 재사용 컴포넌트는 `CompanionGreeting`, 전용 스타일은 `src/styles/welcome.css`입니다. 현재 메인 배너는 [호버 지우기 전환](src/shared/ui/hover-scratch/README.md)을 사용합니다. [채린·수아·다희 전용 가로 이미지](src/assets/welcome-banners/README.md)를 생성했으며, 현재 이미지와 HTML 대사는 하나의 마스크로 함께 지워집니다. 마우스가 지나간 자리에 다음 이미지와 다음 대사가 보이고 면적 40%가 지워지면 나머지를 정리한 뒤 다음 이미지로 순환합니다. 첫 방문·이어하기 문구와 버튼은 HTML로 관리합니다. 모바일·터치·모션 감소에서는 친구 선택 버튼으로 전환합니다. 이전 하프톤 시안은 현재 화면에서 연결을 해제했습니다.

기존 포스터의 잘림을 줄이기 위해 9종 모두 이미지 생성으로 전신 친구/그룹과 독립 배경을 만들었습니다. 메인화면은 [책상 없는 바닥 배경 9종](src/assets/scenes/seated-v1/README.md) 위에 앉은 모습을 보여 주고, 첫 룸에는 채린·수아·다희가 함께 나옵니다. 공부 화면과 기본 리포트에서는 [전신과 책상 레이어](src/assets/scenes/layered-v2/README.md)를 재사용합니다. **원본 포스터 / PNG 마스터 / 웹용 WebP / 투명 제목 이미지**를 분리했습니다. 메인화면 카드의 제목은 원본 서체를 참조한 [제목 이미지 9종](src/assets/room-titles/README.md)을 `RoomTitle`로 표시하고, 실제 이름은 대체 텍스트·검색·상세·기록에서 함께 사용합니다. [에셋 편집 가이드와 미리보기](src/assets/scenes/README.md), [배경/전경 생성 프롬프트](src/assets/scenes/generation-manifest.json), [제목 생성 프롬프트](src/assets/room-titles/generation-manifest.json)에서 교체 방법을 확인할 수 있습니다. `sceneArtwork`에 9종을 등록해 `RoomArtwork`와 Canvas 합성에서 같은 장면 ID로 사용할 수 있습니다.

로그인 히어로에는 랜딩페이지의 스터디룸 포스터 9종을 사용합니다. -10° 격자의 홀수 행은 오른쪽, 짝수 행은 왼쪽으로 흐릅니다. GSAP을 사용하는 [PosterMosaic](src/shared/ui/poster-mosaic/README.md)로 분리했으며, 포스터 목록과 이동 속도·회전은 `src/features/auth/posters.ts`와 컴포넌트 props에서 설정합니다. 모바일 상단 히어로, 일시정지·재생, 모션 감소 설정을 지원합니다.

데스크톱 좌우 영역은 **1.5:1(60%:40%)**이며, 좌측에는 포스터 격자를 보여 줍니다. 포스터는 `contain`으로 원본 이미지 전체를 표시합니다. 우측 폼은 가로·세로 중앙에 배치하며, 내용이 길면 우측 영역 안에서 스크롤합니다.

스터디룸은 **쌀쌀맞은 갸루짝꿍이 나에게만 친절하다! / 전교 1등을 이겨라 / 냥냥이가 날 그렇게 쳐다보면 집중할 수가 없잖아!! / 김상병의 두근두근 비밀연등 / 페보니우스 마법학교 / 모르는 일진이 나한테 말을 건다 / 쥬라기 독서실 / 뚝딱뚝딱 실험실 / 조선시대 야간 학습** 총 9종입니다. 새 6개 룸도 검색·저장·상세·공부·휴식 대화·리포트·캡슐 카드에 연결했습니다. 신규 친구 이름과 소개는 수정 가능한 더미 데이터이며, 전체 19명의 관계·선물·기록을 각 ID로 관리합니다.

기존 룸·친구 ID와 저장 데이터 형식을 유지하므로 기존 브라우저 데이터로도 9종을 바로 볼 수 있습니다. 새 룸의 누적 기록은 실제 데모 세션을 마친 뒤부터 쌓입니다. 개별 인물 화면은 원본 포스터의 표시 영역을 `CharacterArtwork`에서 재사용하고, 룸과 기본 리포트·캡슐 카드는 분리된 배경/전경 레이어를 사용합니다. 채린·수아·다희의 종료 화면과 카드는 새 완료 전용 이미지를 사용합니다.

홈의 첫 방문·이어하기 문구와 룸 목록으로 이동하는 동작은 [홈·기간별 기록 가이드](docs/HOME_AND_RECORDS.md)에 정리했습니다. 내 기록은 주·월·년 선택에 따라 요약·달력·친구 시간·최근 스터디를 함께 바꾸며, 중복 이용일 카드와 MVP에서 제외한 랭킹은 제거했습니다. 기본 닉네임은 `꾸윙젠렝`이며 기존 데모 데이터의 이름도 기록을 유지한 채 이전합니다.

## 구현 경계

실제 카메라·마이크 권한, 영상 미리보기, 마이크 입력 레벨과 MediaPipe Face Landmarker 추론을 연결했습니다. MVP는 MediaPipe만 사용하며 YOLO 기반 휴대폰 감지는 이후로 미뤘습니다. 준비 화면의 **카메라·마이크 켜기**를 눌러 확인하며, HTTPS 또는 localhost가 필요합니다. 마이크 권한이 없어도 카메라를 사용할 수 있고 카메라 없이 시작할 수도 있습니다. 준비→공부 화면 이동 중에는 같은 장치 연결을 유지하고, 종료·로그아웃·관련 화면 이탈 시 모든 트랙을 해제합니다. 재접속 후 권한 재획득은 사용자가 카메라 켜기를 눌렀을 때 수행합니다.

준비 화면에서 실제 영상으로 장치를 확인합니다. 공부·휴식 화면은 아바타를 기본으로 표시하며 독에서 실제 캠으로 전환할 수 있습니다. 카메라가 꺼진 상태에서 실제 캠 보기를 누르면 카메라 권한을 요청하고, 카메라를 끄면 아바타로 돌아갑니다. 아바타 보기로만 바꾸면 카메라 연결과 별도 숨김 영상의 얼굴 감지·집중률 측정은 유지합니다. 실제 캠은 같은 스트림을 음소거한 미리보기로 표시합니다. 준비 화면 제목 옆 물음표에서 카메라·마이크 권한의 목적과 로컬 처리·서버 미전송 안내를 확인합니다. 호버·키보드 초점·터치로 열고 Escape·외부 클릭으로 닫을 수 있습니다.

얼굴 감지는 사용자 기기의 GPU/CPU와 Web Worker에서 실행합니다. WebGL GPU 우선이며 추론 초기화가 실패하면 CPU/WASM으로 전환합니다. 최대 초당 5회 처리하며, 느린 기기에서는 다음 프레임을 대기해 추론이 겹치거나 쌓이지 않습니다. 일시정지·휴식·숨김 탭에서는 추론을 중단합니다. 영상은 메모리에서만 처리하며 서버 전송·녹화를 하지 않고, 마이크는 로컬 입력 확인에만 사용하며 녹음·음성 인식·재생에 연결하지 않습니다.

MediaPipe의 영상 입력에는 CPU 추론을 쓰더라도 WebGL이 필요합니다. WebGL 자체가 차단된 브라우저에서는 원인을 안내하며 카메라 없이 진행할 수 있습니다. 첫 실제 얼굴 추론이 완료된 뒤 카메라 확인의 다음 버튼이 활성화됩니다.

MVP 집중률은 **얼굴이 보인 시간 ÷ 정상 측정 시간**입니다. 얼굴이 감지되지 않은 유효 구간은 미감지 시간으로 누적해 집중률을 낮춥니다. 준비 화면, 모델 초기화·오류, 카메라 꺼짐, 일시정지, 휴식, 숨김 탭, 1초를 넘는 프레임 공백은 측정에서 제외합니다. 프레임 수가 아닌 시간으로 계산하고, 공부 중 집중률 표시·종료 리포트·내 기록에 같은 관측값을 사용합니다. 측정이 없는 새 세션은 `—`로 표시하며 더미 집중률을 생성하지 않습니다. 이전 샘플 기록은 유지합니다.

측정 누계는 초당 한 번 저장하고, 일시정지·카메라 끄기·종료 시 마지막 유효 구간을 반영합니다. 재접속 시 누계를 이어 가되 오프라인 구간을 추가하지 않습니다. OAuth·Live2D·LLM/TTS·결제·서버 저장과 자동 친구 반응은 후속 연결 대상이며 대화·관계 계산은 기존 샘플 규칙을 사용합니다.

공식 모델 파일·고정 버전·해시·라이선스는 [모델 문서](public/models/README.md)에 있습니다. `npm ci`/개발/빌드 시 설치한 패키지에서 로컬 WASM 실행 파일을 준비하므로 실행 중 외부 CDN에 의존하지 않습니다. 실제 청구가 없는 결제 흐름은 기존과 같습니다.

종료 화면은 룸 이름과 완료 시각·대화 옵션을 구분하고, 함께한 친구별 관계 증가를 표시합니다. 관계 바는 해당 공부 직전 값부터 증가분만 채우며 레벨 경계를 넘으면 링·빛·입자 효과 후 새 레벨 진행도로 이어집니다. 이후 기록은 과거 리포트의 관계 변화에 포함하지 않습니다. 채린·수아·다희는 [공부 완료 전용 이미지](src/assets/reports/completion-v1/README.md)를 생성했으며 리포트와 카드에서 함께한 친구를 선택해 볼 수 있습니다. 카드 미리보기와 저장 PNG에는 공식 로고와 홈용 투명 제목 이미지를 사용합니다.

캡슐 카드 미리보기는 `CapsuleCardSurface`에서 포인터를 따라 기울며 사진·로고·공부 시간을 서로 다른 깊이로 보여 줍니다. 홀로그램 반사와 미세한 반짝임을 더하고, 키보드 초점에서는 고정된 입체감을 제공합니다. 터치 화면과 움직임 줄이기 설정에서는 기울기를 생략합니다. 다음 공부 약속은 날짜·시간 휠에서 선택합니다.

캡슐 카드 PNG는 정중앙에 호버했을 때의 그라데이션·반짝임·빛 반사를 고정해 저장합니다. 마우스 위치나 터치·움직임 줄이기 설정에 관계없이 같은 색감을 사용합니다. 파일 공유를 지원하는 브라우저에서는 같은 PNG로 공유 창을 열고, 지원하지 않으면 이미지 저장으로 안내합니다. 복사한 데모 링크의 기록은 이 브라우저 안에만 있으므로 다른 기기와의 동기화는 지원하지 않습니다.

React + TypeScript(strict) + Vite + Tailwind CSS v4를 사용합니다. 공통 UI, 기능 모듈, 페이지와 더미 reducer를 분리했고 페이지는 지연 로딩합니다. 타입 검사·린트·빌드 및 타이머/원장/대화 한도 등의 상태 테스트를 실행할 수 있습니다.

## 참고

피그마는 읽기 전용으로 확인했습니다. 원본 프레임의 번호 핀과 메모는 기획 주석이므로 웹 UI에 포함하지 않았습니다. 화면 흐름은 유지하면서 `Landing_Page`의 로고·Pretendard 폰트·WebP 포스터·친구 일러스트를 재사용해 네이비와 라벤더 중심의 디자인을 적용했습니다. Figma 원본과 랜딩페이지 파일은 수정하지 않았습니다. 에셋 출처와 매핑은 [에셋 문서](src/assets/README.md)에 정리했습니다.

BrowserRouter를 사용하므로 배포 서버에서는 `/rooms/dawn-library` 같은 URL도 `index.html`로 연결하는 SPA fallback이 필요합니다. Cloudflare Workers용 `wrangler.jsonc`에 이 동작과 빌드 결과 경로를 설정했습니다.

### Cloudflare Workers 배포

Git 저장소 루트가 이 디렉터리인 Workers 프로젝트의 설정입니다. 배포할 브랜치에도 `wrangler.jsonc`가 포함되어 있어야 합니다.

| 항목 | Production | Preview |
| --- | --- | --- |
| 브랜치 | `main` | `dev` 등 Production 외 브랜치 |
| Build command | `npm run build` | `npm run build` |
| Deployment / Preview command | `npx wrangler deploy` | `npx wrangler preview` |
| Root directory | `/` | `/` |

`wrangler.jsonc`는 `dist`의 정적 파일을 배포하며, `previews` 설정을 선언해 브랜치별 Preview를 지원합니다. Preview 이름은 현재 Git 브랜치에서 정해지므로 `--name dev`를 공통 Preview 명령에 고정하지 않습니다. 기존 Production 명령의 `--assets ./dist --name capsule-front-web --compatibility-date 2026-10-23` 옵션도 파일의 설정과 같아 유지할 수 있습니다.

`dev`의 **Tracking branch**와 **Preview builds**를 확인한 뒤 변경 사항을 `dev`에 push합니다. 해당 Preview의 **Deployments**에서 최신 커밋의 성공 여부와 실제 URL을 확인하세요. Preview 토글을 켜거나 URL을 활성화한 것만으로 배포가 성공한 것은 아닙니다. 공개 배포에는 Cloudflare Access 설정이 필요하지 않습니다.

설정 참고: [Vite](https://vite.dev/guide/), [Tailwind Vite 설치](https://tailwindcss.com/docs/installation/using-vite), [React Router 설치](https://reactrouter.com/start/declarative/installation). 사용 중인 외부 코드·라이브러리의 상업 이용 검토는 [REFERENCE_COMMERCIAL_USE.md](docs/REFERENCE_COMMERCIAL_USE.md)에 기록합니다.


홈 북마크와 가입·충전 동의 체크박스에는 자체 모션을 적용했습니다. 충전 동의는 회원가입과 같은 `AnimatedCheckbox`를 사용합니다. 마이페이지 일정은 왼쪽의 연·월 선택 달력과 오른쪽 목록·편집 기능으로 구성하며, 일정 표시와 날짜별 조회를 연결했습니다. 기록은 일별 공부 시간 히트맵과 숫자/호가 동기화되는 집중률 링으로 표시합니다. 공부 시작 시 목표 시간을 고르면 타이머·일시정지·재접속·종료 기록까지 이어집니다. [컨트롤·목표 시간 가이드](docs/INTERACTIONS_AND_STUDY_GOALS.md), [상업 이용과 배포 고지](docs/THIRD_PARTY_NOTICES.md)를 확인할 수 있습니다.

친구별 함께한 시간은 선택한 기간의 누적 시간을 비교하는 SVG 라인차트로 표시하고, 날짜에 호버하면 당일·월별 시간과 누적 시간을 구분해 보여 줍니다. 왼쪽 카드에는 기간별 공부 시간·횟수·친구 수·집중률과 최근 스터디를 묶고, 오른쪽 카드에는 달력과 선택한 날짜의 상세를 묶었습니다. 날짜 선택 상태는 달력 컴포넌트에서 관리하며, 최근 스터디의 종료 상태 배지는 제거했습니다. 누적 시간 차트는 하단 전체 너비를 사용합니다. 공통 토글은 선택 배경이 슬라이딩합니다. 친구와 날짜·주·월·년에 따라 공부 시간과 집중률이 달라지는 연중 샘플을 사용하며, 기존 실제 공부 기록은 유지한 채 구형 샘플만 자동으로 이전합니다. 북마크 우측 하단 알림과 내 기록 패널·날짜 툴팁의 외곽선은 제거했습니다.

룸 상세에는 인물과 좌석·배경을 함께 생성한 [완성형 배너 9종](src/assets/room-detail-banners/README.md)을 사용합니다. 제목·소개는 HTML로 수정할 수 있으며, 생성 PNG·WebP·전체 프롬프트를 보관합니다. 도윤·모루·민하준·유리는 룸 상세의 친구 카드와 친구 프로필에서 얼굴 크롭을 공유하며, 프로필에는 별도의 책상 레이어를 표시하지 않습니다. 친구 소개는 해시태그로 표시하고 다음 관계 단계까지의 시간은 관계 막대에 호버하거나 포커스하면 보여 줍니다. 공통 토글 외곽선과 PREVIEW 표시는 제거했습니다.
