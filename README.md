# CAPSULE Web

AI 캐릭터와 함께 공부하는 CAPSULE의 프런트엔드 데모입니다. 백엔드 없이 더미 계정·기록·크레딧으로 전체 화면 흐름을 체험할 수 있습니다. `Front_Web` 안에서 독립적으로 실행하며, 옆의 `Landing_Page`와 의존성·설정을 공유하지 않습니다.

## 실행

Node.js 22 LTS(22.13 이상) 또는 24 이상이 필요합니다. `.nvmrc`는 Node 22를 기준으로 합니다.

```bash
cd Front_Web
npm ci
npm run dev
```

Vite가 출력하는 로컬 주소에서 확인합니다.

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run preview
```

## 화면 흐름

```text
더미 로그인 → 내 아바타 → 홈 → 스터디룸 상세
  → 카메라 확인 → 목표 시간·대화 옵션 선택 → 공부 → 휴식·대화
  → 종료 리포트 → 캡슐 카드·다음 약속 → 홈
```

| 경로 | 화면과 동작 |
|---|---|
| `/login` | 카카오·더미 계정 시작 화면. 로그인/회원가입 링크로 우측 전체 폼 전환. 회원가입은 약관 2개 필수 동의 및 전문 보기 (`?mode=login`, `?mode=signup`) |
| `/onboarding` | 이름과 헤어·의상·외모·배경의 샘플 옵션 선택 |
| `/mypage` | 닉네임·아바타 편집, 모든 캐릭터의 일정 조회·추가·수정·삭제 |
| `/` | 첫 방문/이어하기 홈, 룸 탐색·저장, 진행 중인 세션 복귀 |
| `/rooms/:roomId` | 룸 설명과 캐릭터 관계, 공부 시작 |
| `/rooms/:roomId/prepare` | 카메라 확인 → `?step=goal`에서 목표 시간·대화 옵션 선택, 일정은 마이페이지에서 추가 후 복귀 |
| `/study/:sessionId` | 1:1/1:3 공부, 포커스 보기, 타이머·일시정지·채팅·휴식·등급 변경 |
| `/reports/:recordId` | 집중·딴짓·복귀·관계 변화의 샘플 결과 |
| `/capsules/:recordId` | 카드 색·PNG 저장·공유·다음 공부 약속 |
| `/records` | 전체/스터디룸별 시간·이용일·최근 세션 |
| `/characters/:characterId` | 관계·해금 콘텐츠, 해당 캐릭터로 필터된 마이페이지 일정으로 이동 |
| `/characters/:characterId/shop` | 선물/보이스 필터·미리보기·더미 구매·보관함 |
| `/credits` | 잔액·패스·원장 필터·샘플 영수증 |
| `/credits/charge` | 상품/결제 수단/동의 선택 → 명시적 데모 결제 확인 |

`/characters`는 기본 캐릭터 채린의 관계 화면으로 열립니다. 없는 룸·캐릭터·기록은 찾을 수 없음으로 처리합니다.

## 빠르게 체험하기

1. 카카오로 계속하기 → 아바타 설정을 완료하거나, **더미 계정으로 바로 둘러보기**를 누릅니다.
2. 쌀쌀맞은 갸루짝꿍이 나에게만 친절하다! → 공부 시작 → 카메라 확인 → 원하는 세트를 선택합니다.
3. 공부 화면의 **데모 조작 → 휴식 화면 보기**를 누르면 50분을 기다리지 않고 휴식을 볼 수 있습니다. 시작 타이머는 와이어프레임처럼 47:12, 휴식 미리보기는 07:42부터 표시합니다.
4. 쉬는 시간에 프리미엄으로 올리면 이미 낸 200을 제외한 300만 차감됩니다. 베이직의 3턴 한도는 캐릭터·공부/휴식 화면 전체에서 공유하며, 서울 기준 새벽 5시에 갱신합니다.
5. 종료 후 캡슐 카드 이미지를 저장하거나 다음 공부 약속을 추가합니다. 크레딧 충전·선물·패스도 더미 상태로 연결됩니다.

프로필 메뉴의 **마이페이지**에서 닉네임·아바타와 캐릭터별 시험·목표·약속을 한곳에서 관리합니다. 모든 캐릭터의 일정을 날짜순으로 모으고 예정/전체/지난 일정·캐릭터 필터를 제공합니다. 기존 일정과 캐릭터 연결은 그대로 유지합니다. 프로필 메뉴에서 **첫 방문 홈 보기**, 로그아웃, **데모 초기화**도 할 수 있습니다. 사용자 데이터는 `localStorage`의 `capsule-wireframe-demo:v1`에 저장됩니다. 저장을 사용할 수 없으면 메모리로 동작하며, 새로고침하면 초기화될 수 있음을 화면에 안내합니다.

## 디자인

홈의 캐릭터 환영 장면, 포스터형 스터디룸 카드, 일러스트 기반 공부·휴식 화면, 캐릭터 관계·선물·기록·크레딧 화면을 같은 색상·컨트롤로 연결했습니다. 룸/캐릭터 검색·저장 필터·SVG 아바타 미리보기를 지원하고, 캡슐 카드의 실제 PNG에도 캐릭터 그림이 들어갑니다.

- 색상·폰트·간격: `src/styles/index.css`의 Tailwind `@theme`
- 공통 UI: `src/shared/ui`의 `Brand`, `Icon`, `AvatarIllustration`, `Button`, `Panel` 등
- 캐릭터 그림·표정·인물별 표시 영역: `src/features/characters/artwork.ts` / 공통 렌더링: `CharacterArtwork`
- 룸 문구·캐릭터 구성: `src/features/rooms/data/rooms.ts` / 원본 포스터: `src/features/rooms/posters.ts` / 이미지 결합: `services/room-service.ts`
- 룸 장면의 배경·캐릭터·책상·제목: `src/features/rooms/artwork.ts` / `src/styles/scenes.css`
- 탐색·기록·공통 피드백 스타일: `src/styles/interactions.css`
- 상세 가이드: [디자인 시스템](docs/DESIGN_SYSTEM.md)

참고 사이트의 기존 조사로 활동 달력·집중률 링·공통 로딩·조용히 집중 모드를 추가했습니다. 현재 52곳을 재조사한 뒤 메인 히어로의 큰 슬로건과 소개는 방문 상태별로 바꾸고, 우측 하단 대사를 초상화·이름·꼬리 없는 글래스모피즘 형태로 정리했습니다. 확인 범위·접근 오류·적용 판단은 [52곳 재조사 기록](docs/WELCOME_HERO_RESEARCH.md)에 있습니다. 재사용 컴포넌트는 `CompanionGreeting`, 전용 스타일은 `src/styles/welcome.css`입니다. 현재 메인 배너는 [호버 지우기 전환](src/shared/ui/hover-scratch/README.md)을 사용합니다. [채린·수아·다희 전용 가로 이미지](src/assets/welcome-banners/README.md)를 생성했으며, 현재 이미지와 HTML 대사는 하나의 마스크로 함께 지워집니다. 마우스가 지나간 자리에 다음 이미지와 다음 대사가 보이고 면적 40%가 지워지면 나머지를 정리한 뒤 다음 이미지로 순환합니다. 첫 방문·이어하기 문구와 버튼은 HTML로 관리합니다. 모바일·터치·모션 감소에서는 캐릭터 선택 버튼으로 전환합니다. 이전 하프톤 시안은 현재 화면에서 연결을 해제했습니다.

기존 포스터의 잘림을 줄이기 위해 9종 모두 이미지 생성으로 전신 캐릭터/그룹과 독립 배경을 만들었습니다. 메인화면은 [책상 없는 바닥 배경 9종](src/assets/scenes/seated-v1/README.md) 위에 앉은 모습을 보여 주고, 첫 룸에는 채린·수아·다희가 함께 나옵니다. 공부·리포트에서는 [전신과 책상 레이어](src/assets/scenes/layered-v2/README.md)를 재사용합니다. **원본 포스터 / PNG 마스터 / 웹용 WebP / 투명 제목 이미지**를 분리했습니다. 메인화면 카드의 제목은 원본 서체를 참조한 [제목 이미지 9종](src/assets/room-titles/README.md)을 `RoomTitle`로 표시하고, 실제 이름은 대체 텍스트·검색·상세·기록에서 함께 사용합니다. [에셋 편집 가이드와 미리보기](src/assets/scenes/README.md), [배경/전경 생성 프롬프트](src/assets/scenes/generation-manifest.json), [제목 생성 프롬프트](src/assets/room-titles/generation-manifest.json)에서 교체 방법을 확인할 수 있습니다. `sceneArtwork`에 9종을 등록해 `RoomArtwork`와 Canvas 합성에서 같은 장면 ID로 사용할 수 있습니다.

로그인 히어로에는 랜딩페이지의 스터디룸 포스터 9종을 사용합니다. -10° 격자의 홀수 행은 오른쪽, 짝수 행은 왼쪽으로 흐릅니다. GSAP을 사용하는 [PosterMosaic](src/shared/ui/poster-mosaic/README.md)로 분리했으며, 포스터 목록과 이동 속도·회전은 `src/features/auth/posters.ts`와 컴포넌트 props에서 설정합니다. 모바일 상단 히어로, 일시정지·재생, 모션 감소 설정을 지원합니다.

데스크톱 좌우 영역은 **1.5:1(60%:40%)**이며, 좌측에는 포스터 격자를 보여 줍니다. 포스터는 `contain`으로 원본 이미지 전체를 표시합니다. 우측 폼은 가로·세로 중앙에 배치하며, 내용이 길면 우측 영역 안에서 스크롤합니다.

스터디룸은 **쌀쌀맞은 갸루짝꿍이 나에게만 친절하다! / 전교 1등을 이겨라 / 냥냥이가 날 그렇게 쳐다보면 집중할 수가 없잖아!! / 김상병의 두근두근 비밀연등 / 페보니우스 마법학교 / 모르는 일진이 나한테 말을 건다 / 쥬라기 독서실 / 뚝딱뚝딱 실험실 / 조선시대 야간 학습** 총 9종입니다. 새 6개 룸도 검색·저장·상세·공부·휴식 대화·리포트·캡슐 카드에 연결했습니다. 신규 캐릭터 이름과 소개는 수정 가능한 더미 데이터이며, 전체 19명의 관계·선물·기록을 각 ID로 관리합니다.

기존 룸·캐릭터 ID와 저장 데이터 형식을 유지하므로 기존 브라우저 데이터로도 9종을 바로 볼 수 있습니다. 새 룸의 누적 기록은 실제 데모 세션을 마친 뒤부터 쌓입니다. 개별 인물 화면은 원본 포스터의 표시 영역을 `CharacterArtwork`에서 재사용하고, 룸·리포트·캡슐 카드는 분리된 배경/전경 레이어를 사용합니다.

홈의 첫 방문·이어하기 문구와 룸 목록으로 이동하는 동작은 [홈·기간별 기록 가이드](docs/HOME_AND_RECORDS.md)에 정리했습니다. 내 기록은 주·월·년 선택에 따라 요약·달력·캐릭터 시간·최근 스터디를 함께 바꾸며, 중복 이용일 카드와 MVP에서 제외한 랭킹은 제거했습니다. 기본 닉네임은 `꾸윙젠렝`이며 기존 데모 데이터의 이름도 기록을 유지한 채 이전합니다.

## 구현 경계

실제 OAuth·카메라 촬영·행동 감지·Live2D·LLM/TTS·결제·서버 저장은 연결하지 않았습니다. 카메라는 아바타가 있는 샘플 미리보기, 대화는 준비된 답변, 음성은 샘플 텍스트로 보여 줍니다. 결제에는 카드 정보를 받지 않으며 실제 청구가 없습니다. 관계·집중 리포트는 더미 계산 규칙입니다.

캡슐 카드 PNG는 실제로 저장할 수 있습니다. 파일 공유를 지원하는 브라우저에서는 공유 창을 열고, 지원하지 않으면 이미지 저장으로 안내합니다. 복사한 데모 링크의 기록은 이 브라우저 안에만 있으므로 다른 기기와의 동기화는 지원하지 않습니다.

React + TypeScript(strict) + Vite + Tailwind CSS v4를 사용합니다. 공통 UI, 기능 모듈, 페이지와 더미 reducer를 분리했고 페이지는 지연 로딩합니다. 타입 검사·린트·빌드 및 타이머/원장/대화 한도 등의 상태 테스트를 실행할 수 있습니다.

## 참고

피그마는 읽기 전용으로 확인했습니다. 원본 프레임의 번호 핀과 메모는 기획 주석이므로 웹 UI에 포함하지 않았습니다. 화면 흐름은 유지하면서 `Landing_Page`의 로고·Pretendard 폰트·WebP 포스터·캐릭터 일러스트를 재사용해 네이비와 라벤더 중심의 디자인을 적용했습니다. Figma 원본과 랜딩페이지 파일은 수정하지 않았습니다. 에셋 출처와 매핑은 [에셋 문서](src/assets/README.md)에 정리했습니다.

BrowserRouter를 사용하므로 배포 서버에서는 `/rooms/dawn-library` 같은 URL도 `index.html`로 연결하는 SPA fallback이 필요합니다. 실제 배포는 수행하지 않았습니다.

설정 참고: [Vite](https://vite.dev/guide/), [Tailwind Vite 설치](https://tailwindcss.com/docs/installation/using-vite), [React Router 설치](https://reactrouter.com/start/declarative/installation).


홈 북마크와 가입 체크박스에는 자체 모션을 적용했습니다. 기록은 일별 공부 시간 히트맵과 숫자/호가 동기화되는 집중률 링으로 표시합니다. 공부 시작 시 목표 시간을 고르면 타이머·일시정지·재접속·종료 기록까지 이어집니다. [컨트롤·목표 시간 가이드](docs/INTERACTIONS_AND_STUDY_GOALS.md), [상업 이용과 배포 고지](THIRD_PARTY_NOTICES.md)를 확인할 수 있습니다.

캐릭터별 함께한 시간은 선택한 기간의 누적 시간을 비교하는 SVG 라인차트로 표시하고, 날짜에 호버하면 당일·월별 시간과 누적 시간을 구분해 보여 줍니다. 왼쪽 카드에는 공부 시간·횟수·친구 수와 달력을 합쳤으며, 선택한 날짜의 상세는 상단에서 세로선으로 구분합니다. 오른쪽에는 큰 집중률 링과 최근 스터디를 쌓고 누적 시간 차트는 하단 전체 너비를 사용합니다. 공통 토글은 선택 배경이 슬라이딩합니다. 캐릭터와 날짜·주·월·년에 따라 공부 시간과 집중률이 달라지는 연중 샘플을 사용하며, 기존 실제 공부 기록은 유지한 채 구형 샘플만 자동으로 이전합니다. 북마크 우측 하단 알림과 내 기록 패널·날짜 툴팁의 외곽선은 제거했습니다.

룸 상세에는 인물과 좌석·배경을 함께 생성한 [완성형 배너 9종](src/assets/room-detail-banners/README.md)을 사용합니다. 제목·소개는 HTML로 수정할 수 있으며, 생성 PNG·WebP·전체 프롬프트를 보관합니다. 친구 카드의 도윤·모루·하준·유리는 카드 전용 얼굴 크롭을 사용하고 공통 토글 외곽선과 PREVIEW 표시는 제거했습니다.
