# CAPSULE Web

AI 친구와 함께 공부하는 CAPSULE의 프런트엔드입니다. Railway 백엔드의 인증·홈·프로필·일정·공부 세션 API를 사용합니다. `Front_Web` 안에서 독립적으로 실행하며, 옆의 `Landing_Page`와 의존성·설정을 공유하지 않습니다.

## 현재 API 연동

- 실제 이메일 인증·회원가입·로그인·로그아웃과 쿠키 기반 토큰 갱신을 사용합니다. 기존 localStorage의 더미 계정·기록·크레딧은 앱 상태로 읽지 않습니다.
- 서버 룸·친구 ID로 3분 MVP 공부를 시작하고, `FOCUS/AWAY/RETURN/BREAK`, 1분 heartbeat, 메시지·리포트·일정을 연결합니다. 자리 비움은 서버 계약의 연속 10초 기준이며, 자리 지킴률은 자리 지킴 시간 ÷ 공부 시간입니다.
- 카카오 로그인은 `.env.local`의 `VITE_KAKAO_REST_API_KEY`, `VITE_KAKAO_REDIRECT_URI`를 설정하고 같은 URI를 카카오 개발자 콘솔에 등록합니다. 현재 callback 경로는 `/oauth/kakao`입니다. 배포 환경에도 각각 값을 설정합니다.
- 로컬 개발·미리보기는 `http://localhost:3000`을 사용합니다. 추가 제공 자료의 등록 URI에 맞춰 `VITE_KAKAO_REDIRECT_URI=http://localhost:3000/oauth/kakao`로 설정합니다. [카카오·재설정 후속 반영](docs/KAKAO_LOGIN_REVIEW_2026-11-05.md)을 참고하세요.
- 브라우저는 동일 출처 `/api/backend/*`를 사용하며 Vite 개발/미리보기 또는 Cloudflare Worker가 Railway의 `/api/*`로 전달합니다. `BACKEND_API_ORIGIN`은 서버 설정입니다.
- 연결 상태·실제 검증 범위·대기 기능은 [API 연동 기록](docs/API_INTEGRATION_2026-11-05.md)에 정리했습니다. 아래의 기존 시연 안내에는 API 연결 전 데모 동작과 이전 UI 검토 이력이 포함됩니다.

## 현재 MVP 시연 범위

- `쌀쌀맞은 갸루짝꿍이 나에게만 친절하다!` 룸의 채린만 함께 공부하고 대화할 수 있습니다. 나머지 8개 룸과 상세 화면의 수아·다희 친구 카드는 블러 및 `MVP 이후`로 표시합니다. 홈 환영 배너 3종, 갸루짝꿍 홈 카드의 그림·초상화, 룸 상세 배너는 원래 모습으로 유지합니다.
- 준비 화면의 대화 옵션은 블러 처리하고 선택을 막습니다. 크레딧 차감과 무료 대화 횟수 제한 없이 시작합니다.
- 목표 시간 슬라이더는 조작할 수 있지만, 표시하는 시연 목표와 실제 세션·리포트의 목표는 항상 **3분(180초)**입니다. 목표에 도달해도 공부를 계속하며, 사용자가 **쉬는 시간**을 눌러야 휴식을 시작합니다. 초과 공부 시간도 타이머·집중률·종료 리포트에 반영합니다.
- 내 기록·친구·선물/보이스·내 크레딧·충전은 진입 요소를 비활성화하고 직접 주소로도 차단합니다. 마이페이지, 일정, 종료 리포트와 캡슐 카드는 유지합니다.
- 정책은 `src/features/mvp/`에서 관리합니다. 이전 완료 기록은 보존하고, 저장된 진행 세션만 MVP 범위로 맞춥니다.

아래의 전체 기능 설명에는 MVP 이후에 제공할 기존 프로토타입 화면도 포함되어 있습니다.

## 공부 레벨과 호감도

두 값은 서로 독립적입니다. 공부 레벨은 친구와 함께 공부한 시간으로 올라가는 **Lv.1~5**이며, 호감도는 상호작용에 따라 오르거나 내려가는 **0~100** 값입니다. 공부 시간·선물 개수·메시지 수에서 호감도를 계산하지 않습니다.

호감도의 초기값과 상호작용별 증감 기준은 백엔드에서 결정합니다. 프런트의 `affection`은 친구 ID별 확정 점수만 보관하며, 데이터가 없는 친구는 `— / 100`으로 표시합니다. `SET_AFFECTION`은 서버에서 확정한 점수를 반영하는 경계이며, 자동으로 점수를 적립하는 프런트 규칙은 없습니다. 기존 저장 데이터도 기록·프로필을 유지한 채 이 상태를 추가합니다.

레벨의 현재 600분 단위·그룹 참여 시간 배분은 기존 데모 규칙을 유지합니다. 최종 성장 기준은 백엔드 연동 시 확정합니다. 종료 리포트의 레벨 진행은 해당 세션 종료 시점 기준이며, 별도의 `현재 호감도`는 최신 확정값입니다. 호감도 변화 이력을 받기 전에는 리포트에 세션별 증감값을 만들지 않습니다.

리포트와 MVP 이후 친구·선물/보이스 화면은 같은 지표를 공유합니다. 제품 아이콘은 앞으로도 [AnimateIcons Lucide](https://animateicons.in/icons/lucide)에서 찾아 공통 `Icon`으로 적용합니다. [공식 소스·선택 기준](src/shared/ui/animate-icons/README.md)을 따릅니다. 리포트 수치는 [Tween UI Number Counter](src/shared/ui/number-counter/README.md)로 각 자릿수가 한 번 위로 회전하며, 숫자·단위의 기준선과 줄 높이를 맞춥니다. 날짜·Lv 단계와 미정값은 유지합니다. Arcade Pixel은 사용자 요청으로 제거했습니다. 캡슐 카드 버튼의 반복 빛 강조를 유지하고, 모션 감소에서는 정적으로 표시합니다. 리포트 상단의 룸명·완료 시각·집중률은 우측에 묶으며 공부 시간은 제목 아래에 표시합니다.

## 실행

Node.js 22 LTS(22.13 이상) 또는 24 이상이 필요합니다. `.nvmrc`는 Node 22를 기준으로 합니다.

```bash
cd Front_Web
npm ci
npm run dev
```

Vite가 출력하는 로컬 주소에서 확인합니다.

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run preview
```

## 화면 흐름

```text
더미 로그인 → 내 아바타 → 홈 → 스터디룸 상세
  → 목표 시간 화면(시연 3분 고정) → 채린과 공부·대화 → 휴식
  → 종료 리포트 → 캡슐 카드·다음 약속 → 홈
```

| 경로 | 화면과 동작 |
|---|---|
| `/login` | 카카오·더미 계정 시작 화면. 로그인/회원가입 링크로 우측 전체 폼 전환. 회원가입은 비밀번호 확인 아래 닉네임 필수 입력(20자 이내), 약관 2개 필수 동의 및 전문 보기 (`?mode=login`, `?mode=signup`). 로그인 폼의 비밀번호 찾기는 이메일 입력 화면(`?mode=forgot-password`)으로 이동하며, 실제 재설정 메일 발송은 인증 API 연결 후 제공 |
| `/onboarding` | 헤어·의상·외모·배경의 샘플 옵션 선택. 회원가입에서 입력한 닉네임 유지 |
| `/mypage` | 제목 옆 프로필·아바타 / 달력·일정 아이콘 토글. 기본은 프로필 편집이며 `#schedule`은 달력·일정. 화면 전환 중 미저장 프로필과 달력 선택 상태 유지 |
| `/` | 첫 방문/이어하기 홈, 룸 탐색·저장, 진행 중인 세션 복귀 |
| `/rooms/:roomId` | 룸 설명과 친구 관계, 공부 시작 |
| `/rooms/:roomId/prepare` | 실제 카메라·마이크 권한 및 로컬 얼굴 감지 확인, 캠 배경 선택(기본·블러·이미지 3종, 미리보기에 즉시 반영) → `?step=goal`에서 목표 시간·대화 옵션 선택 |
| `/study/:sessionId` | 1:1/1:3 공부, 포커스 보기, 타이머·일시정지·채팅·휴식·등급 변경, 하단 메뉴 **배경 바꾸기**로 캠 배경 변경(준비 화면 선택 유지) |
| `/reports/:recordId` | 전체 화면 완료 장면 위 좌측 채린·한마디, 우측 유리 패널의 공부 시간·집중률·자리 비움·복귀·공부 레벨 진행·현재 호감도. 모바일은 인물·대사·결과를 세로 배치 |
| `/capsules/:recordId` | 카드 색·PNG 저장·공유·날짜/시간 휠로 다음 공부 약속 |
| `/records` | 전체/스터디룸별 시간·이용일·최근 세션, 이전/다음 주·월 탐색 |
| `/characters/:characterId` | 친구별 관계·해금 콘텐츠·선물·공부 시작 |
| `/characters/:characterId/shop` | 선물/보이스 필터·미리보기·더미 구매·보관함 |
| `/credits` | 잔액·패스·통합 충전/사용/보너스 내역·샘플 영수증, 우측 상단 충전 버튼 |
| `/credits/charge` | 패스/크레딧 토글 가격표 → 결제 오버레이 → 완료 영수증 출력·떼기·재출력 |

`/characters`는 기본 친구 채린의 관계 화면으로 열립니다. 없는 룸·친구·기록은 찾을 수 없음으로 처리합니다.

## 빠르게 체험하기

1. 카카오로 계속하기 → 아바타 설정을 완료하거나, **가입 없이 둘러보기**를 누릅니다.
2. 쌀쌀맞은 갸루짝꿍이 나에게만 친절하다! → 공부 시작 → 카메라 확인 → 대화 옵션을 선택합니다.
3. 공부 화면의 **데모 조작 → 휴식 화면 보기**를 누르면 목표 시간을 기다리지 않고 휴식을 볼 수 있습니다. 공부 타이머는 `경과 시간 / 목표 시간`으로 표시하며 0초부터 늘어납니다. 휴식 미리보기는 07:42부터 줄어듭니다.
4. MVP 시연은 무료이며 대화 횟수 제한이 없습니다. 등급 올리기·크레딧 기능은 MVP 이후에 제공합니다.
5. 종료 후 캡슐 카드 이미지를 저장하거나 다음 공부 약속을 추가합니다. 크레딧 충전·선물·패스도 더미 상태로 연결됩니다.

프로필 메뉴의 **마이페이지**에서 제목과 같은 행의 프로필·아바타 / 달력·일정 아이콘 토글로 편집 영역을 전환합니다. 화면 전환 중 미저장 프로필과 달력의 월·기간·날짜 선택은 유지합니다. 일정은 모든 친구가 함께 기억하는 공통 목록이며 예정/전체/지난 기간으로 조회합니다. 일정마다 친구를 지정하지 않으며, 기존 친구별 일정도 내용과 날짜를 보존해 공통 일정으로 이전합니다. 친구 화면에는 개별 일정 영역을 표시하지 않습니다. 프로필 메뉴에서 **첫 방문 화면 보기**, 로그아웃, **체험 기록 초기화**도 할 수 있습니다. 사용자 데이터는 `localStorage`의 `capsule-wireframe-demo:v1`에 저장됩니다. 저장을 사용할 수 없으면 메모리로 동작하며, 새로고침하면 초기화될 수 있음을 화면에 안내합니다.

공부 화면의 **확대 모드(V)**에서는 친구 카드를 눌러 크게 보기·원래 보기로 전환합니다. **말 걸기 모드(C)**나 헤더 대화 버튼은 오른쪽 공통 채팅 패널을 엽니다. 친구 토글로 상대를 바꾸면 각 대화 이력·입력 중인 내용을 유지하며 영상의 확대 상태는 바뀌지 않습니다. 넓은 화면은 사이드바, 1023px 이하는 배경 스크롤을 막는 드로어로 표시합니다. 공부·휴식에서 같은 패널을 사용하며 새 답장만 타이핑하고 이전 이력은 즉시 표시합니다. 입력창은 입력 시 확장되며 Enter로 전송, Shift+Enter로 줄바꿈합니다. 한글 조합 중 Enter는 전송하지 않습니다. 영상 위 유리 독에서 마이크·카메라·아바타/실제 캠·일시정지·계속·종료를 조작하며 데모 메뉴는 룸 제목 오른쪽에 있습니다. 헤더 시간은 `00:17:23 / 00:50:00` 형식이고 바뀐 숫자만 움직입니다. 집중률은 50% 미만 빨강, 50~80% 미만 흰색, 80% 이상 초록이며 미측정은 `—`입니다. 움직임 줄이기 설정에서는 패널·타이핑·숫자 효과를 생략합니다.

## 디자인

홈의 친구 환영 장면, 포스터형 스터디룸 카드, 일러스트 기반 공부·휴식 화면, 친구 관계·선물·기록·크레딧 화면을 같은 색상·컨트롤로 연결했습니다. 룸/친구 검색·저장 필터·SVG 아바타 미리보기를 지원하고, 캡슐 카드의 실제 PNG에도 친구 그림이 들어갑니다.

- 색상·폰트·글자 역할: `docs/DESIGN_TOKENS.json` → `npm run tokens:sync` → `src/styles/design-tokens.css` / 런타임 `src/shared/design/tokens.ts`
- 공통 UI: `src/shared/ui`의 `Brand`, `Icon`, `AvatarIllustration`, `Button`, `Panel` 등
- 친구 그림·표정·인물별 표시 영역: `src/features/characters/artwork.ts` / 공통 렌더링: `CharacterArtwork`
- 룸 문구·친구 구성: `src/features/rooms/data/rooms.ts` / 원본 포스터: `src/features/rooms/posters.ts` / 이미지 결합: `services/room-service.ts`
- 룸 장면의 배경·친구·책상·제목: `src/features/rooms/artwork.ts` / `src/styles/scenes.css`
- 탐색·기록·공통 피드백 스타일: `src/styles/interactions.css`
- 적용된 기준: [통합 디자인 기준](docs/DESIGN_SYSTEM.md) · [토큰 정의](docs/DESIGN_TOKENS.json). Front_Web 앱 전체에 반영했고, Landing_Page는 적용 대상에서 제외합니다. 적용 범위·예외·검증은 디자인 문서 12장에 기록했습니다. `npm run tokens:check`로 생성물과 정적 대비를 검사합니다.

참고 사이트의 기존 조사로 활동 달력·집중률 링·공통 로딩을 추가했습니다. 조용히 집중 버튼과 전용 상태는 후속 사용자 요청으로 제거했습니다. 현재 52곳을 재조사한 뒤 메인 히어로의 큰 슬로건과 소개는 방문 상태별로 바꾸고, 우측 하단 대사를 초상화·이름·꼬리 없는 글래스모피즘 형태로 정리했습니다. 확인 범위·접근 오류·적용 판단은 [52곳 재조사 기록](docs/WELCOME_HERO_RESEARCH.md)에 있습니다. 재사용 컴포넌트는 `CompanionGreeting`, 전용 스타일은 `src/styles/welcome.css`입니다. 현재 메인 배너는 [호버 지우기 전환](src/shared/ui/hover-scratch/README.md)을 사용합니다. [채린·수아·다희 전용 가로 이미지](src/assets/welcome-banners/README.md)를 생성했으며, 현재 이미지와 HTML 대사는 하나의 마스크로 함께 지워집니다. 마우스가 지나간 자리에 다음 이미지와 다음 대사가 보이고 면적 40%가 지워지면 나머지를 정리한 뒤 다음 이미지로 순환합니다. 첫 방문·이어하기 문구와 버튼은 HTML로 관리합니다. 모바일·터치·모션 감소에서는 친구 선택 버튼으로 전환합니다. 이전 하프톤 시안은 현재 화면에서 연결을 해제했습니다.

기존 포스터의 잘림을 줄이기 위해 9종 모두 이미지 생성으로 전신 친구/그룹과 독립 배경을 만들었습니다. 메인화면은 [책상 없는 바닥 배경 9종](src/assets/scenes/seated-v1/README.md) 위에 앉은 모습을 보여 주고, 첫 룸에는 채린·수아·다희가 함께 나옵니다. 공부 화면과 기본 리포트에서는 [전신과 책상 레이어](src/assets/scenes/layered-v2/README.md)를 재사용합니다. **원본 포스터 / PNG 마스터 / 웹용 WebP / 투명 제목 이미지**를 분리했습니다. 메인화면 카드의 제목은 원본 서체를 참조한 [제목 이미지 9종](src/assets/room-titles/README.md)을 `RoomTitle`로 표시하고, 실제 이름은 대체 텍스트·검색·상세·기록에서 함께 사용합니다. [에셋 편집 가이드와 미리보기](src/assets/scenes/README.md), [배경/전경 생성 프롬프트](src/assets/scenes/generation-manifest.json), [제목 생성 프롬프트](src/assets/room-titles/generation-manifest.json)에서 교체 방법을 확인할 수 있습니다. `sceneArtwork`에 9종을 등록해 `RoomArtwork`와 Canvas 합성에서 같은 장면 ID로 사용할 수 있습니다.

로그인 히어로에는 랜딩페이지의 스터디룸 포스터 9종을 사용합니다. -10° 격자의 홀수 행은 오른쪽, 짝수 행은 왼쪽으로 흐릅니다. GSAP을 사용하는 [PosterMosaic](src/shared/ui/poster-mosaic/README.md)로 분리했으며, 포스터 목록과 이동 속도·회전은 `src/features/auth/posters.ts`와 컴포넌트 props에서 설정합니다. 모바일 상단 히어로, 일시정지·재생, 모션 감소 설정을 지원합니다.

데스크톱 좌우 영역은 **1.5:1(60%:40%)**이며, 좌측에는 포스터 격자를 보여 줍니다. 포스터는 `contain`으로 원본 이미지 전체를 표시합니다. 우측 폼은 가로·세로 중앙에 배치하며, 내용이 길면 우측 영역 안에서 스크롤합니다.

스터디룸은 **쌀쌀맞은 갸루짝꿍이 나에게만 친절하다! / 전교 1등을 이겨라 / 냥냥이가 날 그렇게 쳐다보면 집중할 수가 없잖아!! / 김상병의 두근두근 비밀연등 / 페보니우스 마법학교 / 모르는 일진이 나한테 말을 건다 / 쥬라기 독서실 / 뚝딱뚝딱 실험실 / 조선시대 야간 학습** 총 9종입니다. 새 6개 룸도 검색·저장·상세·공부·휴식 대화·리포트·캡슐 카드에 연결했습니다. 신규 친구 이름과 소개는 수정 가능한 더미 데이터이며, 전체 19명의 관계·선물·기록을 각 ID로 관리합니다.

기존 룸·친구 ID와 저장 데이터 형식을 유지하므로 기존 브라우저 데이터로도 9종을 바로 볼 수 있습니다. 새 룸의 누적 기록은 실제 데모 세션을 마친 뒤부터 쌓입니다. 개별 인물 화면은 원본 포스터의 표시 영역을 `CharacterArtwork`에서 재사용하고, 룸과 기본 리포트·캡슐 카드는 분리된 배경/전경 레이어를 사용합니다. 채린·수아·다희의 종료 화면과 카드는 새 완료 전용 이미지를 사용합니다.

홈의 첫 방문·이어하기 문구와 룸 목록으로 이동하는 동작은 [홈·기간별 기록 가이드](docs/HOME_AND_RECORDS.md)에 정리했습니다. 내 기록은 주·월·년 선택에 따라 요약·달력·친구 시간·최근 스터디를 함께 바꾸며, 중복 이용일 카드와 MVP에서 제외한 랭킹은 제거했습니다. 기본 닉네임은 `꾸윙젠렝`이며 기존 데모 데이터의 이름도 기록을 유지한 채 이전합니다.

## 구현 경계

실제 카메라·마이크 권한, 영상 미리보기, 마이크 입력 레벨과 MediaPipe Face Landmarker 추론을 연결했습니다. 공부 중에는 Gesture Recognizer와 Object Detector(EfficientDet-Lite2)도 함께 사용해 딴짓·상태를 감지합니다. 준비 화면의 **카메라·마이크 켜기**를 눌러 확인하며, HTTPS 또는 localhost가 필요합니다. 마이크 권한이 없어도 카메라를 사용할 수 있고 카메라 없이 시작할 수도 있습니다. 준비→공부 화면 이동 중에는 같은 장치 연결을 유지하고, 종료·로그아웃·관련 화면 이탈 시 모든 트랙을 해제합니다. 재접속 후 권한 재획득은 사용자가 카메라 켜기를 눌렀을 때 수행합니다.

준비 화면에서 실제 영상으로 장치를 확인합니다. 공부·휴식 화면은 아바타를 기본으로 표시하며 독에서 실제 캠으로 전환할 수 있습니다. 카메라가 꺼진 상태에서 실제 캠 보기를 누르면 카메라 권한을 요청하고, 카메라를 끄면 아바타로 돌아갑니다. 아바타 보기로만 바꾸면 카메라 연결과 별도 숨김 영상의 얼굴 감지·집중률 측정은 유지합니다. 실제 캠은 같은 스트림을 음소거한 미리보기로 표시합니다. 준비 화면 제목 옆 물음표에서 카메라·마이크 권한의 목적과 로컬 처리·서버 미전송 안내를 확인합니다. 호버·키보드 초점·터치로 열고 Escape·외부 클릭으로 닫을 수 있습니다.

얼굴 감지는 사용자 기기의 GPU/CPU와 Web Worker에서 실행합니다. WebGL GPU 우선이며 추론 초기화가 실패하면 CPU/WASM으로 전환합니다. 준비 화면은 최대 초당 5회 처리하며, 느린 기기에서는 다음 프레임을 대기해 추론이 겹치거나 쌓이지 않습니다. 일시정지·휴식·숨김 탭에서는 추론을 중단합니다. 영상은 메모리에서만 처리하며 서버 전송·녹화를 하지 않고, 마이크는 로컬 입력 확인에만 사용하며 녹음·음성 인식·재생에 연결하지 않습니다.

공부 타이머가 흐르는 동안에는 같은 워커에서 얼굴(초당 10회)·손 제스처(초당 15회)·핸드폰(1초에 1회)을 모델별 주기로 감지합니다. 손·핸드폰 모델은 공부를 시작한 뒤 처음 필요할 때 불러옵니다. 감지 규칙은 **자리 비움**(얼굴 3초 미검출), **졸음**(양쪽 눈 감김 2초), **하품**(입 벌림 1초), **고개 돌림**(좌우 25도 이상 2초), **핸드폰**(3회 연속 검출), **손 흔들기**(1초 안에 좌우 방향 전환 2회)입니다. 기준값과 오버레이 켜기/끄기는 `src/features/media/behavior-constants.ts` 한 곳에서 조정합니다. 감지된 규칙 이름은 내 칸 왼쪽 위에 배지로 표시됩니다. 졸음·하품·손 흔들기·고개 돌림이 새로 시작되면 서버에 동작 이벤트(`DROWSY`·`YAWN`·`WAVE`·`HEAD_TURN`)를 같은 종류당 1분에 한 번 보내고, 응답의 표정과 대사로 친구가 반응합니다. 카메라 꺼짐·휴식·일시정지·숨김 탭에서는 보내지 않으며, 핸드폰과 자리 비움(서버 기준 10초 `AWAY`)은 동작 이벤트로 보내지 않습니다. 동작 이벤트는 상태 이벤트 흐름과 분리되어 자리 비움 반응 강도(1→2→3)를 끊지 않습니다. 서버로는 이벤트 종류와 시각만 보내며 영상과 감지 기록은 저장하지 않습니다.

공부·휴식 화면의 친구 칸은 공부 시작·이어하기 응답의 `character.modelJsonUrl`로 Live2D 모델(Cubism 5)을 그립니다. 주소가 없거나 불러오지 못하면 기존 이미지를 그대로 보여 줍니다. `scale`과 `offsetX`·`offsetY`(칸 크기 대비 %)를 적용하고, 칸이 바뀌어도 WebGL 캔버스 하나를 옮겨 쓰며 공부 화면을 떠나면 정리합니다. 표정은 서버가 준 `expression.file`(모델 폴더 기준 경로)만 사용하며, 상태 이벤트 > 대사 > 동작 이벤트 순 우선순위와 최소 유지 시간으로 바꿉니다. 시선은 공부 중(일시정지 포함) 정면에 고정하고 휴식 중에만 커서를 따라가며, 움직임 줄이기 설정에서는 따라가지 않습니다. 조절 값은 `src/features/live2d/live2d-constants.ts`에 있습니다. PixiJS와 Live2D 엔진은 공부 화면에서만 불러오는 별도 청크로 분리하고, Cubism Core는 `public/live2d/`에서 제공합니다.

MediaPipe의 영상 입력에는 CPU 추론을 쓰더라도 WebGL이 필요합니다. WebGL 자체가 차단된 브라우저에서는 원인을 안내하며 카메라 없이 진행할 수 있습니다. 첫 실제 얼굴 추론이 완료된 뒤 카메라 확인의 다음 버튼이 활성화됩니다.

MVP 집중률은 **얼굴이 보인 시간 ÷ 정상 측정 시간**입니다. 얼굴이 감지되지 않은 유효 구간은 미감지 시간으로 누적해 집중률을 낮춥니다. 준비 화면, 모델 초기화·오류, 카메라 꺼짐, 일시정지, 휴식, 숨김 탭, 1초를 넘는 프레임 공백은 측정에서 제외합니다. 프레임 수가 아닌 시간으로 계산하고, 공부 중 집중률 표시·종료 리포트·내 기록에 같은 관측값을 사용합니다. 측정이 없는 새 세션은 `—`로 표시하며 더미 집중률을 생성하지 않습니다. 이전 샘플 기록은 유지합니다.

측정 누계는 초당 한 번 저장하고, 일시정지·카메라 끄기·종료 시 마지막 유효 구간을 반영합니다. 재접속 시 누계를 이어 가되 오프라인 구간을 추가하지 않습니다. OAuth·LLM/TTS·결제·서버 저장은 후속 연결 대상이며 대화·공부 레벨 계산은 기존 데모 규칙을 사용합니다. 호감도 초기값과 증감 기준은 백엔드에서 확정합니다.

공식 모델 파일·고정 버전·해시·라이선스는 [모델 문서](public/models/README.md)에 있습니다. `npm ci`/개발/빌드 시 설치한 패키지에서 로컬 WASM 실행 파일을 준비하므로 실행 중 외부 CDN에 의존하지 않습니다. 실제 청구가 없는 결제 흐름은 기존과 같습니다.

종료 화면은 룸 이름과 완료 시각을 구분하고, 함께한 친구별 공부 레벨 진행과 현재 호감도를 별도로 표시합니다. 레벨 바는 해당 공부 직전 값부터 공부 시간 증가분만 채우며 레벨 경계를 넘으면 링·빛·입자 효과 후 새 레벨 진행도로 이어집니다. 이후 기록은 과거 리포트의 레벨 변화에 포함하지 않습니다. 레벨은 보라색, 호감도는 하트와 분홍색으로 구분합니다. 채린의 리포트는 [분리 레이어](src/assets/reports/completion-layers-v3/README.md), 캡슐 카드는 [기존 완료 이미지](src/assets/reports/completion-v1/README.md)를 사용합니다. 카드 미리보기와 저장 PNG에는 공식 로고와 홈용 투명 제목 이미지를 사용합니다.

캡슐 카드 미리보기는 `CapsuleCardSurface`에서 포인터를 따라 기울며 사진·로고·공부 시간을 서로 다른 깊이로 보여 줍니다. 홀로그램 반사와 미세한 반짝임을 더하고, 키보드 초점에서는 고정된 입체감을 제공합니다. 터치 화면과 움직임 줄이기 설정에서는 기울기를 생략합니다. 다음 공부 약속은 날짜·시간 휠에서 선택합니다.

캡슐 카드 PNG는 정중앙에 호버했을 때의 그라데이션·반짝임·빛 반사를 고정해 저장합니다. 마우스 위치나 터치·움직임 줄이기 설정에 관계없이 같은 색감을 사용합니다. 파일 공유를 지원하는 브라우저에서는 같은 PNG로 공유 창을 열고, 지원하지 않으면 이미지 저장으로 안내합니다. 복사한 데모 링크의 기록은 이 브라우저 안에만 있으므로 다른 기기와의 동기화는 지원하지 않습니다.

React + TypeScript(strict) + Vite + Tailwind CSS v4를 사용합니다. 공통 UI, 기능 모듈, 페이지와 더미 reducer를 분리했고 페이지는 지연 로딩합니다. 타입 검사·린트·빌드 및 타이머/원장/대화 한도 등의 상태 테스트를 실행할 수 있습니다.

Landing_Page에 적용했던 변경은 사용자 요청에 따라 원복했습니다. 이번 통일 작업에서 Figma 원본은 수정하지 않았습니다. 에셋 출처와 매핑은 [에셋 문서](src/assets/README.md)에 정리했습니다.

BrowserRouter를 사용하므로 배포 서버에서는 `/rooms/dawn-library` 같은 URL도 `index.html`로 연결하는 SPA fallback이 필요합니다. Cloudflare Workers용 `wrangler.jsonc`에 이 동작과 빌드 결과 경로를 설정했습니다.

### Cloudflare Workers 배포

Git 저장소 루트가 이 디렉터리인 Workers 프로젝트의 설정입니다. 배포할 브랜치에도 `wrangler.jsonc`가 포함되어 있어야 합니다.

| 항목 | Production | Preview |
| --- | --- | --- |
| 브랜치 | `main` | `dev` 등 Production 외 브랜치 |
| Build command | `npm run build` | `npm run build` |
| Deployment / Preview command | `npx wrangler deploy` | `npx wrangler preview` |
| Root directory | `/` | `/` |

`wrangler.jsonc`는 `dist`의 정적 파일을 배포하며, `previews` 설정을 선언해 브랜치별 Preview를 지원합니다. Preview 이름은 현재 Git 브랜치에서 정해지므로 `--name dev`를 공통 Preview 명령에 고정하지 않습니다. 기존 Production 명령의 `--assets ./dist --name capsule-front-web --compatibility-date 2026-10-23` 옵션도 파일의 설정과 같아 유지할 수 있습니다.

`dev`의 **Tracking branch**와 **Preview builds**를 확인한 뒤 변경 사항을 `dev`에 push합니다. 해당 Preview의 **Deployments**에서 최신 커밋의 성공 여부와 실제 URL을 확인하세요. Preview 토글을 켜거나 URL을 활성화한 것만으로 배포가 성공한 것은 아닙니다. 공개 배포에는 Cloudflare Access 설정이 필요하지 않습니다.

설정 참고: [Vite](https://vite.dev/guide/), [Tailwind Vite 설치](https://tailwindcss.com/docs/installation/using-vite), [React Router 설치](https://reactrouter.com/start/declarative/installation). 사용 중인 외부 코드·라이브러리의 상업 이용 검토는 [REFERENCE_COMMERCIAL_USE.md](docs/REFERENCE_COMMERCIAL_USE.md)에 기록합니다.


홈 북마크와 가입·충전 동의 체크박스에는 자체 모션을 적용했습니다. 충전 동의는 회원가입과 같은 `AnimatedCheckbox`를 사용합니다. 마이페이지 일정은 왼쪽의 연·월 선택 달력과 오른쪽 목록·편집 기능으로 구성하며, 일정 표시와 날짜별 조회를 연결했습니다. 기록은 일별 공부 시간 히트맵과 숫자/호가 동기화되는 집중률 링으로 표시합니다. 공부 시작 시 목표 시간을 고르면 타이머·일시정지·재접속·종료 기록까지 이어집니다. [컨트롤·목표 시간 가이드](docs/INTERACTIONS_AND_STUDY_GOALS.md), [상업 이용과 배포 고지](docs/THIRD_PARTY_NOTICES.md)를 확인할 수 있습니다.

친구별 함께한 시간은 선택한 기간의 누적 시간을 비교하는 SVG 라인차트로 표시하고, 날짜에 호버하면 당일·월별 시간과 누적 시간을 구분해 보여 줍니다. 왼쪽 카드에는 기간별 공부 시간·횟수·친구 수·집중률과 최근 스터디를 묶고, 오른쪽 카드에는 달력과 선택한 날짜의 상세를 묶었습니다. 날짜 선택 상태는 달력 컴포넌트에서 관리하며, 최근 스터디의 종료 상태 배지는 제거했습니다. 누적 시간 차트는 하단 전체 너비를 사용합니다. 공통 토글은 선택 배경이 슬라이딩합니다. 친구와 날짜·주·월·년에 따라 공부 시간과 집중률이 달라지는 연중 샘플을 사용하며, 기존 실제 공부 기록은 유지한 채 구형 샘플만 자동으로 이전합니다. 북마크 우측 하단 알림과 내 기록 패널·날짜 툴팁의 외곽선은 제거했습니다.

룸 상세에는 인물과 좌석·배경을 함께 생성한 [완성형 배너 9종](src/assets/room-detail-banners/README.md)을 사용합니다. 제목·소개는 HTML로 수정할 수 있으며, 생성 PNG·WebP·전체 프롬프트를 보관합니다. 도윤·모루·민하준·유리는 룸 상세의 친구 카드와 친구 프로필에서 얼굴 크롭을 공유하며, 프로필에는 별도의 책상 레이어를 표시하지 않습니다. 친구 소개는 해시태그로 표시하고 다음 공부 레벨까지의 시간은 레벨 막대에 호버하거나 포커스하면 보여 줍니다. 공통 토글 외곽선과 PREVIEW 표시는 제거했습니다.
