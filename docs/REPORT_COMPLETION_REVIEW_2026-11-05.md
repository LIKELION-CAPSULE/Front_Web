# 종료 리포트 후속 적용 — 2026-11-05

## 현재 적용

- 완료 대사는 기존 채팅의 `TypingMessage`를 공유합니다. 타이핑 속도·커서는 `typing-message.css`를 사용하고, 숨긴 완성 문장으로 최종 높이를 확보합니다. 보조 기술에는 완성 문장을 한 번 제공하며 모션 감소에서는 즉시 표시합니다.
- 배경과 투명 인물은 [분리 레이어 v3](../src/assets/reports/completion-layers-v3/README.md)입니다. 인물은 `contain`, 배경은 `cover`로 배치합니다. 캐릭터와 대화창은 같은 컨테이너에서 가로 중심을 맞춥니다.
- 결과 패널은 왼쪽 제목·공부 시간, 오른쪽 룸명 → 완료 시각 → 집중률 순서입니다. 완료 시각 행에는 향후 대화 옵션을 같은 줄에 추가할 수 있습니다.
- `캡슐 카드 만들기`의 빛 흐름·글로우는 3.6초 주기로 반복합니다. 호버·키보드 초점에서는 일시 정지하며 모션 감소에서는 정적인 버튼으로 표시합니다.

## 아이콘·숫자에 대한 최신 사용자 결정

**Arcade Pixel 적용은 취소했습니다.** 픽셀 컴포넌트·스프라이트·캔버스 코드·전용 CSS·출처/고지 파일을 제거했습니다. 이전의 픽셀 하트와 레벨업 별은 AnimateIcons Lucide의 Heart·Sparkles로 교체했습니다.

제품 아이콘은 앞으로도 [AnimateIcons Lucide](https://animateicons.in/icons/lucide)에서 의미가 맞는 것을 찾아 사용합니다. 공통 `Icon`이 MVP 이후 친구·선물/보이스·기록·크레딧·충전·일정 화면까지 공유됩니다. 41종의 공식 SVG·Motion variants를 바탕으로 인라인 HTML의 바깥 span·로컬 이벤트 타입·실시간 모션 설정을 조정했습니다. 현재 호감도 하트에는 원본 박동 곡선의 반복 옵션을 추가했습니다. 기본은 버튼/링크 전체의 포인터 진입·키보드 초점에서 한 번 재생합니다. 현재 호감도 하트는 후속 사용자 결정에 따라 자동 반복하는 예외입니다. MVP 차단·비활성 조작·모션 감소에서는 정지합니다. [소스·선택 기준·라이선스](../src/shared/ui/animate-icons/README.md)를 따릅니다.

리포트 숫자는 [Tween UI Number Counter](https://tween-ui.vercel.app/component/number-counter)의 공식 GSAP 트리거와 NumberFlow 롤링을 사용합니다.

| 적용 대상 | 표시 기준 |
|---|---|
| 공부·집중·자리 비움·친구와 함께한 시간 | 기존 시간/분·소수 초 단위를 유지하며 숫자만 롤링 |
| 집중률·목표 진행률·복귀 횟수 | 기존 계산·단위를 유지 |
| 다음 레벨까지 남은 분·샘플 집중 흐름의 시간 | 기존 계산을 유지 |
| 현재 호감도 | 확정된 점수만 롤링하며 미정값은 `— / 100` 유지 |
| 날짜·완료 시각·Lv 단계·범위 상한 | 고정 의미의 표기 유지, Lv 단계는 기존 진행 바의 실제 단계 전환을 따름 |

기본 1.8초 동안 화면에 들어올 때 한 번 재생하고, 다시 스크롤해도 반복하지 않습니다. 최종값 너비를 먼저 확보해 문장이 밀리지 않게 하며, 보조 기술에는 최종값을 한 번 제공합니다. 모션 감소 설정 변경은 즉시 반영합니다. [소스·수정 내역·라이선스](../src/shared/ui/number-counter/README.md)를 보존합니다.

## 독립된 공부 레벨·호감도

MVP 이후 친구·선물/보이스 화면도 공부 레벨 Lv.1~5와 호감도 0~100을 별도로 표시합니다. 시간 이력 증가에는 `분` 단위를 붙이고, 확정되지 않은 스토리 조건을 관계 단계로 표현하지 않습니다. 호감도 초기값·증감 규칙은 백엔드 결정이며 프런트에서 공부·대화·선물로 임의 적립하지 않습니다. 리포트의 `현재 호감도`는 최신 확정값이고 과거 세션별 증감이 아닙니다. MVP 진입 차단과 캡슐 카드의 기존 이미지 원본도 유지합니다.

## 빈 공부 화면

진행 세션이 없는 `/study/:sessionId`는 `min-h-dvh` 그리드로 EmptyState를 화면 중앙에 배치합니다. 제목과 `스터디룸 둘러보기` 버튼을 유지하고, 요청한 `스터디룸을 골라 친구와 공부를 시작해 보세요.` 문구는 제거했습니다.

## 검증 기록

이전 분리 레이어·타이핑 검수에서는 2560·1440·1366·1024·768·390·320px 및 모바일 가로에서 캐릭터/말풍선 중심·가로 넘침·버튼 영역·채팅과의 타이핑 공유·캡슐 카드 원본 유지를 확인했습니다. 후속 아이콘·숫자 교체 검증은 아래에 기록합니다.

- 41종 아이콘을 별도 렌더링해 SVG·크기·접근성 숨김을 확인했습니다. 실제 버튼 호버와 키보드 초점에서 원본 variants가 움직이고, disabled·모션 감소에서는 정지합니다. 북마크의 저장/해제와 채움, 320px 일정 창의 새 닫기 아이콘도 확인했습니다.
- 숫자 롤링의 실제 Web Animations 및 시작/완료 이벤트를 관찰했습니다. 중첩 스크롤 진입 시 1회 재생 후 정지하며 재스크롤로 반복하지 않습니다. 모션 감소에서는 화면 밖 숫자도 즉시 최종값이고 실행 중 애니메이션이 없습니다.
- `44.6초`·집중률 `73.1%`·확정 호감도 `64`의 예시를 1440·1024·768·390·320px 및 844px 가로에서 확인했습니다. 소수 단위·최종 너비 확보·가로 넘침 없음을 확인했습니다. 실제 기존 샘플의 미정 호감도는 `— / 100`입니다.
- MVP 이후 친구·선물/보이스·내 기록·크레딧·충전을 실제 컴포넌트의 별도 렌더링으로 1440·390·320px에서 확인했습니다. 문자로 남아 있던 돌아가기·미리 듣기·다시 듣기도 교체했고 보이스 미리보기 창 열기/닫기를 확인했습니다. 실제 경로 5개는 계속 `MVP 이후`로 차단됩니다.
- 공부 독의 아이콘은 데스크톱 22px/모바일 20px이며 작은 공부 타일도 기존 크기 조정을 유지합니다. 캡슐 카드 진입과 `completion-v1` 이미지 유지를 확인했습니다.
- 빈 공부 화면은 1440×900·390×844·320×568·844×390에서 가로 중심 오차 0.01px 미만·세로 중심 오차 0px였고 안내 문구가 제거됐습니다.
- 린트·빌드·토큰 검사·전체 테스트 155개가 통과했습니다. 배포물의 AnimateIcons·Tween UI 고지는 원문과 같고, 제거한 Arcade Pixel 고지는 배포물에도 없습니다. 카메라 하드웨어·다른 브라우저 검수는 이번 시각 변경 확인 범위에 포함하지 않았습니다.

## 시각 오류 후속 수정

- 조용히 집중 버튼·상태·가드·전용 CSS를 제거했습니다. 일반 채팅 열기/닫기, 감지 반응과 타이머는 기존 동작을 이어갑니다.
- 공부 상단 집중률은 라벨과 값 모두 가로 중심을 공유합니다. 미측정 `—`도 같은 기준으로 정렬하며 미측정을 0%로 바꾸지 않습니다. 버튼 제거 후 모바일 룸 제목과 권한 안내가 겹치지 않도록 남은 grid 배치를 정리했습니다.
- 리포트 숫자는 최종값 너비만 확보해도 내부 롤링 글리프가 위·아래·옆으로 그려질 수 있었습니다. 카운터의 고정 영역에 `overflow: clip`을 적용해 두 축 모두 영역 안에서 전환합니다. 정적 최종값·단위·시간 계산은 유지합니다.
- 시작 아이콘의 이동은 원본 viewBox 경계를 넘으므로 공통 SVG에 `overflow: visible`을 적용했습니다. 외부 크기와 버튼 간격은 유지합니다.
- 검색창에 `data-icon-trigger`를 지정하고 공통 Icon이 복합 입력 영역의 포인터 진입·초점·클릭에 반응하게 했습니다. 이미 초점이 있는 입력창을 다시 클릭해도 돋보기를 재생하고, 돋보기/빈 패딩 클릭은 입력에 초점을 줍니다. 검색·지우기 동작과 모션 감소 대응을 유지합니다.

후속 검증에서는 실제 공부 페이지 컴포넌트의 1440·1024·768·390·320px 배치에서 미측정 라벨/대시 중심 차이 0px, 조용히 집중 버튼 제거, 룸 제목과 권한 안내 분리를 확인했습니다. 실행 중 공부의 C/Escape 채팅 열기·닫기도 확인했습니다. 리포트는 `44.6초`·`73.1%`·호감도 100 예시와 실제 320px 샘플의 전환 중간·완료 프레임을 확인해 숫자가 카운터 영역 밖의 문구/행에 그려지지 않음을 검수했습니다. 기존 검색/지우기, 이미 초점이 있는 검색 입력의 재클릭, 시작 아이콘의 이동 끝부분도 확인했습니다. 모션 감소로 처음 연 뒤 설정을 해제하는 경우에도 아이콘이 재생되도록 공통 실시간 구독을 사용합니다. 모션 감소에서 카운터와 돋보기는 정지합니다. 린트·빌드·토큰 검사·전체 테스트 155개가 통과했습니다.

## 자릿수 롤링·기준선 보정

사용자 후속 요청으로 숫자 전체의 표시 영역 제한을 보완했습니다. 최종 정수·소수 자릿수를 처음부터 확보해 `000 → 595`, `00.0 → 44.6`처럼 같은 열 안에서 각 숫자가 위로 회전합니다. NumberFlow의 `trend={1}`·`continuous`를 사용하며 각 digit part를 개별 클리핑합니다. 소수점·구분자·단위는 고정되고 외부 영역 보호도 유지합니다.

기존 inline-grid와 라이브러리 기본 line-height/마스크 패딩의 차이로 일반 텍스트와 카운터의 높이가 달랐습니다. 보이지 않는 일반 인라인 텍스트로 기준선·최종 너비·줄 높이를 확보하고, 실제 숫자를 같은 위치에 겹쳐 표시합니다. NumberFlow는 부모 줄 높이를 상속하고 추가 마스크 패딩을 0으로 둡니다.

실제 StudyLevelGain의 `+10초`·`Lv.5까지 595분`과 12/16/20/32px 일반 텍스트를 비교했습니다. DOM 기준선 프로브의 차이는 모두 0px였고 카운터와 표시 영역의 줄 높이도 같았습니다. 10·595·소수 초·100의 전환 프레임에서 각 숫자 열의 x좌표·너비가 고정된 채 위쪽으로 회전함을 확인했습니다. 같은 값을 실제 계산하는 리포트 예시를 1440·1024·768·390·320px에서 확인했고 가로 넘침은 없었습니다. 모션 감소에서는 실제 리포트 숫자가 최종값으로 즉시 표시되며 실행 중 애니메이션이 없습니다.

자릿수·기준선 보정 후 린트·빌드·토큰 검사와 전체 테스트 155개가 통과했습니다.

## 현재 호감도 하트 반복

리포트의 `현재 호감도` 하트는 진입 즉시 원본 AnimateIcons Heart 모션을 무한 반복합니다. 0.8초 동안 박동하고 0.7초 쉬며 다음 주기를 시작합니다. 해당 하트의 호버 트리거를 해제해 포인터 진입/이탈로 반복을 다시 시작하거나 멈추지 않게 했습니다. 모션 감소에서는 즉시 기본 크기로 정지하고, 설정을 해제하면 반복을 다시 시작합니다. 점수·미정값·숫자 카운터의 동작은 유지합니다.

현재 호감도 하트 검증에서는 포인터 없이 두 주기 이상 반복되는 것을 관찰했고, 호버/이탈 후에도 박동이 계속됐습니다. 모션 감소에서 scale=1로 정지하고 설정 해제 뒤 재생하는 것도 확인했습니다. 미정 점수는 `— / 100`을 유지합니다. 린트·빌드·토큰 검사와 `git diff --check`가 통과했습니다.
