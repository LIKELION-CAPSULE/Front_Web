## 이미지 재사용

이미지는 개별 이미지 채움 레이어로 등록했습니다. 어두운 미리보기 바탕은 별도 부모 레이어이므로, **이미지 레이어**를 선택해 내보내면 투명 배경을 보존합니다. 각 이미지의 PNG 내보내기 배율은 원본 픽셀 크기에 맞췄습니다.

제목 크롭 9개는 Figma 표시 호환성을 위해 원래 WebP와 픽셀·알파·해상도가 동일한 PNG로 등록했습니다. 프로젝트에서 사용하는 WebP 파일은 변경하지 않았습니다.

## 파일 대응 목록

[FIGMA_GENERATED_ASSETS.json](FIGMA_GENERATED_ASSETS.json)에 이미지별 소스 경로·크기·SHA-256·사용 상태와 Figma 페이지·분류·카드·이미지 노드 ID를 기록했습니다. 같은 파일을 갱신할 때는 이 노드 ID를 사용해 이미지 채움만 교체할 수 있습니다.
