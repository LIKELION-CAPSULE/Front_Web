# 홈 탐색과 기간별 기록

## 홈

`룸 둘러보기`는 모든 룸과 빈 검색어를 복원한 뒤 다음 프레임에 목록 제목으로 이동합니다. `scrollIntoView({ block: 'start' })`와 24px의 `scroll-margin-top`을 사용해 배너를 벗어나 `오늘은 누구와 공부할까요?`가 화면 위에 오도록 했습니다. 제목으로 키보드 포커스도 옮기며, 모션 감소 설정에서는 즉시 이동합니다. 버튼의 화살표는 아래 방향입니다.

문구는 [welcome-copy.ts](../src/features/rooms/welcome-copy.ts)에서 수정합니다.

홈과 룸 상세 헤더의 잔여 크레딧·아바타 메뉴는 공통 [HeaderAccount.tsx](../src/app/components/HeaderAccount.tsx)를 사용합니다. 헤더의 오늘 공부 시간 표시는 제거했습니다. 룸 상세의 긴 룸 이름은 별도 줄에 배치합니다. 로그인하지 않은 상세 방문자는 로그인 버튼으로 계정에 진입합니다. 아바타 메뉴는 바깥 클릭·터치·Escape·메뉴 밖으로의 키보드 초점 이동으로 닫힙니다.

`쌀쌀맞은 갸루짝꿍이 나에게만 친절하다!`와 `전교 1등을 이겨라`의 홈 룸 카드에는 [홈 전용 캐릭터 전경 v2](../src/assets/scenes/home-v2/README.md)를 사용합니다. 원본 포스터의 복장과 조명을 유지하고 의자 없이 바닥에 단정히 앉은 자세로 재생성했으며, `home-artwork.ts`에서 홈에만 적용합니다. 다른 화면의 공유 원본·룸 상세 배너·친구 초상화는 별도 에셋을 유지합니다.

| 상태 | 큰 문구 |
| --- | --- |
| 첫 방문 | 혼자 할 뻔했네. / 같이 앉을래? |
| 최근 공부 이어하기 | 책갈피 꽂았어. / 너만 오면 돼. |
| 진행 중인 세션 | 자리 맡아 뒀어. / 하던 데서 계속. |

진행 중인 세션은 첫 방문 플래그보다 우선합니다. 배너 캐릭터를 바꾸어도 이어하기는 실제 진행 중인 세션 또는 최근 룸으로 연결합니다. 이미지·대사는 기존 공유 알파 마스크로 함께 지워지고 문구·버튼은 고정 HTML로 유지합니다.

## 닉네임

기본 데모 이름은 `꾸윙젠렝`입니다. [profile.ts](../src/features/demo/profile.ts)에서 기본값과 이전 처리를 관리합니다. 기존 기본 이름으로 저장한 데이터는 기록·원장·아바타를 유지하면서 이름을 바꾸고, 캐릭터의 기존 자동 답변에 들어간 기본 이름도 바꿉니다. 사용자가 작성한 메시지와 다른 사용자 지정 닉네임은 보존합니다. 빈 프로필 입력도 새 기본 이름을 사용합니다.

## 내 기록

`MY CAPSULE` 장식, 소개 문단, `SMALL STEPS, EVERY DAY`, 별도의 `이번 주 이용일` 카드와 MVP 대상이 아닌 `주간 랭킹`을 제거했습니다. 달력에 공부한 날짜가 남으므로 별도 출석 카드를 중복해서 두지 않습니다.

주·월·년은 **현재 서울 날짜**를 기준으로 계산합니다. [record-period.ts](../src/features/reports/record-period.ts)에 기간 경계와 필터·요약을 모았습니다.

| 선택 | 기간 | 달력 |
| --- | --- | --- |
| 주 | 월요일 00:00부터 다음 월요일 직전 | 월~일 7일 |
| 월 | 이번 달 1일부터 다음 달 직전 | 실제 월의 전체 날짜, 요일에 맞춰 정렬 |
| 년 | 올해 1월 1일부터 다음 해 직전 | 연간 일별 기여도 히트맵 |

전체·스터디룸별 보기 모두 같은 기간을 적용합니다. 공부 시간·시간으로 가중한 집중률·공부 횟수·함께한 친구 수, 달력, 캐릭터별 시간, 최근 5개 기록을 같은 자료에서 계산합니다. 룸 선택기의 시간·횟수에도 선택한 기간을 적용합니다. 캐릭터별 차트는 기록이 있는 모든 캐릭터를 포함하고 함께한 시간을 나누어 합산합니다.

달력의 날짜를 고르면 그 칸의 시간·횟수·집중률을 보여 줍니다. 미래 날짜/월은 비활성화하며 기록이 없는 기간은 0과 빈 상태를 표시합니다. 모바일에서는 긴 룸 목록 대신 선택 상자를 사용합니다.

> 2026-11-24: 아래 두 문단이 말하는 `StudyHistoryPanel`·`StudyActivityPanel`·`ActivityHeatmap`(와 `StudyHeatmap`·`CompanionTimeChart`·`RecordSummary`·`SessionList`·`FocusSummary`·`FocusTimeline`)은 쓰이지 않아 삭제했습니다. 현재 구성은 다음 절(「2026-11-24 개편」)을 보세요.

기간별 공부 시간·횟수·함께한 친구 수·집중률과 최근 스터디는 `StudyHistoryPanel`(삭제됨)의 한 카드로 묶었습니다. 최근 스터디에는 날짜·스터디룸·공부 시간과 설정된 목표 시간을 표시하며 종료 상태 배지는 표시하지 않습니다. `StudyActivityPanel`(삭제됨)은 달력과 선택한 날짜의 시간·횟수·집중률, 날짜 선택 상태를 함께 관리합니다. 날짜 선택은 해당 날짜의 상세만 바꾸며 기간 요약과 최근 스터디 목록은 유지합니다.

주요 화면은 [RecordsPage.tsx](../src/pages/RecordsPage.tsx), 달력 표시는 당시 `ActivityHeatmap`(삭제됨)이었습니다. 공유 `PageHeading`은 `eyebrow={null}`일 때 상단 장식 문구를 생략할 수 있습니다.

### 2026-11-24 개편: 연결 시간 기준 · 캡슐 달력 · 채린 코멘트

아래 이전 설명보다 이 절이 우선합니다.

- **시간 기준(사용자 결정)**: 화면의 대표 숫자는 **연결 시간**이고 「함께한 시간」으로 부릅니다. 요약 카드, 캡슐 달력의 채움, 날짜·달별 그래프, 선택한 날 요약, 채린 코멘트에 모두 연결 시간을 씁니다. 카메라를 끈 사용자도 같은 기록을 봅니다(PRD M-2).
- **카메라 시간**: 측정된 경우에만 보조로 표시합니다. 요약 카드 아래 작은 글씨, 그래프 안쪽의 가는 회색 막대, 선택한 날·기록 행에 「카메라로 함께한 시간」으로 나옵니다. 0이면 숨깁니다.
- **캡슐 달력**: [capsule-calendar.ts](../src/features/records/capsule-calendar.ts) · [CapsuleCalendar.tsx](../src/features/records/CapsuleCalendar.tsx)
  - 모양: 하루가 로고 v2 캡슐(stadium 몸통과 이음매, 기울기)을 단순화한 CSS 캡슐 하나입니다. 주는 7칸, 월은 날짜 격자, 년은 365칸 「캡슐 잔디」(열은 주, 행은 요일)입니다.
  - 채움: 그날 연결 시간의 절대 구간으로 정합니다. 30분 미만, 30분+, 1시간+, 2시간+로 갈수록 더 많이, 더 밝게 채웁니다. 기록이 없는 날은 옅은 윤곽만 두고, 미래 날짜는 흐리게, 오늘은 윤곽선으로 표시합니다.
  - 등장 연출: 화면에 들어오거나 기간·메이트를 바꾸면, 첫날부터 마지막 날까지 빛이 한 번 차오릅니다. 칸 수와 관계없이 약 1초 안에 끝나고, 움직임 줄이기 설정에서는 바로 최종 상태를 보여 줍니다.
  - 조작: 마우스를 올리거나 포커스하면 툴팁이 나옵니다. 방향키로 칸을 이동합니다(주 ←→, 월 ←→↑↓, 년 ↑↓ 하루·←→ 한 주, Home/End).
  - 날짜 선택: `selectCapsuleDay`가 그날과 그날의 기록을 넘깁니다. 기록이 있는 날을 누르면 내 메이트의 캡슐과 같은 기록 카드(`CapsuleRecordCard`, 네이티브 모달, 수집형 카드 — `MY_MATES_CAPSULE_SCENE.md`의 「기록 카드」)가 열리고, 그날 연결이 여럿이면 카드 안에서 이전·다음으로 넘깁니다. 「연결 기록 보기」는 `/connections/:id`로 갑니다.
  - 좁은 화면: 년 잔디는 가로 스크롤하며, 선택한 날(기본은 오늘)이 보이게 시작합니다.
- **채린 코멘트**: 요약 카드 위에서 선택한 기간과 메이트의 사실만으로 말합니다. 생성 함수는 [mate-comment.ts](../src/features/records/mate-comment.ts)입니다. 밤과 새벽이 섞이면 「늦은 시간」이라고 말하고, 한 시간대만 말할 때는 그 시간대의 실제 횟수를 씁니다.
- **날짜 기준(대표 = 시작 시각)**: 연결 하나는 **시작한 날(서울)**에 속합니다. 요약·코멘트(요일·시간대)·달력·선택한 날·목록과 내 메이트 캡슐이 모두 [connection-day.ts](../src/features/records/connection-day.ts)를 씁니다. 23:30–00:40 연결은 전날 밤 기록입니다. 근거: 캡슐과 코멘트의 시간대가 이미 시작 시각 기준이었고, 「그날 밤에 만났다」는 사용자의 기억과 맞으며, 월말·연말에 걸친 연결도 시작한 기간에 한 번만 셉니다.
- **완료 기록만**: `endedAt <= now`인 연결만 요약·코멘트·달력·목록·캡슐에 나옵니다(같은 cutoff).
- **표면**: 카드, 패널, 기록 행, 기간 탭, 이동 버튼, 메이트 칩에 외곽선이 없습니다. 구획은 표면 색, 간격, 제목으로 나누고, 보라는 주 지표, 선택 상태, 채움에만 씁니다.

### 2026-11-25 내 메이트 기준으로 정리

위 「표면」 항목보다 이 절이 우선합니다. 배치 순서와 비율은 바꾸지 않았습니다(「캡슐 달력이 주인공」 재배치는 다음 작업).

- **겉 표면 없음(사용자 결정)**: 내 메이트처럼 `AppPanel`과 `.records-window-body`의 바탕을 투명하게 합니다. 내 기록 한정 규칙이며 공용 기본값(`app-surfaces.css`)은 그대로입니다.
- **유리 블록**: 기간 탭 묶음, 이동 버튼, 메이트 칩, 요약 카드, 달력, 그래프, 최근 연결, 빈 상태가 모두 홈 말풍선 재질을 씁니다(`panel` 68% → `canvas` 62%, 18px 흐림, 140% 채도, 외곽선 없음, 흐림 미지원 시 불투명 `panel`). 채린 코멘트 말풍선은 원래 같은 재질입니다.
- **블록 언어**: 내 메이트 「함께한 시간」 열과 같습니다. 여백 16px 20px, 모서리 18px, 제목은 작은 아이콘 + 13px 굵은 `muted` 글자(`records-block-title`). 블록 안에는 상자를 겹치지 않고 얇은 구분선과 간격으로 나눕니다(선택한 날 요약, 기록 행).
- **보라 사용처**: 선택 상태(기간 탭, 메이트 칩, 고른 날짜)는 `selected` 색, 캡슐 빛과 그래프 막대는 아래 시간대 색입니다. 주 지표 카드의 보라 그라데이션, 2시간+ 캡슐의 글로우, 오늘 캡슐의 외곽선은 없앴습니다. 오늘은 굵은 날짜 + 작은 점으로 표시합니다.
- **캡슐 시간대 색**: 연결 시작 시각의 시간대(`timeBand`)를 따릅니다. 색은 브랜드 캡슐(채린 테마 `tintHalfShade`)을 내 메이트 캡슐과 같은 이동값(`capsuleBandTheme`)으로 옮긴 값입니다(`capsuleBandFill`, 새벽은 푸르게, 저녁은 분홍 쪽, 밤은 진하게). 메이트와 관계없이 한 팔레트를 씁니다.
  - 여러 시간대가 섞인 날은 **가장 오래 함께한 시간대** 하나를 씁니다. 같으면 먼저 시작한 연결의 시간대입니다. 2톤은 쓰지 않습니다(연 보기 캡슐이 13×7px라 두 색을 구분하기 어렵습니다).
  - 툴팁에 시간대를 적습니다(「저녁」, 섞이면 「주로 저녁」). 범례에는 시간대 색을 따로 싣지 않습니다. 한 보라 안의 작은 차이라 범례가 길어지기만 해서입니다.
  - 그래프의 날짜 막대도 그날 캡슐과 같은 색입니다. 달 막대(연 보기)와 범례 점은 기준 보라입니다. 카메라 시간은 막대 안쪽의 가는 흰 막대로 남깁니다.
- **기념 캡슐**: 함께한 시간이 이정표(1·3·5·10·20·30·50·100시간, `capsule-moments.ts`)를 넘긴 연결이 있는 날은 캡슐 끝에 작은 흰 별을 답니다. 메이트마다 전체 기록으로 셉니다(내 메이트와 같은 `capsuleKeepsakes`). 툴팁과 선택한 날 요약에 「함께한 지 n시간」이 나오고, 그런 날이 보이는 기간에만 범례에 「기념」이 붙습니다. 별은 캡슐이 차오른 뒤 나타나며, 움직임 줄이기에서는 바로 보입니다.
- **요약 카드**: 주 지표(함께한 시간)는 30px, 나머지는 24px이고 카메라 시간은 13px 보조 줄입니다. 960px 미만에서 카드가 3개면 주 지표가 첫 줄 전체를 씁니다.
- **픽셀 눈·하트 바탕**은 아직 넣지 않습니다(사용자 결정 대기).

### 2026-11-25 「함께 쌓은 시간」 2.5D 캡슐 보드 — 1단계 단독 시안

사용자 결정: 내 기록의 주인공을 캡슐 자체가 데이터인 2.5D(아이소메트릭) 보드로 삼습니다. 최종 구성(2단계)은 채린 코멘트 → 요약 숫자 3개 → 보드 → 선택한 날 요약과 최근 연결이며, 날짜별 막대그래프(보드 높이가 대신)와 메이트별 그래프(보드 위 메이트 칩이 대신)는 빠집니다. 블록 제목은 요약 카드 「함께한 날」과 겹치지 않게 「함께 쌓은 시간」입니다.

- **시안 진입점**: `/records?board=preview`. 개발 서버 + 로컬 mock(`body[data-local-demo]`)에서만 열립니다. 운영 빌드에서는 `import.meta.env.DEV`가 거짓이라 시안 모듈과 청크가 아예 빠집니다. 기존 내 기록 동작은 그대로입니다. 시안 컨트롤은 기간(주·월·연), 기록 패턴(로컬 더미 7종 + 「연간 꽉 참(성능 측정용)」), 메이트 2명 섞기와 메이트 칩, 움직임 줄이기 강제, 다시 재생입니다. 시안은 기록을 `record-patterns.ts`의 패턴으로 직접 만듭니다(store와 무관).
- **모듈**: `src/features/records/capsule-board/`
  - `capsule-board-layout.ts`(순수, `tests/capsule-board-layout.test.ts`): 칸 배치, 쌓기, 높이 규칙, 솟아오름 시간.
  - `capsule-board-scene.ts`(three.js, 지연 청크): 바닥 타일·바닥 글자·캡슐 인스턴싱, 직교 카메라, 선택(광선-상자 판정), 기울기.
  - `CapsuleBoard.tsx`: 장면 수명, 툴팁, 키보드·스크린리더 날짜 목록, WebGL 대체.
  - `CapsuleBoardPreview.tsx`·`capsule-board-preview.css`: 시안 전용.
- **높이 규칙**: 캡슐 1개 = 그날 함께한 시간 30분. 주·월·연 모두 같고, 하루 합계를 반올림합니다(±15분, 정확한 값은 툴팁). 그날 연결들이 시작 순서대로 시간 비율로 나눠 가지며(최대 나머지 방식), 연결마다 최소 1개라 연결별 색이 모두 보입니다. 내 메이트의 「10분당 1개, 연결당 3~18개」는 더미를 쌓는 규칙이라 쓰지 않았습니다. 최소 3개 규칙 때문에 5분과 30분이 같은 높이가 되고, 상한이 긴 날을 눌러서 높이 비교가 깨집니다.
- **상한과 압축**: 기둥은 최대 8칸(4시간)입니다. 넘는 날은 캡슐을 모두 둔 채 8칸 높이 안에 겹쳐 담아, 유리가 더 촘촘하고 밝게 보입니다(`compressed`).
- **색과 기념**: 캡슐마다 그 연결의 시간대 색(`capsuleBandTheme`)입니다. 아래부터 시작 순서로 쌓습니다. 기념 캡슐은 내 메이트와 같이 1.4배 크기, 더 밝은 빛, 이음매의 별 다섯입니다. 기념 판정은 메이트별 전체 기록의 `capsuleKeepsakes`이고, 그 연결 안에서의 위치 비율대로 기둥의 한 캡슐이 기념이 됩니다.
- **렌더 재사용**: 내 메이트 `capsule-jar-scene.ts`의 `capsuleGeometry`·`capsuleRadiusAt`·`shellMaterial`·`coreMaterial`·`haloMaterial`을 export해서(동작 변경 없음) 같은 유리 캡슐을 세워 씁니다. 셸·코어·후광은 `InstancedMesh` 세 개가 인스턴스 행렬과 속성을 공유합니다. 연 보기나 300개를 넘는 보드에서는 같은 단면 함수로 만든 가벼운 메시(약 1/10 삼각형)를 씁니다. 코어의 숨쉬기는 끄고, 움직임이 있을 때만 그립니다.
- **기간별 칸**: 주는 큰 7칸 한 줄, 월은 요일 정렬 격자, 연은 365칸 「캡슐 정원」(열은 주, 행은 요일)입니다. 연은 캡슐을 조금 길게 하고, 월 라벨을 정원 앞에 둡니다. 주·월은 칸마다 날짜를 바닥에 눕혀 쓰고, 오늘은 굵게 + 점입니다. 560px보다 좁으면 주·월 시점을 더 돌려 세로로 길게 놓습니다.
- **상호작용**
  - 날짜 순서대로 아래부터 톡톡 솟습니다. 기록 있는 날만이고, 약 1~1.3초입니다.
  - 마우스를 올린 칸은 떠오르고 밝아지며 툴팁이 나옵니다(날짜·함께한 시간·횟수·시간대·「함께한 지 n시간」).
  - 누르면 수집형 캡슐 카드가 열리고, 여러 연결이면 날짜 페이저가 붙습니다.
  - 포인터를 따라 보드가 최대 약 2°까지 기웁니다.
- **움직임 줄이기**: 솟아오름·기울기·떠오름이 없습니다. 고른 칸은 색과 빛으로만 알립니다.
- **접근성**
  - 보드 아래에 시각적으로 숨긴 날짜 버튼 목록이 있습니다. 각 버튼의 이름은 툴팁과 같은 문장입니다.
  - 버튼 하나만 Tab으로 들어가는 roving 방식이고, 방향키 이동은 캡슐 달력과 같습니다(`capsuleNeighbor`). Enter로 엽니다.
  - 포커스가 있으면 보드에 포커스 링이 생기고, 그 칸이 떠오르며 툴팁이 나옵니다.
  - WebGL을 쓸 수 없으면 2D 캡슐 달력으로 대체합니다.
- **성능**: 화면 밖이나 탭이 숨겨지면 정지하고, 해제 시 GPU 자원을 dispose합니다. 2026-11-25 측정(1440×900, 기울기와 마우스 올림을 계속 움직인 5초):

| 보기 | 캡슐 | 칸 | Apple M4 Pro(Metal) | SwiftShader(CPU 래스터, 참고) |
|---|---|---|---|---|
| 연 | 1,783 | 365 | 119.4fps, p95 9.2ms | 3.9fps |
| 월 | 130 | 30 | 120fps, p95 9.3ms | 7.7fps |
| 주 | 8 | 7 | 120fps, p95 9.3ms | 30.5fps |

M4 Pro 수치는 디스플레이 상한(120Hz)입니다. 저사양 GPU 실측은 하지 않았습니다.

## 공부 종료와 캡슐카드

종료 화면은 룸 이름을 제목 아래에, 완료 시각과 대화 옵션을 별도 메타 정보 행에 표시합니다. 장식용 CAPSULE 문구, 얼굴 관측 시간 설명과 인물 하단의 관계 배지는 표시하지 않습니다. 집중률·집중·미감지·복귀는 실제 기록 값을 유지하며 미측정은 `—`입니다.

함께 공부한 친구별로 이번에 더한 시간을 표시합니다. `reportRelationship`은 해당 공부 이전 기록만 합산하고, 기존 친구별 시간 배분과 600분 단위 레벨 규칙을 사용합니다. 진행 바는 이전 값에서 실제 증가량까지 움직이며, 레벨을 넘으면 끝까지 채운 뒤 축하 효과와 새 레벨 진행도를 표시합니다. 최대 Lv.5는 완전히 채워진 상태를 유지합니다. 움직임 줄이기에서는 최종 값과 정적인 안내만 표시합니다.

채린·수아·다희의 [완료 전용 이미지](../src/assets/reports/completion-v1/README.md)를 리포트와 캡슐카드에서 함께 사용합니다. 해당 공부에 참여한 친구만 선택할 수 있으며 선택은 `friend` 쿼리로 이어집니다. 다른 친구는 기존 장면을 유지합니다.

캡슐카드의 공식 로고와 왼쪽 위 투명 제목은 기존 홈 에셋을 재사용합니다. 미리보기와 실제 720×1200 PNG에 동일한 선택 인물·로고·제목을 합성합니다. PNG는 카드 색 선택을 반영하고 다음 공부 약속과 저장·공유 흐름을 유지합니다.

로고의 흰 바탕은 제거했습니다. `CapsuleCardBrand`는 보라·검정 카드의 글자 부분에만 밝은 색을 입히고 밝은 카드에서는 원래 보라색을 사용합니다. 캡슐 아이콘의 색·입체감·투명 여백은 유지하며 은은한 그림자로 구분합니다. PNG에도 같은 글자 색과 투명 배경을 반영합니다.

이미지 저장·스토리 공유는 실제 포인터 위치와 관계없이 정중앙 호버의 색감을 고정합니다. `capsule-card-material.ts`가 미리보기의 그라데이션·호버 강도와 Canvas의 배경 합성을 공유하며, 반짝임과 빛 반사를 콘텐츠 뒤에 그립니다. 터치·움직임 줄이기에서도 같은 정적 PNG를 생성하고 저장·공유·공유 미지원 시 다운로드에 동일한 파일을 사용합니다.

왼쪽 미리보기의 `CapsuleCardSurface`는 포인터 위치에 맞춰 카드 기울기·홀로그램 반사·반짝임을 갱신합니다. 사진·로고·공부 시간을 서로 다른 깊이에 놓고, 키보드 초점에서는 고정된 기울기를 사용합니다. 터치 스크롤을 유지하며 움직임 줄이기 설정에서는 정적인 카드로 표시합니다. 오른쪽 설정에서는 안내 문단 두 개와 오늘·내일·모레 바로가기를 제거하고 날짜·시간 휠로 약속을 정합니다.

## 검증

- 린트·TypeScript/Vite 빌드·단위 테스트 **23개** 통과.
- 격리 Chromium의 실제 UI와 통제된 더미 기록에서 **50항목** 통과.
- 1440/390/320px에서 검색 결과가 비어 있어도 모든 룸을 복원한 뒤 제목을 화면 위 약 24px에 배치했습니다. 배너는 화면 밖에 있고 키보드 포커스도 제목으로 옮겨졌습니다.
- 서로 다른 주·월·연도의 자료로 필터·시간으로 가중한 집중률·친구 수·달력·룸 선택·빈 상태를 확인했습니다. 서울 날짜의 월요일 시작, 윤년, 기간 끝 제외는 단위 테스트로 검증했습니다.
- 상태별 큰 문구는 390/320px에서도 두 줄을 유지했고, 모바일 연간 달력의 월/시간 표시는 겹치지 않았습니다.
- 이전 닉네임 이전 시 기록·원장·아바타와 사용자 지정 이름/메시지를 보존하는지 검증했습니다. 캐릭터가 기존 기본 이름을 부른 자동 답변은 새 이름으로 바꿉니다.
- 브라우저 런타임·콘솔 오류 0개. [항목과 측정값](../src/features/reports/validation.json). 다른 브라우저 엔진과 실제 모바일 기기는 이번 검사에 포함하지 않았습니다.
