# CAPSULE 디자인 시스템

> 10월 디자인 이력입니다. 원래 내용을 보존하고 이동에 필요한 상대 링크만 조정했습니다. 이후 통일 작업은 [통합 디자인 기준](../DESIGN_SYSTEM.md)을 따릅니다. 이 파일의 토큰·화면 상태·검증 기록은 작성 당시 기준입니다.

2026-10-26 · 사용자 확인: 네이비·라벤더 유지 + 대비 정돈 / Pretendard 유지. 참고 사이트 45곳 조사와 레이어 에셋 보완을 반영한 로컬 웹 디자인. Figma와 Landing_Page 원본은 읽기만 했으며 수정하지 않았다.

## 방향

좋아하는 친구가 기다리는 공부 공간. 네이비 배경으로 화면의 소음을 줄이고, 라벤더는 시작·선택·관계 변화에 사용한다. 노을·햇살이 담긴 원본 일러스트가 가장 밝은 영역이 된다.

## 재사용 단위

- Brand, Icon, Button/ButtonLink, Badge, Panel/StatCard, Tabs, Dialog, RadioOption, PageHeading.
- Avatar: 캐릭터 이미지 또는 저장한 개인 아바타. AvatarIllustration: 헤어·의상·외모를 반영하는 SVG.
- RoomArtwork: 배경·투명 캐릭터·제목을 분리한 카드/히어로/세션/프로필/썸네일 변형.
- RoomCard: 입장 상태·저장·되돌리기·캐릭터 썸네일. HomePage에서 검색·저장한 룸 필터.
- PageSkeleton / ProgressRing: 실제 로딩, 집중 비율을 재사용.
- ActivityHeatmap: 완료 기록에서 날짜별 공부 시간을 합산하는 최근 4주 달력.
- CharacterCard, CharacterFigure, CharacterTile: 관계 소개·세션·휴식·리포트·카드에서 같은 이미지 매핑을 재사용.
- 캐릭터 ID와 표정별 에셋은 `features/characters/artwork.ts`, 원본 출처는 `src/assets/README.md`.
- 룸의 순수 도메인 데이터와 Vite 이미지 import를 분리해 reducer 테스트가 브라우저 없이 실행된다.

## 반응형과 접근성

홈 카드는 데스크톱 3열, 중간 화면 2열, 작은 모바일 1열. 공부 화면은 데스크톱 그리드와 모바일 세로 배치를 지원한다. 모바일 컨트롤은 하단에 고정한다. 320/390/768/1280px 화면에서 가로 넘침을 확인한다.

아이콘은 인접 텍스트가 있으면 장식용으로 처리하고 단독 버튼은 이름을 제공한다. 키보드 포커스, 본문 건너뛰기, 네이티브 dialog, 선택 상태 aria-pressed/radio를 사용한다. prefers-reduced-motion 환경에서는 이동 효과를 최소화한다.

## 데모 범위

기존 라우팅·localStorage·타이머·잔액·대화 한도·약속 흐름을 유지한다. 도윤·모루는 생성한 배경과 투명 캐릭터를 합성한 정지 장면으로 표시한다. 카메라·마이크 권한과 미리보기·입력 확인, MediaPipe 얼굴 감지 기반 집중률을 연결한다. 실제 LLM·결제·음성 합성·Live2D는 후속 연결 대상이다.

## 대비 검사

사용자가 선택한 기존 계열 안에서 hover 버튼·공부 종료 버튼·보라 공유 카드의 흰 글자 대비를 정돈했다. 아래는 실제 토큰/색 조합의 sRGB 상대 휘도 계산이다. 이미지 위 제목은 별도 CSS 그라디언트와 그림자를 사용하며 각 화면에서 시각 확인한다.

## 메인 히어로 보완 · 2026-10-27

큰 슬로건과 소개, 우측 일러스트 하단의 대사 위치는 유지합니다. `CompanionGreeting`은 대사만 담은 글래스모피즘 blockquote입니다. 초상화·이름·꼬리는 표시하지 않고, 접근성 이름으로 화자를 식별합니다. 장식용 하트·관계 레벨·긴 룸 이름 배지·히어로의 중복 통계는 덜어냅니다. 새로운 폰트·팔레트·모션 라이브러리는 추가하지 않았습니다. `welcome.css`에서 반응형과 모션 감소를 관리합니다. [52곳 재조사와 적용 근거](../WELCOME_HERO_RESEARCH.md).

대사 표면은 `#1b2034b8` → `#111727ab`의 반투명 네이비, 테두리는 `#ffffff36`, 본문은 `#faf7ff`입니다. `backdrop-filter: blur(18px) saturate(125%)`로 배경을 투과시킵니다. 더 투명한 끝 색을 순백 배경에 합성했을 때 본문 대비는 약 **5.63:1**입니다. 필터 미지원 시 `#182032ed` 표면을 사용합니다.

## 히어로 호버 지우기 전환 · 2026-10-27

이전 하프톤 연결을 제거하고 [UI Beats Scratch to Reveal](https://uibeats.com/docs/component/scratch-to-reveal)의 Canvas 지우기·면적 기준 완료 방식을 적용했습니다. 현재 이미지를 호버로 지우면 아래에 다음 이미지가 바로 보이며, 실제 면적 40%를 지우면 460ms 동안 남은 조각을 제거하고 채린 → 수아 → 다희 → 채린 순으로 이어집니다. 클릭/드래그나 시간 기반 자동 넘김은 없습니다. [컴포넌트 설정·출처](../../src/shared/ui/hover-scratch/README.md).

[전용 가로 배너 3종](../../src/assets/welcome-banners/README.md)은 built-in imagegen으로 새로 생성했습니다. 채린은 노을빛 교실, 수아는 비 오는 도서관, 다희는 보랏빛 야간 스터디룸입니다. 글자와 UI는 이미지에 합치지 않았습니다. 큰 슬로건·소개·첫 방문/이어하기 버튼은 HTML, 대사는 우측 이미지 하단의 `CompanionGreeting`으로 유지합니다. 이미지·그라디언트·대사를 하나의 슬라이드에 넣고 같은 CSS 알파 마스크로 지우므로 다음 이미지와 다음 대사가 함께 드러납니다. 배너 캐릭터와 실제 공부 중인 룸은 독립적이며 이어하기는 실제 세션/최근 룸을 따릅니다.

지우기는 768px 이상 hover/fine 마우스에서만 켜고 모션 감소에서는 끕니다. 이름/초상화 선택 버튼은 모든 입력 방식에서 사용할 수 있습니다. 모바일에서는 버튼을 그림 위로 겹치지 않고 문구 아래에 둡니다. Canvas 미지원·이미지 로딩 지연 시 현재 그림을 보여 줍니다. [전체 동작과 수정 지점](../HOVER_SCRATCH_BANNERS.md).
