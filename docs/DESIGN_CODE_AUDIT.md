## 공통 버튼 규칙

| size | 최소 높이 | 글자 크기 | 용도 |
| --- | ---: | ---: | --- |
| xs | 32px | 12px | 휠의 완료 버튼, 조밀한 보조 조작 |
| sm | 40px | 13px | 일정 추가, 이미지 저장·공유 같은 도구 버튼 |
| md | 44px | 14px | 헤더의 충전하기, 상품 카드의 결제하기, 등급 올리기 |
| lg | 48px | 15px | 폼 저장·로그인·공부 시작·선물 보내기·카드 받기 등 주요 실행 |

Button과 ButtonLink는 같은 규칙을 사용합니다. 크기를 바꿀 때 size를 지정하고, 글자 크기·줄 높이·패딩을 페이지에서 각각 재지정하지 않습니다. 긴 문구가 좁은 화면에서 줄바꿈되면 높이는 내용에 맞게 늘어납니다.

primary는 기존 보라 그라데이션, secondary는 주변 바탕과 구분되는 옅은 배경, soft는 기존에 요청된 연한 보라 배경, ghost는 배경 없는 보조 버튼입니다. 비활성 버튼에는 호버 배경 변화가 적용되지 않습니다. 카카오 버튼의 브랜드 색상과 홈 히어로의 강조 표현은 전용 스타일을 유지합니다.

외곽선 제거 후 바탕과 섞이던 보조 버튼은 button-subtle 표현을 공유합니다. 기본 배경은 흰색 약 5%, 호버는 약 9%이며, @theme의 color-button-subtle·color-button-subtle-hover에서 관리합니다. 목표 시간·날짜의 미선택 빠른 버튼, 미리 듣기·반응 닫기·등급 올리기, 일괄 선택·공부 조작부에 적용합니다. 선택 상태의 보라색 배경과 강조선은 유지합니다. 내 기록·마이페이지 달력의 좌우 화살표와 닫기(X) 버튼은 기본 배경 없이 호버·포커스 효과만 사용합니다.

## 글자와 여백 규칙

[index.css](../src/styles/index.css)의 @theme에서 다음 기준을 관리합니다.

| 역할 | 토큰 | 기준 |
| --- | --- | ---: |
| 폼 라벨 | text-label | 14px / 줄 높이 20px |
| 보조 설명 | text-caption | 12px / 줄 높이 18px |
| 입력값 | text-control | 15px / 줄 높이 20px |
| 카드 제목 | text-card-title | 16px / 줄 높이 24px |
| 조밀한 카드 제목 | text-card-title-compact | 14px / 줄 높이 20px |
| 섹션 제목 | text-section-title | 18px / 줄 높이 28px |
| 페이지 제목 | text-page-title | 30px / 줄 높이 40px |
| 모달 제목 | text-dialog-title | 20px / 줄 높이 28px |

Panel의 기본 여백은 모바일 20px, sm 이상 24px입니다. compact는 20px, roomy는 모바일 24px·sm 이상 32px입니다. 일정 목록은 roomy, 달력과 기록의 일반 카드는 기본 밀도를 사용합니다. Panel은 기본적으로 외곽선이 없습니다.

공통 섹션 간격은 40px, 콘텐츠 간격은 24px, 조밀한 콘텐츠 간격은 16px입니다. 가격·공부 시간·차트 눈금·영수증·포스터와 히어로·채팅 조작부는 역할에 필요한 별도 글자 크기를 유지합니다. StatCard의 조밀한 숫자는 size=compact로 지정합니다.

## 컴포넌트 사용과 동작

- SearchField는 룸 검색과 친구 검색에서 외곽선 없이 모서리와 패딩을 공유합니다. 필터링 로직은 각 페이지가 관리합니다.
- WheelField는 입력 틀을 담당하고, DateTimeWheelField·WheelSelectField는 값과 열 구성을 담당합니다. 종류의 낮은 휠과 날짜·시간의 여러 열 구성을 유지합니다.
- 휠 조작은 즉시 입력값에 반영되며, 선택창은 한 번에 하나만 펼쳐집니다. 완료·Escape는 선택창만 닫고, 일정은 저장하기를 누를 때 저장합니다.
- Dialog의 modal·sheet·popover는 배치 방식입니다. 모두 네이티브 모달로 동작하므로 배경은 조작되지 않고 스크롤이 잠깁니다. 시트·팝오버는 부모 패널을 기준으로 배치하며 화면 크기가 바뀌면 다시 맞춥니다.
- 모달은 창 안에서 시작한 드래그가 밖에서 끝나도 닫히지 않습니다. 바깥에서 시작해 바깥에서 끝난 클릭·탭, Escape, 닫기 버튼으로 닫습니다.
- 컴포넌트 안의 선택·저장·결제·업그레이드 동작은 기존 도메인 로직을 사용합니다. 기존에 요청된 외곽선 제거와 연한 결제 버튼도 유지했습니다.

- 카드·배너·입력창·버튼·선택 컨트롤·아바타의 기본 외곽선과 링, 안쪽 선 형태의 하이라이트를 제거했습니다.
- 일정 추가·수정의 종류·이름·날짜·시간, 로그인·회원가입의 이메일·비밀번호·비밀번호 확인, 내 아바타 만들기의 이름 입력은 예외로 1px 외곽선을 사용합니다. 각 폼에서 --form-input-border를 지정하며, 포커스·펼침 강조는 기존 규칙을 따릅니다.
- 헤더·푸터·표의 행·목록·영수증 내부의 구분선은 유지합니다.
- 호버·클릭·선택·펼침·키보드 포커스에서 나타나는 테두리와 강조선은 유지합니다. 상품 카드의 호버 광택과 공부 타일의 반응 강조도 유지합니다.
- 상태 변경 때 크기가 바뀌지 않도록 필요한 컨트롤에는 투명 테두리 공간을 남깁니다. 체크박스와 라디오의 미선택 상태는 배경색으로 구분합니다.
- 아이콘·차트·진행률 원의 선은 정보 표시이므로 유지합니다.

## 친구 관계 단계와 진행률

2026-10-28 · 현재 레벨과 진행률을 RelationshipProgress 컴포넌트에서 함께 표시합니다.

- 현재 레벨(Lv.3 친구 등)은 막대 위 왼쪽에, 다음 레벨까지의 진행률(Lv.4까지 60% 등)은 오른쪽에 표시합니다.
- 다섯 칸 아래에 Lv.1~Lv.5를 모두 표시하고 현재 레벨을 강조합니다. 도달한 레벨은 전체를 채우고, 다음 레벨 칸은 진행률만큼 밝은 보라색으로 채웁니다.
- 기존 친구별 공부 시간 배분과 600분마다 레벨이 오르는 기준을 사용합니다. 진행률은 소수점 한 자리까지 표시합니다.
- Lv.5에서는 다섯 칸을 모두 채우고 최고 레벨로 표시합니다. 이후 공부 시간이 늘어나도 진행률 100%·남은 시간 0분을 유지하며 Lv.6을 안내하지 않습니다.
- 남은 시간은 막대의 호버·키보드 포커스에서 볼 수 있습니다. Escape로 안내를 닫을 수 있으며, 보조 기술에는 현재 레벨·다음 레벨·진행률·남은 시간을 전달합니다.

## 카메라·마이크와 브라우저 모델 연결

2026-10-28 · 공부 전 확인 1/2와 공부 화면의 샘플 카메라를 실제 장치 연결로 교체했습니다.

- `DeviceController`는 사용자 동작 뒤 카메라·마이크 권한을 따로 요청합니다. 중복 요청, 권한 거부 후 재시도, 장치 분리, 화면 이탈 후 도착한 권한 응답을 처리합니다.
- `MediaProvider`가 준비→목표 설정→공부 사이에 같은 트랙을 유지합니다. 종료·로그아웃·관련 화면 이탈 시 트랙을 해제하며 일시정지·휴식·숨김 탭에서는 추론을 중단합니다.
- `DeviceCheck`, `CameraPreview`, `MicrophoneMeter`, `DetectionStatus`로 미리보기·입력 확인·감지 상태를 분리했습니다. 영상과 감지 표시를 함께 좌우 반전하고 실제 영상 비율에 맞춰 정렬합니다.
- 공식 Face Landmarker float16 v1을 Worker에서 실행합니다. GPU 추론 우선, CPU/WASM 대체 경로를 지원합니다. MediaPipe 영상 입력에 필요한 WebGL 자체가 차단된 경우에는 안내와 카메라 없이 진행하기를 제공합니다. YOLO는 MVP 이후 대상입니다.
- 첫 실제 얼굴 추론이 완료된 뒤 다음 버튼을 활성화합니다. 마이크 권한 거부가 카메라를 막지 않으며, 모델 로딩만 재시도할 때 장치 권한을 다시 요청하지 않습니다.
- 영상·소리를 서버에 전송하거나 녹화·녹음하지 않습니다. 마이크는 Web Audio 입력 크기 확인에만 사용합니다. MVP 집중률은 정상 관측 시간 중 얼굴이 보인 시간으로 계산하며, 새 세션에는 더미 집중률을 생성하지 않습니다.
- 모델 원본·해시·라이선스를 `public/models`와 `public/licenses/vision`에 보관했습니다. 설치·개발·빌드 시 패키지의 로컬 MediaPipe 런타임을 준비합니다. YOLO·ONNX 가중치와 실행 파일·의존성을 배포물에서 제거했습니다.

### 장치 확인 화면 크기와 표시 시점

공부 전 장치 확인 화면의 최대 너비를 720px에서 1040px로 늘렸습니다. 데스크톱 카메라 영역은 약 584×438px이며 아바타, 제목, 장치 버튼, 마이크 입력 표시도 함께 키웠습니다. 768px 미만에서는 세로로 배치합니다. 목표 설정 화면은 기존 720px를 유지합니다.

화면 제목은 `카메라·마이크를 확인해요`로 통일하고 중복 소제목, `1 / 2 · 처음 한 번만` 배지, 카메라 안내 캡션을 제거했습니다. 마이크 확인 영역은 켜기 버튼을 누르면 표시하며, 권한 확인 중에도 표시됩니다. 이미 연결한 장치를 다시 확인할 때는 연결 상태를 그대로 보여 줍니다.

검증: 320·390·640·768·1024·1440px의 배치, 클릭 전 마이크 영역 숨김·클릭 직후 표시, 실제 입력 레벨과 모델 추론, 목표 설정·돌아오기·장치 해제를 포함한 브라우저 확인 56개 통과.

### 장치 상태와 버튼 정렬

오른쪽 내용을 카메라·마이크 두 상태 항목으로 묶고 공통 `DeviceCheckItem`에서 제목·상태·버튼·상세 영역의 간격을 관리합니다. 버튼은 각 항목 오른쪽에 정렬하며, 오류 안내는 해당 장치 항목 안에 표시합니다. 배경으로 항목을 구분하고 기본 외곽선은 추가하지 않았습니다.

공통 `DeviceCheckStatus`는 정상 연결에 초록 체크, 연결 실패에 분홍 엑스, 꺼진 장치에 회색 엑스, 확인 중에는 시계, 최초 연결 대기에는 중립 표시를 사용합니다. 아이콘과 상태 문구를 함께 표시합니다. 카메라 연결과 얼굴 감지 결과는 분리해, 장치 연결 성공과 감지 실패를 구분할 수 있습니다.

마이크 영역은 켜기 버튼을 누른 뒤 표시합니다. 마이크는 실제 AudioContext 연결까지 성공한 뒤 체크를 표시하고, 입력 초기화 실패도 엑스로 안내합니다. 입력을 확인할 수 없는 상태에는 비어 있는 레벨 막대를 남기지 않습니다. 장치별로 끄기·켜기와 오류 복구를 수행할 수 있습니다.

검증: lint·build 통과. 브라우저 확인 63개 통과. 320·390·640·768·1024·1440px에서 정렬·내용 넘침·외곽선, 실제 얼굴 감지와 마이크 입력, 권한 대기·거부·재연결, 입력 오류·감지 파일 로딩 실패 후 복구, 목표 설정 복귀와 장치 해제를 확인했습니다.

### 준비 화면의 돌아가기와 목표 선택

두 준비 화면의 돌아가기를 `OverlayPage`의 내용 창 첫 항목으로 이동했습니다. 창 내부 패딩에 맞춰 왼쪽 위에 배치하며, 문서 흐름에 포함해 제목과 겹치지 않고 함께 스크롤됩니다. 1/2 제목을 `카메라·마이크를 확인해요`로 바꿔 2/2의 `목표 시간을 정해요`와 해요체를 맞췄습니다.

목표 시간의 25·50·90분 빠른 선택 버튼 영역을 제거했습니다. 기본 50분, 5~180분의 5분 단위 슬라이더, 키보드 조작, 이전 단계로 돌아갈 때의 목표 유지 기능을 제공합니다.

검증: lint·build 통과. 320·390·640·768·1024·1440px에서 두 화면의 돌아가기 위치·제목 배치·내용 넘침, 빠른 선택 제거, 슬라이더 키보드 조작·최솟값·최댓값·선택 유지와 기존 이동 경로를 포함한 브라우저 확인 61개 통과.

### MVP: MediaPipe 단독 감지와 실제 집중률

YOLO 기반 휴대폰 감지는 MVP 이후로 미뤘습니다. YOLOX-Nano 모델·전처리·후처리·테스트, ONNX Runtime 의존성과 실행 파일, 미사용 라이선스 파일을 제거했습니다. MediaPipe에서는 얼굴 존재와 미리보기 표시용 얼굴 좌표만 사용하며 눈 감김 점수 추론은 요청하지 않습니다.

`FaceFocusTracker`는 신선한 얼굴 관측 사이의 실제 시간을 누적합니다. 집중률은 **얼굴이 보인 시간 / 정상 측정 시간 × 100**입니다. 얼굴 미감지는 비집중 시간으로, 유효한 미감지→감지 전환은 복귀로 집계합니다. 준비 화면·모델 초기화와 오류·카메라 꺼짐·일시정지·휴식·숨김 탭·1초를 넘는 프레임 공백은 새 측정을 만들지 않습니다.

누계는 초당 한 번 `FACE_FOCUS` 액션으로 세션에 저장하고, 일시정지·카메라 끄기·종료 전에 마지막 신선한 구간을 반영합니다. 세션 ID, 중복·역순 값, 실제 공부 시간 상한을 검증합니다. 재접속 시 누계를 복원하되 이전 프레임 시각은 복원하지 않아 오프라인 공백이 집중이나 미감지 시간으로 추가되지 않습니다.

새 기록의 `observedSeconds`로 측정 시간과 전체 공부 시간을 구분합니다. 공부 화면·종료 리포트·내 기록·친구별 집계가 같은 분모를 사용합니다. 관측이 없는 기록은 `—`로 표시하고 샘플 집중률·고정 복귀 횟수를 만들지 않습니다. 이전 샘플 기록과 사용자 기록은 유지합니다. 실제 기록에는 예시 집중 타임라인을 표시하지 않으며, 1분 미만의 측정 시간은 초 단위로 표시합니다.

검증: 타입 검사·lint·build 통과, 단위 테스트 70개 통과. 격리된 브라우저에서 테스트 카메라 영상과 실제 MediaPipe 추론으로 확인한 항목은 43개입니다. 얼굴 미감지에 따른 집중률 감소, 일시정지·숨김 탭·카메라 꺼짐·감지 오류 제외, 재접속 누계 복원, 종료 리포트·내 기록·캡슐 카드 일관성, CPU 대체 실행과 WebGL 미지원 안내를 확인했습니다. 카메라·마이크 데이터의 업로드와 YOLO·ONNX 요청은 발생하지 않았습니다.

### 준비 단계 이동과 공통 계정 헤더

1/2의 버튼을 `카메라 없이`, `다음`으로 줄였습니다. 2/2의 돌아가기는 선택한 목표·대화 옵션과 연결된 장치를 유지하며 1/2로 이동합니다. 장치 상태 재확인 영역과 `2 / 2 · 공부 설정` 배지를 제거하고, 대화 옵션을 목표 시간 위로 이동했습니다. 보유 크레딧과 이용 중인 패스 이름 또는 `없음`을 표시하며, 만료된 패스는 이용 중으로 표시하지 않습니다. 시작 버튼은 `시작하기`로 표시하되 기존 요금 계산과 패스 혜택은 유지합니다.

`HeaderAccount`를 추출해 홈·룸 상세에서 잔여 크레딧, 오늘 공부 시간, 아바타와 프로필 메뉴를 공유합니다. 룸 상세의 계정 정보는 모바일에서도 표시하며 긴 룸 이름은 별도 줄로 배치합니다. 비로그인 방문자에게는 로그인 버튼을 표시합니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 42개 통과. 단계 이동과 목표·옵션 유지, 실제 카메라 연결 유지, 요금 차감·패스 혜택, 유효·만료·미보유 패스 표시, 홈·룸 상세의 값 일치, 프로필 메뉴·초기화 창과 크레딧 이동, 320·390·640·768·1024·1440px의 배치와 내용 넘침을 확인했습니다.

### 공부 화면의 내 아바타와 장치 권한 안내

공부 화면의 내 칸은 카메라를 켜거나 끄고 다시 연결해도 항상 프로필 아바타를 표시합니다. 휴식 화면의 내 썸네일에도 같은 아바타를 표시합니다. 실제 카메라 미리보기는 1/2 장치 확인에만 표시하며, 집중률을 측정하는 숨김 영상 입력은 `MediaProvider`에서 독립적으로 유지합니다.

1/2 제목 오른쪽의 `DevicePrivacyInfo` 물음표에서 카메라의 얼굴 감지·집중 시간 측정과 마이크 입력 확인 목적, 영상·소리를 기기 안에서만 처리하고 서버로 전송·저장하지 않는다는 안내를 제공합니다. 상시 개인정보 안내 문단과 미사용 스타일은 제거했습니다. 호버·키보드 초점·터치로 열고, Escape·외부 클릭·초점 이탈로 닫습니다. 설명 위로 포인터를 옮기거나 키보드 초점을 유지한 동안에는 안내가 닫히지 않습니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 30개 통과. 320·390·640·768·1024·1440px 제목·툴팁 배치, 호버 유지·키보드·터치 조작, 안내 열람 중 권한 미요청, 카메라 켜짐·꺼짐·재연결·카메라 없이 시작·휴식 중 아바타 표시를 확인했습니다. 격리된 테스트 카메라와 실제 MediaPipe 추론으로 아바타 뒤에서도 얼굴 감지·미감지가 집중률에 반영되는 것과 미디어 업로드가 발생하지 않는 것을 확인했습니다.

### 장치 확인의 넓은 미리보기와 가로 상태 카드

`device-check`의 좌우 배치를 한 열로 바꿔 카메라 미리보기가 내용 영역의 전체 너비를 사용하도록 했습니다. 최초에는 카메라·마이크 상태 카드를 표시하지 않습니다. 켜기 버튼은 640px 이상에서 미리보기 우측 상단에 겹쳐 두고, 좁은 화면에서는 미리보기 바로 위에 배치합니다. 하단 `카메라 없이`·`다음` 진행 버튼과 분리했습니다.

켜기 버튼을 누른 뒤에는 미리보기 아래에 카메라·마이크 카드 두 개를 같은 줄의 동일한 너비로 표시합니다. 모바일에서도 두 열을 유지하며 각 카드 안의 제목·상태·버튼을 세로로 정렬합니다. 모델 감지, 마이크 입력 확인, 개별 장치 켜기·끄기·재시도와 2/2에서 돌아왔을 때의 연결 상태는 유지합니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 49개 통과. 320·390·640·768·1024·1440px에서 미리보기 너비·켜기 버튼 위치·두 카드의 가로 정렬과 내용 넘침을 확인했습니다. 실제 MediaPipe·마이크 입력, 권한 확인 대기, 마이크만 거부·모두 거부, 카메라 끄기·재연결과 준비 단계 복귀를 확인했습니다.

### 준비 화면 상단 정보·카메라 비율·새 공부 진입

두 준비 화면의 룸 제목·친구 초상화와 이름을 `OverlayPage.headerAside`로 돌아가기 오른쪽 상단에 묶었습니다. 장치 확인·목표 설정 제목은 그 아래에 둡니다. 2/2의 `카메라 없이 시작` 버튼을 제거하고, 단일 `시작하기`가 1/2에서 정한 카메라 사용 여부를 따르도록 했습니다.

고정 미리보기 영역과 실제 영상의 비율 차이에서 생기던 여백을 제거했습니다. `CameraPreview`는 영상의 `videoWidth`·`videoHeight`를 `loadedmetadata`·`resize`에서 반영하고, 연결 중에는 고정 높이 제한을 해제합니다. 영상·얼굴 표시를 같은 영역 전체에 맞추며 카메라를 끄면 기본 아바타 배치로 복원합니다.

홈의 최근 공부 이어하기·룸 상세·친구 화면·휴식 후 새 공부는 이전 카메라 확인 여부와 관계없이 1/2부터 시작합니다. 기존 목표·옵션과 진행 중인 세션의 이어하기는 유지하며, 설정 도중 충전·일정에 다녀오는 경로는 같은 2/2로 복귀합니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 36개 통과. 320·390·640·768·1024·1440px의 상단 정렬·내용 넘침·단일 시작 버튼, 과거 카메라 확인 후 재진입, 카메라 사용·미사용 선택과 실제 MediaPipe 측정을 확인했습니다. 네이티브 테스트 카메라 및 실행 중 영상 해상도를 1280×720·640×480·480×640·1920×1080으로 바꾸어 미리보기·영상·얼굴 표시 영역의 비율과 경계가 일치하는 것을 확인했습니다.

### 장치 카드 한 줄 구성과 크레딧·선물 문구 정리

장치 카드 내부의 구분선을 제거하고 이름·상태·조작 버튼을 한 줄에 정렬했습니다. 마이크 입력 막대도 같은 줄에 둡니다. 768px 이상에서는 두 카드를 나란히, 작은 화면에서는 위아래로 배치해 카드 내부의 한 줄 구성을 유지합니다. 모델 초기화·얼굴 미감지는 상태에 반영하고, 카메라가 연결된 상태의 감지 오류는 별도 오류 안내·재시도로 처리합니다. 마이크 입력 오류·권한 거부도 해당 카드에서 복구합니다.

2/2의 부족 안내를 시작 버튼 아래 중앙으로 옮기고 별도 `크레딧 · 패스 보기` 링크를 제거했습니다. 충전 화면 제목은 토글과 중복되지 않는 `함께할 시간을 더해요`로 바꿨습니다. 내 크레딧의 사용 크레딧 카드에서 항목별 사용 횟수 문구를 제거했습니다.

선물·보이스 화면의 장식 제목·설명·수신자 캡션과 중복 가격을 제거했습니다. 선택 상품 제목과 보유 잔액을 같은 행에 배치하고 부족 안내의 충전 링크에서 화살표를 뺐습니다. 상품 카드·보내기 버튼에는 실제 가격을 유지하며 구매 후 잔액·보관함을 갱신합니다.

`characterUnlocks`에서 해당 친구와 실제 공부 시간이 있는 첫 종료 기록을 찾아 기본 대사·모션이 열린 날짜를 계산합니다. `YY.MM.DD 열림 · 함께한 공부 시간`처럼 날짜와 사유를 함께 표시합니다. 개인·그룹·순서가 섞인 기록을 처리하고, 목표 달성과 별개인 종료 시각을 사용합니다. 기록이 없는 친구의 날짜와 열린 상태를 임의로 만들지 않으며 열린 개수도 실제 표시와 맞춥니다. 서버 해금 이력은 아직 연결하지 않았습니다.

검증: 타입 검사·lint·build 통과, 단위 테스트 73개 통과. 브라우저 확인 36개 통과. 320·390·640·768·1024·1440px의 장치 내부 정렬과 구분선 제거, 실제 얼굴 감지·마이크 입력·감지 오류·마이크 거부·재시도, 준비 안내 위치·충전 토글, 선물 선택·실제 차감·잔액 위치, 콘텐츠 날짜·서울 날짜 경계·기록 없음 표시를 확인했습니다.

### 준비 상단 간격·관계 레벨 중복·홈 이미지 v2

### 공부 화면의 아이콘 독·친구 조작 모드·상단 타이머

`이곳이 나의 자리` 캡션과 `지금은 집중하는 시간`, `각자의 목표, 같은 시간` 문구를 제거했습니다. 내 아바타를 기본 화면과 확대 화면에서 키우고, 공부·휴식의 남은 시간을 공통 `SessionTimer`로 분리해 상단 오른쪽 한 곳에 표시합니다. 카메라를 켜도 아바타가 표시되며 실제 MediaPipe 측정은 독립적으로 계속됩니다.

`StudyDock`에는 확대 모드·말 걸기 모드·일시정지/계속·공부 끝내기를 아이콘만으로 표시합니다. 확대 모드(V)에서는 친구 카드 전체를 눌러 확대·복원하고, 말 걸기 모드(C)에서는 누른 친구의 대화를 엽니다. 작은 친구에게 말을 걸면 해당 친구를 확대 영역으로 옮깁니다. 개별 카드의 말 걸기 버튼은 제거하고, 대화창에는 닫기 버튼을 추가했습니다. 도구만 바꿀 때 입력 중인 내용을 유지하며, 입력 필드에서는 단축키가 작동하지 않습니다. Escape는 대화창을 먼저 닫고 다음 조작에서 확대를 해제합니다.

[UI Beats Dock](https://uibeats.com/docs/component/dock)의 포인터 근접 확대와 [Animate UI Lucide Icons](https://animate-ui.com/docs/icons/lucide-icons)의 아이콘 움직임을 참고했습니다. 기존 `Icon`과 자체 CSS로 구현하며 라이브러리를 추가하지 않았습니다. 선택 모드·호버/초점 설명·방향키 이동을 제공하고, 터치와 움직임 줄이기 설정에서는 확대 효과를 제한합니다. 미사용 독·타이머·캡션 스타일을 제거하고 한 친구 확대 화면의 빈 사이드바 행도 정리했습니다.

검증: 타입 검사·lint·build 통과, 단위 테스트 77개 통과. 브라우저 확인 46개 통과. 320·390·640·768·1024·1440px의 내용 넘침과 타이머·독 위치, 포인터 확대·툴팁·방향키·터치·움직임 줄이기, 모드 전환·대화 대상·입력 보존·빠른 Escape·확대 복원, 일시정지·재개·종료 리포트를 확인했습니다. 테스트 카메라와 실제 MediaPipe 추론으로 큰 아바타 뒤에서도 측정이 유지되는 것을 확인했습니다.

### 공부 헤더의 경과·목표 시간과 집중률 색상

공부 타이머를 `목표 50분`과 남은 시간 대신 `00:17:23 / 00:50:00` 형태의 경과 시간 / 목표 시간으로 변경했습니다. 경과 시간은 0초부터 늘어나고 일시정지·재개 시 기존 세션의 시간을 이어갑니다. 휴식은 같은 헤더에서 기존 남은 시간 카운트다운을 사용합니다.

내 아바타 영역의 집중률을 `SessionFocus`로 분리해 헤더의 타이머 왼쪽으로 옮겼습니다. 50% 미만은 빨강, 50~80% 미만은 흰색, 80% 이상은 초록으로 표시하며 측정 전에는 회색 `—`를 표시합니다. 실제 관측값과 집중률 계산은 유지합니다. 모바일에서는 헤더 두 번째 줄에 집중률과 타이머를 나란히 배치합니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 37개 통과. 0·49.9·50·79.9·80·100%의 표시값·색상, 미측정 표시, 경과·목표 시간 분리, 일시정지·재개, 최대 3시간 목표, 목표 도달 후 휴식 전환, 320·390·640·699·700·768·1024·1440px의 헤더 겹침·넘침을 확인했습니다.

### 영상 위의 원형 글래스 독과 장치·내 화면 전환

내 이름 배지와 내 칸의 카메라·마이크 버튼을 제거했습니다. `StudyDock`에 실제 마이크·카메라 켜기/끄기와 아바타/실제 캠 전환을 추가하고, 모든 아이콘을 원형 버튼으로 바꿨습니다. 독에는 반투명 배경·블러·빛 반사를 적용하며, 1:1·여러 친구·확대 배치 모두 영상 영역 위에 겹칩니다. 하단의 별도 독 여백을 제거했습니다. 휴식에도 장치·보기·일시정지·종료 조작을 제공합니다.

`StudySelfView`는 기본 아바타와 같은 카메라 스트림의 음소거 미리보기를 전환합니다. 아바타로 바꿔도 트랙과 MediaPipe 측정을 유지하고 카메라 자체를 끄면 미리보기를 아바타로 복원합니다. 카메라가 꺼진 상태에서 실제 캠 보기를 선택하면 명시적으로 연결을 요청하며, 권한 거부 시 아바타와 복구 안내를 표시합니다. 공부 종료 시 기존 장치 해제를 유지합니다.

### 공통 오른쪽 채팅 패널·타이핑·숫자 전환

카드 안의 짧은 채팅과 별도 휴식 채팅을 `SessionChatPanel` 하나로 통합했습니다. 독의 말 걸기 모드(C)·헤더 버튼으로 열고, 친구 카드나 패널의 채린·수아·다희 토글로 상대를 바꿉니다. 대화 상대는 URL의 `friend`, 열림 상태는 `chat`, 영상 확대는 `focus`로 독립 관리합니다. 친구별 대화 이력과 입력 중인 초안을 유지하며 대화 상대를 바꿔도 확대 영상은 바뀌지 않습니다.

1024px 이상에서는 영상 옆 사이드바로, 작은 화면에서는 오른쪽 모달 드로어로 열립니다. native dialog의 초점 제한과 기존 배경 스크롤 차단을 사용하고 Escape·외부 클릭·닫기 버튼으로 닫으며 초점을 복원합니다. 공부·휴식·1:1·여러 친구 화면에 공통으로 적용했습니다.

새 친구 답장에는 `TypingMessage`의 글자 출력과 커서를 적용합니다. 전체 문장은 보조 기술에 한 번만 제공하고 이전 이력을 다시 열 때 효과를 반복하지 않습니다. 입력창은 캡슐에서 확장되며 Enter 전송·Shift+Enter 줄바꿈·한글 조합 중 전송 방지를 지원합니다. 이름·실제 전송 시각과 내 메시지의 전송 상태를 말풍선 바깥에 표시하며, 시각이 없는 기존 메시지는 그대로 둡니다. 무료 대화 한도·음성 체험·옵션 변경·차액 차감을 유지하고, 답장 출력 중 업그레이드 창을 자동으로 열지 않습니다.

타이머는 `AnimatedClock`으로 분리했습니다. 바뀐 숫자만 흐림과 상하 이동으로 전환하며, 공부는 위로·휴식은 아래로 움직입니다. 구분자와 목표는 고정하고 이전 숫자 요소는 전환 후 제거합니다. 움직임 줄이기 설정에서는 패널·타이핑·숫자 효과를 생략합니다. 사용하지 않는 `BreakConversation`, 세션 아이콘 매핑, 기존 채팅·휴식 레이아웃 스타일을 제거했습니다.

시각 참고는 [SmoothUI Sidebar](https://smoothui.dev/docs/primitives/sidebar), [Kokonut Typing Text](https://kokonutui.com/docs/texts/type-writer), [unlumen Animate Digits](https://ui.unlumen.com/components/animate-digits), [AI Chat Input](https://cdn.21st.dev/easemize/ai-chat-input/default/bundle.1783271974589.html), [Message With Header And Delivery Status](https://21st.dev/@sean0205/components/c-message-3)입니다. 화면과 동작을 확인하고 자체 React·CSS·Web Animations API로 구현했으며 패키지를 추가하지 않았습니다.

검증: 타입 검사·lint·build 및 단위 테스트 77개 통과. 브라우저 확인 57개 통과. 친구별 초안·이력·재접속 대상, 새 답장 타이핑·이력 재생 방지·보조 기술용 문장, 전송 시각·한글 조합·줄바꿈·빠른 답장, 무료 한도·중첩 옵션 창·차액 결제, 숫자 변경·방향·정리·일시정지와 움직임 줄이기를 확인했습니다. 320·390·640·768·1023·1024·1440px와 작은 높이의 패널 경계·입력 위치·배경 스크롤·Escape·외부 클릭·초점 복원, 실제 MediaPipe와 카메라 표시 유지, 휴식·종료 기록을 확인했습니다.

### 채팅 재열기 높이 계산과 확대 표시 정리

채팅 입력창이 숨겨져 있거나 사이드바 폭이 전환 중일 때 높이를 계산한 뒤 갱신하지 않아, 같은 초안도 다시 열면 높이가 달라지는 현상을 확인했습니다. `ChatComposer`는 보이지 않는 폭에서는 계산을 건너뛰고 `ResizeObserver`로 실제 입력 폭이 바뀔 때 높이를 재계산합니다. 높이 변경만으로는 관찰 콜백을 반복하지 않으며, 기본 24px·최대 120px 범위에서 내용에 맞춰 늘거나 줄어듭니다.

`Shift + Enter로 줄바꿈` 안내와 확대 시 이름 옆의 `확대` 표시, `tile-focus` 복원 버튼·관련 속성·미사용 스타일을 제거했습니다. 줄바꿈 기능과 확대 모드에서 카드 재클릭·Escape로 원래 보기로 돌아가는 동작은 유지합니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 24개 통과. 같은 초안의 반복 재열기, 패널이 열리는 도중 입력, 내용 삭제 후 축소, 320·390·768·1024·1440px에서 빈 입력·긴 내용 제한·짧은 초안 재열기, 안내·확대 장식 제거, 카드 클릭 복원과 줄바꿈·전송을 확인했습니다.

### 타이핑 속도·한글 단축키·화면 중앙 옵션 모달

친구 답장의 글자 출력 간격을 기본 최대 26ms에서 32ms로 늘렸습니다. 긴 문장의 가변 간격도 함께 늦추며, 이미 읽은 대화와 움직임 줄이기 설정은 기존처럼 즉시 표시합니다.

C/V 모드 단축키는 입력 문자 대신 `KeyboardEvent.code`의 `KeyC`·`KeyV`를 먼저 사용해 한글 `ㅊ`·`ㅍ` 및 IME Process 이벤트에서도 같은 물리 키로 동작합니다. 글을 쓰는 입력·편집 영역의 조합 중 입력과 수정 키 조합, 모달 상태에서는 모드를 전환하지 않습니다.

옵션 변경 창에서 사이드바 기준 sheet/popover 위치 지정을 제거하고 공통 화면 중앙 모달을 사용합니다. `닫고 쉬기`와 현재 옵션·차액 설명 문단을 제거하고, 부족 안내 및 남은 크레딧 링크를 중앙 정렬했습니다. 차액 계산·잔액 부족 시 비활성화·구매 후 옵션과 잔액 갱신은 유지합니다.

검증: 타입 검사·lint·build 통과. 브라우저 확인 31개 통과. 한글·영문·IME Process 키, 입력·수정 키·모달의 단축키 차단, 느려진 답장 출력 시간을 확인했습니다. 베이직·스탠다드 옵션 창, 부족 안내·비활성화·실제 차액 차감, 320·390·768·1024·1440px의 전체 화면 중앙 배치, Escape 후 부모 대화 유지와 초점 유지를 확인했습니다.

### 종료 정보·관계 증가 애니메이션·전용 이미지·공식 캡슐카드

종료 화면의 장식용 CAPSULE, 얼굴 관측 시간 설명과 인물 하단의 관계 배지를 제거했습니다. 룸 이름은 제목 아래에 두고 완료 시각·대화 옵션은 별도 메타 행으로 묶었습니다. 공부 시간·목표·집중률·미감지·복귀는 실제 기록을 유지합니다. 참여한 친구의 이미지를 선택할 수 있으며 친구별 관계 증가는 서로 읽기 쉬운 행으로 분리했습니다.

`reportRelationship`은 해당 종료 시점 이전 기록만 합산하고 공통 친구별 시간 배분과 레벨 상수를 사용합니다. `RelationshipGain`은 실제 이전 진행도부터 이번 증가분까지 채웁니다. 경계를 넘으면 100%에서 링·빛·입자 효과를 표시한 뒤 새 레벨의 남은 진행도를 채웁니다. 다음 단계 문구와 축하 안내의 공간을 확보해 애니메이션 중 배치가 밀리지 않게 했습니다. 과거 리포트에는 이후 공부를 포함하지 않으며 1분 미만의 시간과 최대 Lv.5를 처리합니다. 움직임 줄이기에서는 최종 값과 정적인 레벨 상승 안내만 표시합니다.

내장 `image_gen`으로 채린·수아·다희의 밝게 웃는 1024×1536 전용 이미지를 각각 생성했습니다. 기존 얼굴·복장은 유지하고 노을빛·차분한 창가·활기찬 운동장 옆 분위기로 구분했습니다. `src/assets/reports/completion-v1/`에 PNG·WebP·전체 프롬프트·참조 경로·해시를 보관합니다. 웹 파일 합계는 672,610바이트입니다. 홈과 공부 화면의 기존 이미지는 교체하지 않았습니다.

캡슐카드에서도 같은 참여 인물을 선택하며, 공식 로고와 기존 홈용 투명 제목을 이미지 왼쪽 위에 배치합니다. 일반 텍스트 룸 제목과 CAPSULE 문구는 제거했습니다. 미리보기뿐 아니라 `exportCard`의 PNG에도 실제 선택 인물·로고·제목을 합성하고 카드 색·저장·공유·다음 약속 기능을 유지합니다. 다른 룸은 기존 초상화·장면을 사용합니다.

검증: 타입 검사·lint·build와 단위 테스트 83개 통과. 브라우저 확인 38개 통과. 이전 진행도·실제 증가분·레벨 상승·최대 레벨·짧은 공부·미측정 표시, 세 친구 이미지 선택·리포트에서 카드로 선택 유지, 움직임 줄이기, 320·390·768·900·1024·1440px의 넘침을 확인했습니다. 다희·수아·도윤의 실제 720×1200 PNG를 저장하고 선택 이미지·공식 로고·제목의 Canvas 합성, 다른 룸 대체 이미지와 카드 색 변경을 확인했습니다.

### 캡슐카드 입체감·홀로그램과 약속 설정 정리

왼쪽 미리보기의 효과를 `CapsuleCardSurface`와 전용 CSS로 분리했습니다. [3D Card](https://www.shadcn.io/ui/card-3d)의 기울기와 층별 깊이, [Holo Card](https://reactbits.dev/components/holo-card)의 홀로그램 반사와 반짝임을 참고해 기존 React·CSS로 구현했습니다. 포인터 위치를 프레임당 한 번 CSS 변수로 반영하며, 변형하지 않는 바깥 영역을 기준으로 계산해 흔들림을 방지합니다. 반사 강도는 밝은 카드에서 낮추고 장식 레이어는 클릭이나 보조 기술의 읽기에 관여하지 않습니다. 키보드 초점은 고정된 입체감을 표시하고 터치 스크롤과 움직임 줄이기를 지원합니다. 새 패키지는 추가하지 않았습니다.

`공부 약속은 모든 친구가 함께 기억해요.`, `이미지로 저장하거나 스토리에 공유해 보세요.`와 오늘·내일·모레 버튼을 제거했습니다. 날짜·시간 휠, 약속 저장, 친구·색 선택과 실제 PNG 저장을 유지합니다.

검증: 타입 검사를 포함한 build와 lint 통과. 브라우저 확인 32개 통과. 포인터 양방향 기울기·층별 깊이·반사 이동·벗어날 때 복원, 키보드 초점·복원, 네 가지 색과 세 친구 선택, 실행 중 움직임 설정 변경, 320·390·640·768·1024·1440px의 가로 넘침, 터치 스와이프 스크롤을 확인했습니다. 720×1200 PNG 다운로드, 날짜·시간 휠의 즉시 반영·단일 펼침과 공통 일정 저장을 확인했고 브라우저 오류는 없었습니다.

### 캡슐카드 로고의 흰 바탕 제거

`CapsuleCardBrand`에서 흰 바탕을 제거하고 공식 로고의 투명도를 그대로 사용합니다. 보라·검정 카드에서는 글자 영역에만 밝은 색을 입히고, 연보라·라벤더에서는 원래 보라색을 표시합니다. 캡슐 아이콘의 색·입체감을 보존하고 작은 그림자로 구분합니다. Canvas 저장도 흰 판을 그리지 않으며 동일한 글자 마스크·색과 원본 아이콘을 합성합니다.

검증: 타입 검사를 포함한 build와 lint 통과. 브라우저 확인 25개 통과. 네 가지 배경의 글자 색 전환·원본 아이콘 보존, 실제 720×1200 PNG의 로고 주변 픽셀이 카드 색과 같은지 확인했습니다. 320·390·768·1440px의 넘침, 기존 호버 기울기와 상시 홀로그램 제거 상태를 확인했으며 브라우저 오류는 없었습니다.

### 정중앙 호버 색감으로 카드 저장·공유

`capsule-card-material.ts`에서 호버의 그라데이션과 강도를 미리보기·PNG에 공유합니다. Canvas는 포인터가 50%/50%에 있을 때의 그라데이션, 반짝임 마스크와 빛 반사를 같은 순서로 합성합니다. 배경에만 적용해 원래 로고·사진·글자의 색과 가독성을 유지하며, 모서리의 투명도도 보존합니다. 저장과 스토리 공유는 같은 `exportCard`를 사용해 버튼을 누르기 전 마우스 위치나 모바일·움직임 줄이기 설정에 영향을 받지 않습니다.

검증: 타입 검사를 포함한 build와 lint 통과. 브라우저 확인 33개 통과. 네 가지 색의 실제 정중앙 호버와 PNG 배경 표본을 비교해 채널별 평균 차이가 1/255 미만임을 확인했습니다. 실제 720×1200 PNG의 투명 모서리, 직전 포인터 위치별 파일 일치, 공유 파일과 다운로드·공유 미지원 다운로드의 바이트 일치, 터치·움직임 줄이기에서 동일한 파일 생성과 제거한 장식의 부재를 확인했으며 브라우저 오류는 없었습니다.
