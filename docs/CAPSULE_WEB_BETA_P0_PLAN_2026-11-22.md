## 전체 단계에 적용할 출시 필수 정책

- **범위 정리:** 공부 준비·목표 시간 선택·여러 친구 선택·쉬는 시간·일정·캡슐 카드·다음 약속·선물·패스·유료 결제·수동 판매·영수증과 관련 진입점을 제거한다. 호그와트·말포이·슬리데린 등 특정 작품 관련 에셋을 제외한다. 모바일·결제·UGC·19세 메이트는 이번 목표에 넣지 않는다.
- **대화와 관계:** 메이트당 대화방 하나를 유지하고 연결을 끊어도 기록·기억을 이어 간다. 초기화는 대화 기록·기억·친밀도·해금을 지우므로 명시적 확인 후 처리한다. 친밀도 해금 레벨과 그날의 분위기를 분리하고, 추천 시간값을 확정 수치로 취급하지 않는다. 베타 전원 강화 기억 정책을 확인한다.
- **가입과 안전:** 만 14세 이상 가입, 만 19세 미만 하루 3시간 제한을 서버에서 집행한다. 출시 메이트는 전연령이며 미성년 캐릭터의 관계 상한·입출력 탐지·단계별 경고/정지/초기화·제재 로그와 검수 결과를 확인한다. 프런트 안내만으로 생성 단계 안전장치가 완료됐다고 판정하지 않는다.
- **카메라:** 권한 요청 전 안내와 카메라 없이 사용하기를 제공한다. 영상은 브라우저 안에서 판정하며 저장·전송하지 않고 상태·시간만 전달한다. 실제 반응 범위는 확정 후 구현한다.
- **과금과 상태:** 베타는 프로 기능 전체 개방·일반 사용자 연결 시간 무제한이다. 크레딧 소진은 연결을 끊는 이유가 아니다. 잔액·차감·초대 보상·일일 제한은 서버 기준이며 중복 요청과 재접속으로 우회되지 않아야 한다.
- **데이터와 운영:** 대화·친밀도·함께한 시간은 서버 저장과 기기 간 동기화를 확인한다. 로그아웃·계정 변경 시 계정 간 데이터가 섞이지 않아야 한다. 탈퇴 시 관련 데이터 삭제와 크레딧 소멸 안내를 반영한다. 최대 100명·베타 기간 운영 설정도 확인한다.
- **측정:** 연결/캠 측정 시간, 카메라 켜기, PIP 전환, 음성 사용, 크레딧 사용·소진, 친구 초대, 재방문과 사용자별 원가를 수집한다. 장시간 연결·PIP·백그라운드 성능과 실제 STT/TTS 지연을 측정하고 결과를 기록한다.

## P0 30개 항목별 상태 · 9차 확인

## 12차 진행 · 현재 API에 맞춘 요청·검증 정정

사용자의 “API 관련해서 자세하게 대조하고 API에 맞춰” 요청에 따라 24개 경로·27개 작업·69개 스키마와 공개 `develop` 커밋 `de5aa98`의 컨트롤러·DTO·서비스·설정·API 테스트를 대조했다. 새 API/스키마 추가는 없으며, 상세는 [11/22 API 감사](API_AUDIT_2026-11-22.md)·[기계 비교 결과](API_AUDIT_2026-11-22.json)에 보관한다.

- **신규 연결 400:** 현재 API에서 실제 필수인 `targetMinutes`를 전송한다. 직접 연결은 기존 API/기존 프런트 기본값 50분을 사용하며, 명시한 값은 3 또는 5~180의 5분 단위만 허용한다. 베타 화면의 목표 선택/카운트다운·목표 도달 자동 종료는 추가하지 않았다. 목표 없는 서버 생성·종료 대사의 미달 판단은 R09에 계속 남는다. 이전 “서버 변경 전 신규 연결 차단” 상태는 이 호환 구현으로 갱신했다.
- **복구 heartbeat:** 이전 presence 이력이 없는 연결에서도 필수 시간 본문을 전송한다. 과거 미측정 구간은 이미 보수적으로 자리 비움으로 계산되며, 실제 캠 시간으로 채우지 않는다. 401→토큰 갱신 뒤 동일 본문 재전송도 확인했다.
- **검증·오류:** 서버와 같은 인증번호 재전송 60초·기본 유효시간 5분, Unicode code point 기준 닉네임 20자, 요청 DTO의 런타임 필수 필드 20개·이벤트 enum을 반영했다. HTTP/SSE 오류의 code/detail을 유지하며 읽을 수 있는 안내로 표시한다.
- **검토 transport:** 목표 시간/heartbeat 필수 값을 독립 검증하고, 실제 상태 코드와 raw SSE done을 반영해 잘못된 요청이 검토 화면에서 성공하지 않게 했다. 운영 서버 경로를 새로 만들지 않았다.
- **검증:** 수정 전 목표 시간 누락 400과 Unicode 닉네임 오류 재현. 수정 후 전체 단위 **421개**, 린트·타입 포함 빌드·diff 공백 검사 통과. Chromium·WebKit의 신규/복구/인증 갱신/프로필/재전송 **12개 브라우저 흐름 통과**. 실제 앱/provider를 사용하되 API와 모델 제작물은 격리했으며, 운영 계정 mutation은 0회다. 공개 OpenAPI·약관 GET 200, 비인증 홈 GET 401만 실제 네트워크로 확인했다.
- **계속 대기:** 생년월일/호칭/자기소개·음성·이전 대화·크레딧/초대·새 친밀도·캠 누적·안전 집행 계약과 최종 제작물. 현재 API 호환 수정이 새 베타 서버 계약 완성을 뜻하지 않는다. 사용자 영수증 작업·디자인 제작물은 변경하지 않았다.

진행 기록은 각 단계의 구현·연동·검증 결과가 생길 때 갱신한다. 커밋·원격 푸시·배포는 이 목표 설정에 포함하지 않는다.


## 13차 진행 · 로컬 더미 모드와 실제 채린 모델

사용자 승인으로 새 백엔드 배포 전 로컬 확인 모드를 구현했다. DEV 기본 `VITE_DATA_SOURCE=mock`, `api`로 전환 후 개발 서버 재시작, 운영 빌드는 실제 API 유지다. 기존 UI 검토 경로도 유지한다.

- **계정/상태:** 로그인된 로컬 계정, 인증번호 123456·가입/카카오 온보딩·프로필 저장, 연결/재개/종료·대화·기록·출석/초대 원장을 브라우저에 저장한다. 실제 모드와 localStorage/sessionStorage를 격리해 숫자 ID가 같아도 운영 데이터를 읽거나 덮지 않는다.
- **모델:** `Design_Auto`의 사용자 제공 채린 런타임 13개 파일을 개발 자산으로 복사했다. 실제 모델 31개 파라미터와 원본 표정 8개를 사용한다. 모션·목소리·립싱크 설정과 남학생 모델은 추가 생성하지 않는다. 모델은 public 밖의 개발 전용 경로로 제공한다.
- **시나리오:** 일반/기록 없음/느린 응답/최초 실패 후 재시도/크레딧 소진/로그인 전을 개발 도구에서 선택한다. 표정 테스트·비용 시뮬레이션·초대한 친구 첫 연결 완료·화면 바로가기를 제공한다.
- **크레딧:** 문서의 출석 1,500/05:00, 기본 0·음성 20·고급 30·함께 50, 출석 우선·중복 요청 방지·부족 시 같은 기본 연결 유지, 초대 1,000·첫 완료 후 지급·최대 10명/중복 방지를 로컬에서 확인한다. 서버의 실제 정산/보상 완료는 아니다.
- **계약 경계:** 계정·메이트·새 베타 데이터는 UI 포트로 주입한다. HTTP transport는 기존 API 클라이언트를 로컬에서 실행하기 위한 호환 계층이다. 새 이전 대화/크레딧 API 경로를 만들어 서버 계약으로 취급하지 않는다.
- **남은 의존:** 실제 STT/TTS·대화/기록/원장 동기화·새 친밀도/해금·안전/청소년 집행·제작물은 [REQUEST](REQUEST.md)에 유지한다. 기존 검토 대사를 재사용하고 임의 홍보 문구/남학생/세계관/대사를 만들지 않았다.

설정과 정확한 제공 범위는 [로컬 모드 문서](LOCAL_MOCK_MODE_2026-11-22.md)에 기록했다. 전체 P0의 실제 서버 연동 완료로 표시하지 않는다.


13차 검증: 전체 단위/계약 **433개**, 린트·타입 검사 포함 운영 빌드 통과. Chromium/WebKit의 실제 채린 모델/표정·대화/재개/기록과 Chromium PIP 등 핵심 5개 묶음, 상태별 14개 흐름 통과. 운영 빌드의 실제 API 경로 사용·더미 UI/코드/모델 제외와 개발 검토 단축키 유지 확인. 외부 운영 API 요청 0건. 실제 음성·정산/동기화·물리 카메라/장시간 성능 완료로 처리하지 않는다. 상세 결과 파일은 로컬 모드 문서에 연결했다. 사용자 영수증/프린터 작업과 별도 로그인 배경 작업은 보존했다.
