## 조사 범위와 확정한 방향

45개 URL 모두 진입을 시도했다. 44곳은 공개 본문·카탈로그 또는 브라우저 렌더링을 확인했고, Behance는 접근 오류로 내용을 확인하지 못했다. 이 중 unlumen UI·Inspora·Pinterest는 아래에 적은 공개 범위까지만 확인했다. 공개 카탈로그 확인은 유료 소스·로그인 이후 화면까지 검증했다는 의미가 아니다.

일반 본문 추출이 비어 있거나 제한된 11곳은 로그인 없는 별도 브라우저에서 다시 확인했다. Originkit·affectUI·Artkit·Google Fonts·Brand Generator·Coolors·playgrnd는 공개 렌더링으로 내용을 확인했다. Pinterest는 공개 소개와 기능 안내까지 확인했으며 개인 보드에 로그인하지 않았다. Behance는 재시도에서도 접근 오류가 발생했다.

사용자에게 컬러와 폰트를 다시 물었고 다음 답변을 받았다.

- **컬러:** 네이비·라벤더 유지 + 대비 정돈.
- **한글 UI 폰트:** 현재 Pretendard 유지.
- **타이머:** 기존 JetBrains Mono를 숫자에 한정해 사용.

표의 ‘적용’은 사이트의 코드를 그대로 설치한다는 뜻이 아니라, 확인한 패턴을 CAPSULE의 기존 React·Tailwind 구조에 맞춰 현재 프로젝트에 맞는 패턴으로 구현했다는 뜻이다. 동일한 기능을 여러 레퍼런스가 뒷받침하므로 45개의 별도 기능을 추가하지 않는다. 실제 적용 파일과 검증 결과는 이 문서 하단의 구현 연결표와 프로젝트 코드를 함께 확인한다.

## 이미지 잘림 문제의 해결 기준

1. 원본 포스터는 참고 원본으로 보관한다.
2. 캐릭터 전경은 원본을 참조한 이미지 생성/분리로 실제 알파 투명도를 가진 파일을 만든다.
3. 배경은 원본 분위기를 유지하며 넓은 가로 환경으로 재구성한다. 원본을 가로로 늘이지 않는다.
4. 제목·룸 이름·설명·상태 표시는 이미지에 합치지 않고 별도의 DOM 레이어로 둔다. 이 레이어는 화면 비율과 폰트가 바뀌어도 수정할 수 있다.
5. 원본/생성 마스터/웹용 파생 파일과 프롬프트를 기록한다. 동일한 레이어를 카드·히어로·세션에서 재사용한다.
6. 눈·귀·머리·제목이 각 비율에서 잘리지 않는지 확인한다. 배경 크롭과 캐릭터 크롭을 같은 규칙으로 처리하지 않는다.

생성물의 실제 파일·프롬프트·레이어 조정 방법은 `src/assets/scenes`의 매니페스트와 에셋 문서를 따른다. 이 기준은 이미지 생성이 원본과 픽셀 단위로 동일한 누끼 결과를 보장한다는 뜻은 아니다. 얼굴·헤어·의상·표정은 원본과 시각 비교하고, 경계·투명도·낮은 해상도 문제는 별도로 확인한다.

## 폰트 확인

Pretendard 유지 결정 후 [제작자 저장소](https://github.com/orioncactus/pretendard)와 [OFL 원문](https://github.com/orioncactus/pretendard/blob/main/LICENSE)을 확인했다. 로컬의 `src/assets/brand/FONT-LICENSE.txt`도 같은 SIL Open Font License 1.1을 포함한다. 폰트를 앱에 함께 제공할 때 이 고지와 라이선스를 보관하며, 폰트 단독 판매나 수정본의 예약 명칭 사용은 해당 조건을 따른다.

## 보류 범위와 남은 확인 한계

- 공부 플로우와 관계없는 WebGL 장면·무한 스크롤 효과·큰 커서 이펙트·실사 자동 재생 영상·외부 유료 폰트/템플릿은 이번 적용에서 제외했다.
- 사이트들의 컴포넌트 수·가격·순위는 변할 수 있어 구현 조건으로 삼지 않았다.
- 공개 설명을 참고한 패턴의 자체 구현과 외부 소스 복사는 구분한다. 유료 소스나 다른 작가의 포스터·썸네일·스틸을 프로젝트 자산으로 내려받지 않았다.
- `REFERENCE_SITES.md`가 참조하는 `REPRODUCTION_CHECKLIST.md`, `FIDELITY_REPORT.md`, `data/source-directory.json`, `data/source-research.json`은 현재 체크아웃에 없다. 이번 조사 결과는 해당 파일을 읽은 것으로 가정하지 않고 이 문서에 독립적으로 기록했다.
- Behance의 사례 본문과 로그인 이후의 개인 컬렉션·유료 소스는 미확인이다.

## 구현·검증 결과

- 공통 구현: `RoomArtwork`, `PageSkeleton`, `ProgressRing`, `ActivityHeatmap`.
- 홈: 룸/캐릭터 검색, 분위기·저장 필터, 결과 수·빈 상태·필터 초기화, 저장·해제·되돌리기.
- 공부: 조용히 집중 모드와 정상 모드 복귀. 타이머·기록은 기존 상태 로직을 사용.

- `npm run lint`, `npm run build`(strict TypeScript 포함), `npm run test` 통과. 런타임/에셋 요청 오류 없음.
