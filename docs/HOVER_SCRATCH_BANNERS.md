# 메인 배너: 호버로 다음 이미지 드러내기

2026-10-27. 이전 하프톤 배경 연결을 제거하고, 현재 배너를 지우면서 다음 배너가 드러나는 상호작용으로 교체했습니다. [UI Beats Scratch to Reveal](https://uibeats.com/docs/component/scratch-to-reveal)의 공식 Canvas 소스와 MIT 라이선스를 확인했습니다. Motion 패키지는 추가하지 않았습니다.

## 동작

1. 채린의 노을빛 교실 배너로 시작합니다.
2. 클릭하지 않고 마우스를 움직이면 이미지와 대사의 지나간 자리만 함께 지워지고 다음 수아 이미지와 수아의 대사가 드러납니다.
3. 실제 배너 면적의 **40%**가 지워지면 **460ms** 동안 커지는 지우개로 남은 조각을 없앱니다.
4. 수아 → 다희 → 채린 순서로 반복합니다. 전환 후 650ms의 짧은 간격을 두고 새로운 마우스 이동부터 다시 지웁니다. 가만히 있어도 넘어가는 자동 슬라이드는 없습니다.

지우기 기준은 포인터 이동 거리 대신 작은 알파 마스크로 계산해 중복해서 문질러도 부풀지 않습니다. 같은 마스크를 화면 크기에 맞춰 다시 그려 리사이즈 뒤에도 지운 부분을 유지합니다. 모든 목적지 이미지가 decode되기 전에는 현재 정지 이미지를 보여 줍니다.

슬로건·소개·첫 방문/이어하기 버튼은 HTML입니다. 대사는 HTML로 편집하며 기존처럼 우측 일러스트 아래에 둡니다. 초상화·이름·꼬리를 제거하고 반투명 네이비와 18px 배경 블러를 사용했습니다. 이미지는 그 위의 대사와 하나의 DOM 슬라이드로 묶고 같은 알파 마스크로 지웁니다. 배너 캐릭터를 바꿔도 실제 공부 중인 세션이나 최근 룸은 바뀌지 않습니다. 이어하기 링크는 실제 데이터를 계속 따릅니다.

이미지 생성은 **built-in imagegen (`image_gen.imagegen`)**을 사용했습니다. 기존 채린·수아·다희의 이미지를 정체성 참고로, 사용자의 첨부 이미지를 배너 구도 참고로 사용했습니다. 결과는 2172×724의 3:1 이미지입니다. 텍스트를 합치지 않아 웹 문구만 바꾸면 첫 방문/이어하기 상태에 맞춰 사용할 수 있습니다. 세 웹용 WebP의 합계는 약 483KiB입니다.

## 입력과 대체 동작

- 768px 이상이며 hover/fine 마우스, 모션 감소가 꺼진 경우에 호버 지우기를 켭니다.
- 모바일·터치·모션 감소에서는 정지 배너와 채린/수아/다희 선택 버튼을 표시합니다. Tab/Space/Enter로도 선택할 수 있습니다.
- 모바일 선택 버튼은 문구 아래에 두어 인물을 가리지 않습니다. 터치 스크롤은 가로막지 않습니다.
- 링크·버튼 위에서는 지우지 않고, 대사 영역은 이미지와 함께 지웁니다. 캔버스·CSS 마스크 미지원/손실이나 목적지 로딩 지연 시 현재 그림을 유지합니다.
- 수동 선택·화면 이동·언마운트는 진행 중인 완료 애니메이션과 입력/크기 관찰자를 정리합니다.

## 검증

현재 구현은 512×256 알파 마스크만 인코딩하고, 실제 그림과 대사는 HTML로 유지합니다. 이전 큰 Canvas와 원본 cover 좌표 계산을 제거했습니다. 이미지 순환 시 이전 마스크를 해제하고 모션 감소·미지원 환경에서는 대사를 포함한 전체 정지 배너를 표시합니다.

린트·TypeScript/Vite 빌드·단위 테스트 **17개**와 브라우저 **70항목**을 통과했습니다. 지워진 대사의 글자·테두리 영역이 다음 슬라이드와 픽셀 차이 0으로 일치했습니다. 5개 화면 너비, 반복·마스크 해제·키보드·터치·모션 감소·미지원 대체·첫 방문/이어하기를 확인했습니다. 마스크 인코딩 256회에서 중앙값 약 0.6ms, 95백분위 약 0.8ms였으며 전체 프레임 시간 측정은 아닙니다. [검증 항목과 수치](../src/shared/ui/hover-scratch/validation.json). 다른 브라우저 엔진과 실제 모바일 기기는 이번 검증에 포함하지 않았습니다. 예전 하프톤 코드와 고지는 이전 시안으로 보관하며 현재 화면에서는 import하지 않습니다.
