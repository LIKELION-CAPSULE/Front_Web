## 01 · 로그인 (`/login`)

### 한 줄 요약
로그인 화면을 **"노트북 바탕화면"**으로 바꿨습니다. 메이트가 화상통화 창 안에서 사용자의 입력에 반응하고, 로그인 폼은 바탕화면 위의 앱 창이 됩니다.

### 기획 대비 달라진 점
PRD A-1은 "구조 유지, 배경만 스터디룸 커버에서 메이트 이미지로 교체"였습니다. 이번 변경은 **배경과 배치 구조까지 바뀝니다.**

| 항목 | 기획(PRD A-1 · 화면 지시서) | 변경 후 |
|---|---|---|
| 배경 | 메이트 이미지 콜라주 | 시간대에 따라 색이 바뀌는 바탕화면. 3D 캡슐이 천천히 떠다님 |
| 메이트 표시 | 배경 이미지 | **화상통화 창 안의 Live2D 메이트.** 커서와 입력에 표정·시선으로 반응 |
| 로그인 폼 | 오른쪽 반투명 카드 | 바탕화면 위의 앱 창("CAPSULE — 시작하기"). 창을 끌어서 옮길 수 있음 |
| 이용약관·개인정보 처리방침 | 화면 가운데 팝업 | 바탕화면 위의 **별도 창**으로 열림. 약관을 띄워 둔 채 가입 폼을 계속 쓸 수 있음 |
| 기타 | 없음 | 상단 메뉴 바(로고, 현재 시각), 바탕화면 파일 아이콘 3개, 이스터에그 2종(배경 속 숨은 CAPSULE 글자, 가끔 나타나는 색이 다른 큰 캡슐) |

바꾼 이유:
- 콜라주는 출시 메이트가 2명뿐이라 같은 그림이 반복되고, 서비스의 핵심("메이트가 나를 알아보고 옆에 있어 줌")을 보여 주지 못했습니다.
- 로그인 화면에서부터 메이트가 반응하면, 연결 화면의 화상통화·PIP 경험을 미리 보여 줄 수 있습니다.
- 메이트를 바탕화면에 그냥 띄우지 않고 **통화 창 안에** 둔 것은 Deskie(바탕화면 캐릭터 앱)와 구분하기 위해서입니다. PRD 1장의 차별점과 같은 기준입니다.

### 그대로 둔 것
- 헤드라인과 보조 문구: "나만의 메이트가 기다리고 있어요" / "노트북 앞의 시간을 함께 보내요."(A-1 초안 그대로)
- 카카오로 시작, "5초만에 빠른 회원가입" 배지, 약관 동의 안내, 로그인·회원가입 링크
- 이메일 로그인, 회원가입(생년월일 포함), 이메일 인증, 비밀번호 찾기, 새 비밀번호 화면의 입력 항목과 동작. 모두 로그인 창 안에서 그대로 동작합니다.

### 메이트 반응 (표정 + 시선만 사용)
Live2D 모델은 표정과 시선·고개 각도만 바뀝니다. 팔이나 몸 동작은 없습니다.

| 상황 | 반응 | 말풍선(적용한 초안) |

| 화면 진입 | 웃는 얼굴 | 왔어? 기다리고 있었어. |

### 이스터에그
- **숨은 CAPSULE 글자:** 배경의 튜브 무늬 일부가 CAPSULE 글자 획입니다. 처음에는 무늬로 보이고, 알고 보면 글자가 보이는 수준으로 대비를 맞췄습니다. 창을 옮기면 더 드러납니다.
- **색이 다른 큰 캡슐:** 떠다니는 캡슐 중 가끔(접속할 때 일정 확률로) 크기가 크고 색이 다른 캡슐 1개가 나타납니다. 누르면 반짝이며 메이트가 반응합니다. 서브컬처 타깃에게 익숙한 "이로치(색이 다른 희귀 개체)" 감성입니다.

### 정책 관련
- **AI 고지:** PRD 11.2는 온보딩과 연결 화면에 "AI 캐릭터입니다"를 표시하도록 정하고 있습니다. 로그인 화면에도 메이트가 나오므로 **메이트 창 제목 바에 같은 문구를 추가로 표시**합니다.
- **카메라:** 로그인 화면에서는 카메라 권한을 요청하지 않습니다. 통화 창의 "내 캠" 자리는 꺼진 상태로만 보입니다. 권한 요청은 기존 기획대로 첫 연결 때입니다.
- **저작권:** 지금 보이는 메이트 이미지와 모델, 통화 창 배경(도서관풍)은 **임시 에셋**입니다. PRD 11.2의 기준에 따라 정식 에셋으로 교체한 뒤 출시합니다.
- **움직임 줄이기 / 저사양 기기:** 운영체제의 '동작 줄이기' 설정을 켜거나 기기 성능이 낮으면, 배경은 정지 화면으로, 메이트는 정지 이미지로 자동 전환합니다. 로그인 폼은 언제나 바로 쓸 수 있습니다.

### 로고
로고를 **정리한 SVG(v2)**로 바꿨습니다. 모양과 색은 기존과 같고, 래스터에서 생긴 흔들림을 정리했으며 심볼·워드마크 분리본과 캡슐 단독 심볼을 추가했습니다. 파일은 `Front_Web/design/brand/capsule-logo-2026-11-22-v2/`, Figma는 디자인 시스템 페이지의 "CAPSULE · 로고 v2"입니다. 이번에는 로그인 화면에만 적용했고, 다른 화면은 이후 순서대로 교체합니다.

## 02 · 온보딩 (`/onboarding`)

### 한 줄 요약
온보딩을 로그인과 **같은 바탕화면**에서 이어지게 바꿉니다. 로그인 창이 닫히면 같은 자리에 "프로필 설정" 창이 열리고, 메이트가 아바타·닉네임 선택에 반응합니다. 로그인부터 온보딩까지가 "메이트와 처음 만나는 하나의 장면"이 됩니다.

### 기획 대비 달라진 점
| 항목 | 기획(PRD A-3 · 화면 지시서) | 변경 후 |
|---|---|---|
| 화면 구성 | 로고만 있는 헤더 + 가운데 큰 아바타 미리보기와 곡선 레일 | 로그인과 같은 바탕화면 + "CAPSULE — 프로필 설정" 창 + 메이트 통화 창 |
| 아바타·닉네임 | 아바타 8개, 닉네임 | **그대로**(창 크기에 맞춘 컴팩트 다이얼) |
| AI 고지 | "AI 캐릭터입니다" 한 줄 | 메이트 통화 창 제목 바에 항상 표시. 기존에 "프로필 선택" 제목 아래 있던 문구는 사용자 본인 설명처럼 읽혀서 뺍니다 |
| 생년월일 | 카카오 가입자에게만 받음 | **그대로.** 가입 방법이 아니라 "계정에 생년월일이 없는지"로 판단합니다. 이메일 가입자는 가입 때 입력했으므로 보이지 않습니다 |
| 추천인 코드 | 없음(가입 후 친구 초대 화면에서만 입력) | **추천인 코드(선택) 칸 추가.** 아직 코드를 등록하지 않은 계정에만 보입니다(주로 카카오 가입자) |

### 추천인 코드 정책 (결정)
- 이메일 가입은 회원가입 창에서, 카카오 가입은 온보딩 창에서 넣을 수 있습니다. 둘 다 선택 항목입니다.
- **가입 때 넣지 않았으면 나중에 친구 초대 화면(S-3)에서 넣을 수 있습니다.** 계정당 한 번만 등록할 수 있습니다.
- 보상 기준은 기존 PRD 그대로입니다: 받은 사람이 첫 연결을 마치면 양쪽 1,000, 1인당 최대 10명.
- **확인 필요:** 첫 연결을 이미 마친 뒤에 코드를 넣으면, 등록 즉시 보상할지 정해 주세요. 제안은 "등록 즉시 지급"입니다.
- 자기 코드는 넣을 수 없습니다.

### 생년월일 입력 방식 (회원가입·온보딩 공통)
- 연·월·일 3칸에 숫자로 입력합니다. 칸 아래에 "예: 2002년 1월 3일 → 2002 / 1 / 3" 안내가 항상 보입니다.
- 연도는 **4자리만** 받습니다. `02`처럼 2자리는 2002로 바꾸지 않습니다. 만 14세 가입 제한을 판단하는 값이라 추측하지 않습니다.
- 월에 2~9, 일에 4~9를 누르면 바로 두 자리로 채워집니다. 월이 채워지면 일 칸으로 넘어갑니다.
- 오류 문구는 상황별로 다릅니다: 연도를 입력해 주세요 / 연도는 4자리로 입력해 주세요 (예: 2002) / 월을 입력해 주세요 / 일을 입력해 주세요 / 존재하지 않는 날짜예요. 다시 확인해 주세요 / 만 14세 이상부터 가입할 수 있어요. 오류가 난 칸으로 커서가 이동합니다.

### 같이 바뀌는 것
- **새 비밀번호 화면(`/password/reset`)**도 같은 바탕화면 위의 창으로 바꿉니다(로그인 화면 계열의 일관성).

### 지원 화면 크기 (결정)
- 기준은 **데스크톱 1440, 1280**입니다. 창을 반으로 나눠 쓰는 경우(960 / 720 / 640)도 로그인부터 연결까지 맞췄습니다(2026-11-23).

- **휴대폰**으로 접속하면 피그마 SCR-40의 "모바일 접속 안내"를 보여 줍니다. 너비가 아니라 기기 종류로 판단하므로, 데스크톱에서 창을 좁혀도 안내가 뜨지 않습니다.
- PRD 5장은 "1440만", 12장은 "1440 + 390"으로 서로 다릅니다. 위 기준으로 정리해 주시면 좋겠습니다.

### 확인해 주시면 좋은 것
1. **모바일 접속 안내(SCR-40) 문구**: 실제 동작에 맞춰 "지금은 PC에서만 열려요. 링크를 복사해 PC 브라우저에서 열어 주세요."로 적었습니다. PC의 사파리 등 다른 브라우저도 막지 않으므로 "크롬에서만"은 뺐습니다. "PC로 링크 보내기"는 휴대폰의 기본 공유 창을 엽니다. 공유 기능이 없는 브라우저에서는 이 버튼을 숨기고 "링크 복사하기"만 보입니다. 초대 링크로 들어오면 초대 코드와 "PC에서 가입하면 둘 다 1,000 크레딧"이 함께 보입니다. 피그마 문구와 다르면 알려 주세요
2. **메이트별 끊기 멘트**(V-11): 확정 문구가 오면 확인 창에 보입니다. 없으면 질문과 버튼만 보입니다. 검토용 예시는 "잠깐 쉬고 와도 괜찮아. 여기서 기다리고 있을게."입니다
3. 위 지원 화면 크기 기준과 PRD 5장·12장 정리

## 11 · 메이트 모델 교체 · 로그인 방향 변경

### 한 줄 요약
채린 모델을 **새 모델(Aliving2D, 팀 자체 형식)**로 바꾸고, 로그인 화면을 "노트북 바탕화면"에서 **"졸던 채린 깨우기"** 화면으로 바꿨습니다. 오른쪽 로그인 폼은 그대로이고, 왼쪽에서 노트북 앞에 앉아 꾸벅꾸벅 졸던 채린이가 사용자가 다가오면 하품하며 깨어나 인사합니다.

> (2026-11-25 변경) 처음에는 채린이 카드를 CAPSULE 로고에 끌어다 놓으면 조립되며 나타나는 「변신」 화면이었습니다. 비교 시안 검토 뒤 이 「졸던 채린 깨우기」로 정했고, 변신 화면과 그 이미지 파일은 삭제했습니다.

### 바꾼 이유
바탕화면 로그인은 볼거리가 많아 시선이 흩어지고 로그인 화면 같지 않다는 피드백이 있었습니다. 변신 화면은 끌어다 놓는 조작이 필요했는데, 졸던 채린은 아무 조작 없이도(다가가기만 해도, 또는 10초 뒤 스스로) 깨어나 "기다리고 있었어"라는 메시지를 바로 보여 줍니다.

### 화면 흐름 (약 2초)
| 단계 | 내용 |
|---|---|
| 졸기 | 왼쪽에 노트북·책상 앞의 채린이. 눈을 감고 천천히 꾸벅이며, 머리 옆으로 큰 z → z → Z가 떠오릅니다. 가슴 위에 안내 말풍선 "채린이를 톡 눌러서 깨워 봐" |
| 깨우는 계기 | 커서가 채린이 얼굴 가까이에 잠시 머물기 · 채린이 클릭/탭 · 아무 키나 누르기(키보드 사용자) · 10초 뒤 스스로 |
| 깨기 | 눈을 깜빡이며 뜸 → 하품 → 사용자(커서) 쪽을 봄 → 웃으며 인사("앗, 왔어? 기다리고 있었어."). 노트북 화면 빛과 뒷면 CAPSULE 로고도 함께 밝아집니다 |
| 그 뒤 | 채린이가 마우스 커서를 눈과 고개로 따라봅니다. 이메일 입력 중엔 입력창을, 비밀번호 입력 중엔 눈을 피합니다. 채린이를 다시 누르면 수줍어합니다 |

### 그대로 둔 것 · 규칙
- 로그인 폼(카카오·이메일 로그인, 회원가입 링크, 약관 안내)은 그대로이며 연출 중에도 바로 쓸 수 있습니다.
- 매번 졸고 있다가 깹니다(인사까지 약 2초). 깬 뒤 왼쪽 아래 "다시 보기"로 다시 재울 수 있고, 1분 동안 입력이 없으면 다시 졸기 시작합니다.
- **AI 표시:** 왼쪽 위 "채린 · AI 캐릭터"는 채린이가 깨어난 뒤 항상 보입니다. 조는 동안에는 숨깁니다.
- 움직임 줄이기 설정 사용자는 정지 그림으로 보고, 깨우면 바로 웃는 그림과 인사가 나옵니다(큰 Z는 멈춘 채로 보입니다).
- 반쪽 화면(768~959px)도 같은 연출입니다(채린이가 위, 폼이 아래).

### 운영 반영 조건
운영에서 채린이가 움직이려면 백엔드의 「로그인 메이트 공개 API」가 Live2D 모델 주소를 내려 줘야 합니다. 그전까지 운영 로그인은 **정지 그림 3장(조는 모습 → 하품 → 웃는 모습)의 크로스페이드**로 같은 이야기를 보여 줍니다. 노트북 로고의 흐르는 빛(히트맵)도 Live2D가 있을 때만 켜지고, 그전에는 정지 로고입니다.

### 확인해 주시면 좋은 것
1. **의상 2벌의 쓰임:** 사용자가 고르는 기능인지(계정·메이트별 저장), 서버가 정하는지, 당분간 기본 의상만 쓰는지. 정해지기 전까지 기본 의상만 씁니다.
2. **문구:** 안내 "채린이를 톡 눌러서 깨워 봐", 인사 "앗, 왔어? 기다리고 있었어.", 버튼 "다시 보기".
3. **새 그림의 명찰:** 셔츠에 "강채린" 명찰이 그려져 있습니다. 캐릭터 설정(성씨 포함)과 맞는지 확인 부탁드립니다.
4. **바탕화면 로그인 요소:** 사진 폴더 이스터에그 등은 새 로그인에서 빠졌습니다. 다른 곳에서 살릴지 정해 주세요.
