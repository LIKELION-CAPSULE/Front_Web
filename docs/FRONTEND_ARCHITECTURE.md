기준일: 2026-10-26. 현재 구현은 백엔드 없이 전체 와이어프레임 흐름을 체험하는 로컬 데모입니다.

## 2. 재사용 경계

- `pages`는 URL과 사용자 행동을 해석하고 기능 컴포넌트를 조합합니다.
- 룸/캐릭터의 표현은 각각 `features`에 둡니다. 서비스 콘텐츠의 현재 진입점은 `room-service.ts`입니다.
- `shared/ui`는 도메인 규칙 없이 버튼·이동·입력·빈 상태·모달·탭·통계 패널을 제공합니다. `Button`은 동작, `ButtonLink`는 이동입니다.
- `CharacterTile`은 캐릭터 칸, `CharacterFigure`는 크기별 실루엣을 담당합니다. 공부 그리드·포커스·휴식에서 공유합니다.
- `ChatComposer`는 공부 중 미니 입력과 휴식 입력을 공유하고, `UpgradePanel`은 베이직 소진 시트와 유료 승급 팝오버를 공유합니다.
- `MemoryEditor`도 여러 화면의 공통 조각입니다. (`SessionList`·`FocusTimeline`은 2026-11-24에 쓰이지 않아 삭제했습니다.)
- `cn`에서 `tailwind-merge`를 사용해 공통 UI의 크기·색 옵션이 호출부에서 정확히 덮어써지도록 합니다.

페이지는 default export, 공유/기능 컴포넌트는 named export를 사용합니다. import alias는 `@/`이며 Vite와 TypeScript에 함께 설정합니다.

## 3. 로컬 상태와 수명

React Context + `useReducer`로 데모 상태를 공유합니다. 초기 샘플 데이터·액션·화면 집계·브라우저 저장을 분리했습니다. 별도 전역 상태/서버 캐시 라이브러리는 도입하지 않았습니다.

저장 키는 `capsule-wireframe-demo:v1`입니다. 버전·주요 필드를 확인해 손상된 JSON이면 초기 상태로 복구합니다. 저장이 거부되거나 공간이 부족하면 메모리 상태로 계속 동작하고 안내합니다. 프로필 메뉴에서 명시적으로 초기화할 수 있습니다.

- 계정: 로컬 로그인 표시·이름·아바타 옵션. 이메일/비밀번호/OAuth 토큰을 저장하지 않습니다.
- 이메일 회원가입: 필드/약관 검증 → 같은 패널의 인증번호 화면 → 확인 완료 → 온보딩 순서입니다. `VerificationCodeInput`은 공통 숫자 입력 표현, `EmailVerificationForm`은 확인·오류·재전송/만료 상태, `email-verification-preview.ts`는 명시적인 화면 확인용 데이터입니다. 인증 전에는 LOGIN 액션을 실행하지 않습니다. 실제 이메일 발송·인증·계정 생성은 아직 연결하지 않았으며 고정 확인 번호를 실제 인증으로 사용하지 않습니다. [동작·연결 경계](INTERACTIONS_AND_STUDY_GOALS.md#회원가입-이메일-인증)를 참고합니다.
- 세션: 룸·캐릭터·등급·이미 낸 크레딧·공부/휴식 phase·누적 경과와 실행 시작 시각.
- 기록: 종료한 세션을 한 번만 추가합니다. 새 세션은 MediaPipe의 얼굴 감지 시간을 누적해 집중/미감지 시간과 복귀 횟수를 저장합니다. 집중률은 정상 관측 시간 중 얼굴이 보인 시간의 비율이며, 미측정 세션은 대기로 표시합니다. 이전 샘플 기록은 유지합니다.
- 대화: 준비된 답변을 반환하며 베이직 3턴을 공부/휴식·모든 캐릭터에서 공유합니다. 서울 시간 새벽 5시 기준으로 갱신합니다.
- 원장: 충전/사용/보너스/패스 구매를 로컬 행으로 추가하고 각 행에 잔액을 남깁니다. 음수 잔액과 같은 등급 재승급을 막습니다.
- 관계: 공부 시간에 데모 참여 비율을 적용합니다. 선물·보이스 구매는 공부 기록을 변경하지 않습니다. 레벨/해금 규칙은 공식 정책이 아닙니다.

친구 화면의 기본 대사·모션이 열린 날짜는 `features/characters/unlocks.ts`에서 해당 친구를 포함한 첫 유효 공부 기록의 종료 시각으로 계산합니다. 실제 공부 시간이 있는 종료 기록을 사용하며 목표 달성 여부와는 별개입니다. 정렬 순서·개인/그룹 기록과 서울 날짜 경계를 고려하고, 기록이 없을 때는 날짜와 열린 상태를 만들어 내지 않습니다. 서버의 해금 이력은 아직 연결하지 않았습니다.
- 일정: 마이페이지에서 시험·목표·약속을 추가/수정/삭제하며, 모든 캐릭터가 동일한 공통 일정 목록을 사용합니다. 캡슐 카드의 다음 공부 약속도 같은 목록에 저장됩니다. 이전 캐릭터별 일정은 내용과 날짜를 보존해 공통 일정으로 이전합니다.

## 4. 타이머와 화면 상태

단순 interval 횟수를 시간으로 적립하지 않고 `elapsedMs + (현재 시각 - runningSince)`로 표시 시간을 구합니다. 일시정지 기능은 없으며, `TAKE_BREAK`는 실제 공부 경과를 고정하고 10분 휴식으로 전환합니다. `RESUME_SESSION`은 정지 상태로 저장된 구형 세션의 복원만 담당하고 실행 중 타이머를 멈추거나 완료된 휴식을 재시작하지 않습니다.

**MVP/API 연동 예정:** `다시 공부를 시작할까요?` 안내의 목적은 비정상 종료 후 공부 화면에 다시 진입했을 때의 복원 확인입니다. 2026-11-03 사용자 결정에 따라 MVP 기능 축소·백엔드 API 연결 단계에서 이 조건을 구현하며, 현재 로컬 데모의 구형 정지 상태/`resume=1` 조건과 구분합니다.

설정한 목표 시간(기본 50분)이 끝나면 휴식 10분으로 전환하고 초과 경과를 이어받습니다. 수동 휴식은 누른 시점부터 10분을 시작하고 목표 대신 실제 공부 시간만 보존합니다. 휴식이 끝나면 같은 목표·옵션·세션의 공부 누적 시간부터 자동 재개하며, `공부 이어가기`로 일찍 재개할 수도 있습니다. 휴식 시간은 공부 누적에서 제외하고 목표를 이미 달성한 뒤 재개하면 초과 공부 시간을 기록합니다. 전체 공부 종료를 확인하면 활성 세션을 비워 중복 기록을 막습니다.

공부는 정한 목표 시간의 경과 0초부터 시작합니다. `데모 조작`은 친구 반응·복귀·휴식 화면을 미리 보는 제어입니다. 실제 얼굴 감지는 공부 화면에서 카메라를 켰을 때 별도의 MediaPipe Worker로 실행합니다. 목표 설정·일정 팝업에서는 장치 권한을 요청하거나 얼굴을 감지하지 않습니다.

공부·휴식의 `StudySelfView`는 기본 아바타와 실제 카메라 미리보기를 전환합니다. 같은 장치 스트림을 사용하며 보기 전환 시 영상 요소만 연결·해제하고 트랙은 종료하지 않습니다. 카메라·마이크 권한은 공부 화면의 `StudyDock`에서 장치를 켤 때 각각 요청합니다. 추론용 숨김 영상은 `MediaProvider`가 별도로 관리해 표시 화면과 독립적으로 집중률을 측정합니다. `MediaProvider`는 로그인한 사용자의 활성 공부 경로에서만 장치 스트림을 유지하고 다른 화면에서는 종료합니다. `StudyDemoControls`는 룸 제목 오른쪽, `DevicePrivacyInfo`는 공부 헤더에 두어 로컬 처리·서버 미전송 안내를 제공합니다.

카메라·마이크 확인 단계와 전용 컴포넌트·스타일은 제거했습니다. 새 공부 진입 링크는 목표·대화 옵션 설정을 바로 열며, 이전 장치 사용 설정과 무관하게 새 세션은 카메라를 끈 상태로 시작합니다. `PreparePage`의 일정 추가는 공통 `MemoryEditor`를 모달로 열고 동일한 공통 일정 상태에 저장합니다. 저장·취소·외부 클릭으로 닫아도 선택한 목표·대화 옵션과 현재 URL을 유지하며, 등록한 일정은 마이페이지에서도 표시합니다.

확대 상태는 URL의 `focus`, 공통 채팅 패널의 열림·닫힘은 `chat`, 대화 상대는 `friend` 쿼리로 표현합니다. 대화 상대와 확대 상태는 독립적입니다. `SessionChatPanel`은 공부·휴식의 대화 목록·친구 토글·옵션 변경을 공유하며 친구별 초안을 컴포넌트 안에서 유지합니다. 넓은 화면에서는 비모달 사이드바, 1023px 이하는 native modal dialog 기반 오른쪽 드로어입니다. `TypingMessage`는 새 답장만 출력하며 전체 문장은 보조 기술에 한 번만 제공합니다. 새 메시지의 `createdAt`은 실제 전송 시각이고 기존 메시지에는 시각을 지어 넣지 않습니다. `AnimatedClock`은 바뀐 숫자만 Web Animations API로 전환하며 구분자·목표 시간은 고정합니다. 움직임 줄이기 설정은 공통 `useReducedMotion`으로 처리합니다. 진행 중 세션은 로컬 저장에서 복원되며, 홈이나 충전 화면을 다녀와도 유지됩니다.

## 5. 스타일·에셋·접근성

Tailwind CSS v4 Vite 플러그인과 `@theme`를 사용합니다. 와이어프레임의 흐름을 유지하면서 Landing_Page의 에셋에 맞춘 네이비·라벤더 테마를 적용했습니다. 토큰과 컴포넌트 기준은 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)에 정리했습니다. flex/grid로 반응형 레이아웃을 구성합니다.

- Pretendard는 랜딩페이지 폰트를 프로젝트 내부로 복사했으며 라이선스를 함께 보관합니다. JetBrains Mono는 Fontsource 로컬 번들입니다.
- 원본 SVG/PNG를 저장하고 임시 Figma URL은 런타임에 사용하지 않습니다. SVG의 루트 크기와 내용도 유지합니다.
- 캐릭터 장면·포스터·썸네일은 Landing_Page의 최적화 WebP를 사용합니다. 개인 아바타는 SVG로 그립니다. 전용 장면이 없는 도윤·모루는 생성 배경·투명 전경을 합성한 정지 장면을 사용합니다.
- 본문 건너뛰기·현재 메뉴·레이블·키보드 초점·동작 줄이기·native dialog를 제공합니다.
- 데스크톱 1280px 기준으로 구성하고, 768/390/320px에서 카드/헤더/세션 칸을 재배치합니다.
- PNG 카드는 로컬 Canvas로 출력합니다. 지원되는 파일 공유 API는 사용자 버튼 클릭 후에만 호출하며 미지원/취소/오류를 처리합니다.

## 6. 백엔드 연결 시 교체할 곳

현재 타입은 화면 모델이며 서버 DTO/DB 스키마를 확정한 것이 아닙니다. 실제 API URL·비밀 키·가짜 외부 요청은 만들지 않았습니다.

| 기능 | 연결 시 책임 |
|---|---|
| 인증 | 더미 로그인 표시를 실제 OAuth/사용자 조회와 인증 수명으로 교체 |
| 룸 | `room-service`를 비동기 조회로 바꾸고 로딩·오류·취소 추가 |
| 세션 | reducer의 로컬 시작/종료를 서버 세션·heartbeat·복구와 대조 |
| 카메라·감지 | MediaPipe 단독 MVP 연결 완료. 장치별 성능·감지 품질 검증과 운영 기준 확정이 남아 있습니다. YOLO는 MVP 이후 대상입니다. |
| 캐릭터 | `CharacterFigure` 자리에 Live2D 렌더러 연결, 반응 정책과 렌더 분리 |
| 대화·음성 | 준비된 답변/샘플 텍스트 대신 스트림·취소·실패·일일 한도 계약 |
| 크레딧·결제 | 서버 원장/승인/멱등성/환불/패스 권한을 기준으로 교체 |
| 기록·관계 | 서버 확정 시간·관계 이력·해금을 조회하고 중복 적립 검증 |
| 공유 | 다른 기기에서도 조회 가능한 공개 카드/공유 범위를 별도로 설계 |

브라우저 잔액·경과·관계 값은 실서비스의 승인 근거가 될 수 없습니다. 영상·얼굴 좌표는 API 모델에 추가하지 않는 원본 원칙을 유지합니다. `VITE_*` 값은 공개된다는 점도 유지해야 합니다.

상태 테스트는 음수 잔액 방지·차액/중복 승급·수동/자동 휴식·구형 정지 세션 복원·한도/5시 경계·중복 종료·충전 보너스·패스·선물/관계 분리를 검증합니다. 수동 휴식은 실제 공부 시간·얼굴 감지 누적값·기존 목표를 보존하고 휴식 재시작과 가짜 목표 달성을 막는지 확인합니다.

브라우저에서는 로그인부터 카드 저장까지, 기록·기억 편집·선물·원장·충전 후 세션 복귀, 1280/768/390/320px, 저장 거부/손상 복구를 확인합니다. 자동화 도구·스크린샷은 임시 폴더에만 두어 앱 의존성을 늘리지 않았습니다.

BrowserRouter를 사용하므로 배포 시 직접 URL 접근에 SPA fallback이 필요합니다. 현재 작업은 로컬 구현이며 배포/커밋/푸시/Figma 편집을 수행하지 않습니다.

## 참고 사이트 반영과 에셋 레이어

45개 사이트의 조사 범위와 적용/보류 결정은 `REFERENCE_RESEARCH.md`에 있다. 큰 UI 라이브러리나 3D 런타임을 추가하지 않고 기존 React·Tailwind에 맞춘 공통 UI로 구현했다.

- `features/rooms/artwork.ts`: 생성 배경·전경 URL, 제목·분위기·프리셋 키.
- `RoomArtwork`: 이미지 레이어와 제목 DOM 합성. 배경 cover, 전경 contain.
- `draw-artwork.ts`: 동일한 레이어를 PNG 내보내기에 사용.
- `PageSkeleton`: 라우트 지연 로딩의 실제 Suspense fallback.
- `ContributionGrid`(`features/records`): 내 기록 2D 잔디(하루 한 칸, 진하기 = 함께한 시간, 2026-11-26). 날짜별 합계는 `capsule-calendar.ts`(연결 시작일·오전 5시 기준). 이전의 `ActivityHeatmap`(2026-11-24)과 `CapsuleCalendar`(2026-11-26)는 삭제했습니다.
- `ProgressRing`: 리포트 집중률의 접근 가능한 meter.
- `report-relationship.ts` / `RelationshipGain`: 종료 시점의 관계 이전·이후 값과 레벨 경계별 진행·축하 효과. 레벨 규칙과 시간 배분은 공통 selectors를 사용합니다.
- `CompletionPortrait` / `completion-artwork.ts`: 채린·수아·다희의 종료 전용 이미지와 다른 친구의 기존 장면 대체 표시.
- `export-card.ts`: 선택한 종료 이미지·공식 로고·홈용 제목 에셋을 저장 PNG에 합성합니다.
- `scenes.css` / `interactions.css`: 레이어 프리셋, 탐색·피드백·기록 표현을 분리.

원본 PNG 마스터와 웹 파생본은 `src/assets/scenes`에 있으며 생성 프롬프트와 해시를 함께 보관한다. 상세 수정 절차는 해당 폴더 README를 따른다.
