## 구현 시 해석한 부분

- 번호 핀·메모·데이터 생성/변경 범례는 기획 주석으로 제외했습니다.
- 룸·프로필의 빈 이미지 슬롯은 유지했습니다. 공부/휴식/결과/공유의 실루엣 머리·가이드·아이콘 등 제공 에셋 25개를 로컬에서 사용합니다. 같은 해시의 중복 에셋은 하나를 공유하고 SVG 자체는 수정하지 않았습니다.
- 새벽 도서관·채린·수아·다희는 Figma 명칭을 유지했습니다. 미정인 두 룸은 한밤의 작업실/도윤, 초록숲 서재/모루라는 더미 콘텐츠로 채웠습니다.
- 더미 계정은 크레딧 1,240과 누적 48시간의 샘플 기록으로 시작합니다. 첫 방문 홈과 이어하기 홈은 프로필 메뉴에서 전환할 수 있습니다.
- 저장은 원본 MVP 제외 사항이지만 화면 체험을 위해 브라우저 안에서만 동작시켰습니다. 서버 로그·추천 개인화는 아닙니다.
- 샘플 아바타는 파츠 슬롯 선택·색·실루엣 형태 변화를 보여 줍니다. 실제 원화/헤어/의상 에셋이나 업로드 파이프라인이 아닙니다.
- 실제 카메라 권한·촬영·감지·Live2D·음성·AI·외부 결제는 연결하지 않았습니다. 모형 결제는 명시적 확인 후 더미 상태에만 반영됩니다.
- 미정인 시간 적립/관계/해금 규칙은 데모 계산으로만 표현합니다. 관계는 기록된 공부 시간의 참여 비율로 집계하고 선물·보이스 구매는 더하지 않습니다. 공식 정책을 확정한 것은 아닙니다.
- 타이머는 와이어프레임의 47:12에서 시작합니다. 데모 조작 메뉴로 07:42의 휴식 상태를 볼 수 있습니다. 실제 경과·일시정지·50분 후 자동 휴식도 동작합니다.
- 모바일 전용 원본은 없어 1280px 배치를 기준으로 768/390/320px에서 레이아웃을 보완했습니다.
- 캡슐 카드 PNG는 로컬 Canvas에서 실제로 저장합니다. 파일 공유를 지원하지 않으면 저장으로 전환하며, 링크의 기록은 이 브라우저 안에만 있습니다.
