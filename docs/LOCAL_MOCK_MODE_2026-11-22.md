# 웹 베타 로컬 더미 모드 · 2026-11-22

사용자 승인에 따라 새 백엔드 배포 전 프런트 동선과 상태를 확인할 수 있는 개발 모드를 추가했다. 실제 API 모드는 유지한다.

## 실행과 전환

1. `Front_Web`에서 `npm run dev` 실행. 현재 `.env.local`은 `VITE_DATA_SOURCE=mock`이다. 값이 없어도 개발 기본값은 더미다.
2. 오른쪽 아래 `로컬 더미`를 열어 상태 전환/초기화/화면 바로가기/표정 테스트를 사용한다.
3. 실제 API는 `VITE_DATA_SOURCE=api`로 변경 후 Vite 재시작. 기존 `BACKEND_API_ORIGIN`과 게이트웨이를 그대로 사용한다.
4. `npm run build`/운영 빌드는 환경 변수에 `mock`이 있어도 실제 API를 사용한다. 배포용 더미 모드를 추가하지 않았다.
5. 기존 독립 UI 검토는 `/__review`에서 유지하며 더미보다 우선한다. 검토 패널이 만든 `__review` 쿼리/창 이름이 있는 탭은 기존 검토 모드다. 일반 앱 확인은 새 탭에서 `/`를 연다.

## 상태 도구

- 일반: 로그인된 샘플 계정, 기록/대화와 출석 1,500 + 초대 2,000.
- 기록 없음: 기록/대화/초대 실적 없이 채린을 처음 연결할 수 있음.
- 느린 응답: 요청마다 2.5초 지연. 영구 대기 대신 로딩 후 완료.
- 실패 후 재시도: 홈/연결/대화/기록/프로필 수정의 각 해당 요청을 최초 한 번 503으로 실패시킨 뒤 재시도 성공. 페이지 전체 새로고침은 실패 상태를 다시 시작하므로 화면의 재시도 사용.
- 크레딧 소진: 잔액 0, 음성/고급 옵션 시뮬레이션 켜짐. 대화 시 기본으로 계속.
- 로그인 전: 로컬 로그아웃 + 빈 기록. 이메일/카카오 온보딩 동선 확인.

상태를 바꾸면 로컬 계정 데이터와 모의 앱 캐시를 초기화하고 화면을 다시 연다. 초기화는 실제 API 계정·토큰·설정에 영향을 주지 않는다.

## 코드와 저장 경계

- `src/main.tsx`: DEV에서만 동적 로딩. 명시적 API 모드와 운영 경로에는 더미 import 없음.
- `features/local-demo/bootstrap.tsx`: ApiClient 생성 전에 fetch를 설치. `/api/*`를 로컬에서 처리하고 외부 fetch/비 GET 자산 요청은 거부. 동일 origin 자산 GET/HEAD만 원래 fetch로 전달.
- `store.ts`: 순수 로컬 도메인/원장/샘플. `transport.ts`: 기존 실제 API 클라이언트를 재사용하기 위한 호환 응답만 제공.
- `BetaAccountPort`, `MateContentPort`, `BetaFeaturePort`: 서버에 없는 데이터는 UI 연산 포트로 주입. 새 `/credits`/이전 대화 등의 HTTP 경로를 서버 계약인 것처럼 추가하지 않음.
- 데이터 키 `capsule-local-beta:v1`. 앱의 기존 localStorage/sessionStorage 접근은 `capsule-local-beta:cache:` 접두사 아래로 격리한다. 숫자 userId가 우연히 같아도 운영 캐시/설정을 읽거나 덮지 않는다. 실제 API 모드로 다시 열면 원래 저장소를 사용한다.
- `local-assets/chaerin/`: 같은 작업공간의 사용자 제공 모델 런타임 13개 파일만 복사. 개발 전용 허용 경로로 제공. 운영 dist에는 moc3/model3/표정 파일이나 더미 코드가 포함되지 않는다.

## 계속 필요한 결정/제작물

실제 계정/원장·초대 지급·이전 대화·캠 누적/기록 목록·새 친밀도/해금·안전/청소년 집행 계약, 남학생/목소리/모션과 승인 대사는 여전히 [REQUEST.md](REQUEST.md)에 남는다. 이 모드 추가로 요청을 완료 처리하지 않는다. 실제 기기·다른 기기 동기화·운영 서버·장시간 모델 부하를 검증한 것은 아니다.
